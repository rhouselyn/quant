## 2. 为什么这些建模改变可能提高预测

当前B0把同一股票历史压成一个排序分数，未明确区分共同预期、行业预期、个股差异和噪声尺度。新模型的作用分工是：

| 建模假设 | 对应结构 | 潜在预测增量 | 失败条件 |
| --- | --- | --- | --- |
| 同行业存在可共享的条件信息 | 所有行业共用小头，读取行业/市场表示均值 | 用同业聚合辅助估计，共享参数而非每股重复估计共同变化 | 行业划分错误或组均值丢失有效尾部/异质信息 |
| 相对信号的有效性随市场状态改变 | M6与股票/行业表示的低秩交互 | 恢复相对标准化难以表达的绝对风险/活动状态 | 状态无预测价值、状态外推差或样本不足 |
| 同时期股票及跨时期噪声不同 | 正尺度头，独立读取z与M | 将收益位置和预测难度分开，避免统一尺度误差假设 | 方差膨胀掩盖均值欠拟合、训练不稳定 |
| 常态波动与少量宽尺度冲击共存 | 同中心两尺度密度 | 相比单Gaussian适应有限尺度尖峰厚尾，合法极端收益不被统一截断 | 非对称/真正幂尾/跳跃原子超出该分布族 |

精确中心化保证输出贡献定义清楚，但不自动减少总预测函数空间，更不自动降低噪声；若各头足够灵活，它可只是重参数化。真正的可检验增量来自共享池化、小头、低秩交互、信息路径和噪声目标。这里没有“数学式更漂亮所以必然更好”的推断。

条件因子网络为“金融结构决定神经网络职责”提供先例，但既有论文的定价重构不等于本模型的周频未来预测。本版不是无套利资产定价模型，不把低秩坐标命名为经济风险因素。[Gu、Kelly、Xiu原论文](https://doi.org/10.1016/j.jeconom.2020.07.009)

## 3. 预测对象：先定义收益单位

以现有快照的同一入退场开盘价为准：

    Y_i,t+1 = log(P_exit/P_entry),   R_i,t+1 = exp(Y_i,t+1)-1.

网络输出模型内条件log收益均值 μ_i,t 和正尺度 s_i,t。主排序分数 score=μ_log，不输出一个可以独立逃离均值含义的自由score。μ是模型内E[Y|F]；分布族错设和选择性缺失下，不保证等于真实条件均值。

本模型目标是个股log收益预测，不是算术收益最大化，也不是组合log效用：E[log(1+R_i)]、E[R_i]、E[log(1+wᵀR)]是不同量。本版保留现有log标签；算术收益期望只作为概率附表派生值，不因尺度更大而自动提高选股分数。

现有标签仍是Q1价格收益代理，不能改称净收益或完整含分红、税费、停牌和券源的总回报。真实R=-1的终值原子不能由有限log标签表示，本版不填造该事件的监督。

## 4. 唯一第一版架构：7,088参数的金融decoder

### 4.1 保留的主干与输入

- X：[B,N,40,30]；N当前为580，B为日期batch。
- 输入候选mask A：[B,N]，继续使用当前20/40/80共同可用性规则；不看未来标签。
- 共享Attention编码器：d=128，4层4头，与B0时序实现一致。
- z=normalize_L2(final_LayerNorm(encoder(X)))：[B,N,128]；所有均值/尺度头读取同一z，不使用InfoNCE projector作为评分表示。
- M：[B,6]，直接使用已有市场特征和训练前缀冻结缩放；不另做横截面z、不新建市场时序encoder、不增加外部数据。

只保留评分所需的时序主干和final_norm/L2；新模型不需要原L-G关系模块、market token、InfoNCE projector和自由score头。不把名义总参数减少误说成有效评分容量减少，旧B0存在不影响score的关系参数。

### 4.2 决策时分组

对A内股票按已知行业分组；首版拟定有效成员<5的行业和未知行业合并为OTHER，门槛5为固定设计默认值、未优化。OTHER不具有经济行业含义；记录原industry_id和effective_group。当前主批是回溯静态行业，仍属Q1，不冒称PIT。

令n=|A|，组人数n_g，p_g=n_g/n。空组不输出；单例组α=0但仍可由组头预测；A为空时无预测，不做除零。所有组汇总只用A；标签有效集合V只用于loss。

定义c_g=mean_{i∈g∩A}z_i，c_M=mean_{i∈A}z_i。这里包含自身，是组汇总，不冒称leave-one-out或官方指数。大小行业的市场权重按候选股数p_g计算，不能改成行业等权又声称同一分解。

### 4.3 基础均值头及状态交互

先在训练固定参考尺度s_ref的无量纲坐标工作：

    m0 = MLP_128→16→1(c_M)
    d0_g = MLP_256→16→1([c_g,c_M])       # 两层间GELU，末层无bias
    a0_i = w_aᵀ z_i                     # 无bias

m0头参数2081，d0共享头4128，a0头128，合计6337。m0最终bias保留；不在这些基础头另拼M，以免重复状态路径。

状态分支采用B的唯一616参数规格：

    c = Linear_8→4(GELU(Linear_6→8(M)))
    q_i = U z_i,      U∈R^(4×128), 无bias
    qbar_g = mean_{i∈g∩A} q_i
    m = m0 + b_Mᵀc
    d_g = d0_g + Σ_k γ_G,k qbar_g,k c_k
    a_i = a0_i + Σ_k γ_A,k q_i,k c_k

状态MLP92参数、U512参数、b_M/γ_G/γ_A各4参数，合计616。U与状态MLP普通非零初始化，三个增益向量零初始化；不能把两边映射也置零，使乘性路径无法启动。市场公共m不改变单checkpoint排序；有用的排序变化来自行业与股票不同的状态响应。

随后执行精确中心化：

    δ_g = d_g − Σ_h p_h d_h
    α_i = a_i − mean_{j∈g(i)∩A} a_j
    μ_i = s_ref × (m + δ_g(i) + α_i)

保存market_log=s_ref*m、industry_log=s_ref*δ、alpha_log=s_ref*α。三者和为μ，满足Σ_gp_gδ_g=0、每组meanα=0。给定A/组/权重与总μ，三项贡献唯一；内部神经权重、raw a/d仍不唯一，α也不是CAPM/Jensen alpha。

状态交互经中心化后仍可改变组内排序：

    Δα_i = Σ_k γ_A,k (q_i,k−qbar_g(i),k)c_k.

如果q在组内恒定，该项消失，行业共同响应交给δ；这正是明确的任务分工。

### 4.4 风险尺度独立读M

所有概率对照均使用相同风险头，避免把均值状态增益和风险状态增益混在一起：

    u_i = b_σ + w_σᵀ z_i + v_σᵀ M
    s_i = s_ref × (0.01 + softplus(u_i)).

参数128+6+1=135，不复用均值状态系数；总decoder=6337+616+135=7088。额外主要计算O(BN·128·16)+O(BN·128·4)，组求和线性于N，不引入N²横截面注意力。此数为解析参数计数，不是已实现运行测量。

s_ref=max(1e−4, median_t[1.4826·MAD_i(Y_it)])，只按共同779训练锚内有效成熟标签估计，每日少于3股不计该统计。它是数值参考单位，不宣称是混合标准差的无偏估计。保存数值、统计日历/mask哈希到冻结preprocessing；scores_only没有标签，绝不重新估s_ref。

初始化w_σ=v_σ=0，b_σ=softplus_inverse(.99)，使s=s_ref。均值头最后层和a0置零；m0末bias可设为训练期日期等权log均值/s_ref。这样初始预测在收益尺度内；不将旧任意单位score权重直接充当μ。新均值头采用标准化坐标，最后乘s_ref，避免优化器对“分数单位”和“周收益单位”不加区分。

## 5. 金融分解不需要伪造未来行业标签

未来实现收益可以在完整标签时分解为市场均值、行业相对均值、组内残差，但第一版不分别制造三套监督。用总μ的概率似然联合训练即可。

若V=A∩valid_y只是A的一部分，α在A内组均值为0，在V内未必为0。因此不能把V中的未来行业均值直接当成m+δ的无偏监督，更不能为方便监督用未来valid_y重新定义forward分组。

首版：forward始终基于A；NLL只索引V；缺失填充值不参与loss。现有industry_excess使用标签有效子集，不能原样接成δ监督。只在完整标签日期做同单位分解诊断；未来若加组辅助，必须同时对观测Y和总预测μ在同V投影，单独登记。

选择性缺失仍可能使可观察标签分布不同于全部候选分布。新网络不会恢复缺失事实，不能用更规范的公式替代停牌、退市和权益资料。

## 6. 概率模型与损失：从生成假设推导

采用有限尺度“常态＋较宽冲击”的同中心混合：

    p(Y|F) = 0.9 Normal(μ,s²) + 0.1 Normal(μ,9s²).

权重.9/.1、尺度比1/3是拟定固定默认，不是估计出的市场定律。只学习一个均值和一个尺度，避免逐股混合权重、多个均值与尾参数互相替代。两成分是噪声尺度成分，不是已识别牛熊状态。

对单样本e=Y−μ，完整NLL：

    ℓ = −logsumexp_k[log π_k − log s − log a_k
                     − 0.5 log(2π) − e²/(2a_k²s²)]
    π=(0.9,0.1), a=(1,3).

用logsumexp，不以“两个NLL加权平均”替代混合密度。若内部归一化Y/s_ref，报告原log收益单位NLL时加回log s_ref。

    L = mean_{t:|V_t|>0} mean_{i∈V_t} ℓ(Y_it;μ_it,s_it).

这是日期等权的边际复合似然，不假设同日股票独立，也未提供组合协方差。全batch无有效标签跳过optimizer更新；先按mask索引再算，不能靠NaN乘0。首版系数1；旧尾BCE、softIC、InfoNCE、行业η²在新model_type中关闭，旧B0不改。rank仍作评价；排序辅助只作为后续独立假设，不预先堆入。

纯log score有明确概率目标，但严格适当评分规则不保证受限分布族能够拟合真实金融分布，亦不解决非随机缺失或优化失败。[Gneiting与Raftery](https://sites.stat.washington.edu/people/raftery/Research/PDF/Gneiting2007jasa.pdf) 网络输出混合密度的原始方法参照为[Bishop](https://www.microsoft.com/en-us/research/publication/mixture-density-networks/)；固定同中心两尺度是本项目为限制自由度选择的简化。

### 为何修正上一轮Student-t建议

log-Student-t虽可有有限log方差，但正指数矩不存在，不能输出有限E[exp(Y)−1]；未截断simple-Student-t则给R<−1正概率。第一版选有限Gaussian混合，使模型内算术矩存在：

    E[Y]=μ, Var(Y)=1.8s²
    E[R]=exp(μ)×[0.9exp(s²/2)+0.1exp(9s²/2)]−1.

expm1(μ)是本对称log分布下的simple中位数，不是期望。完整分布支持R>−1，但不表示涨跌停、成交、退市边界已建模。

有限Gaussian混合只是相对同方差单Gaussian的有限尺度尖峰厚尾（固定配方峰度约8.333），渐近仍为Gaussian尾，远尾梯度仍增长，不具有Student-t红降影响。对称族也未描述偏态。选择它是在数值/矩闭合与有限样本自由度间取舍，不能声称发现正确的收益分布。

风险头可以通过增大尺度削弱均值梯度；log s项不使此行为免费，却不保证不欠拟合。必须保留均值误差、尺度分位数、floor占比、梯度/裁剪和校准诊断。若无法稳定训练，应记录失败并改下一版；不暗加β-NLL、尺度惩罚或删掉合法尾样本。

## 7. 数据、输出和融合必须一起改

### 原始标签与M覆盖

新概率目标使用原始有限有效log标签，不沿用±.25损失截断；特征clip保持。合法极端收益保留幅度，确认源错误则更正版本，未决异常留原因和监督覆盖，不以未来收益大小修改推理候选。训练前须审计原价/复权、入退场、权益、非有限与大幅样本；本轮没有完成这项全训练尾部审计。

M6复用已存定义：当周等权市场收益、4/12周合成累计收益、20周市场波动、上涨广度、成交额相对活动。M按训练前缀固定缩放保留跨期水平，±6特征clip仍会压缩极端值。B核对实际validation/history市场CSV及前939行保存统计，登记日历包络全部有限；最早19预热周有缺失，不属于共同779训练锚。首版遇登记训练/评分锚M缺行/非有限即拒绝，不把缺失当市场均值，不未来插值。详见B报告覆盖/哈希；日历156/303行不等于成熟评价153/297周。

### 输出和跨轮融合

逐模型输出：date、symbol、epoch、score=mu_log、mu_log、scale_log、market_log、industry_log、alpha_log、effective_group、available。π/a/distribution_version/s_ref及输入身份存metadata。组分表用于模型定义，不需要增加特征归因工具。

market_log/industry_log/alpha_log仅适用于结构化P1–P3；未分解P0明确标记贡献字段不适用，不填假零冒充可识别分解。所有概率臂均必须输出总均值、尺度、family和成员身份。

对锁定epoch/seed，概率为等权混合：

    p_ens(Y)=Σ_j w_j p_j(Y),   μ_ens=Σ_j w_j μ_j
    Var_ens(Y)=Σ_j w_j[1.8s_j²+(μ_j−μ_ens)²].

保存成员分布而非把它压回一个双Gaussian；成分数随成员增加。区间来自混合CDF，不能平均各成员分位数。simple期望按各成员simple期望混合，不把平均s塞进非线性公式。这里包含成员差异，但没有因此认证贝叶斯认知不确定性。

所有新概率臂主策略用原单位μ均值排序，不逐epoch z后把结果冒充收益。原standard逐腿验证Sharpe选单轮+win3规则保留，各腿锁对应各自成员混合，long/short概率分别标leg，不能说是同一个统一后验。P3另输出相同成员的legacy-z排序诊断，分离融合变化；旧B0保留原pipeline。新系统对B0总体改善不应被归因于单一loss或架构。

## 9. 综合裁决与研究边界

| 冲突 | 最终决定 |
