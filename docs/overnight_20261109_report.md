## 1. 一句话结论

**没有找到可认证的「更高收益」策略，但这不是想法枯竭，而是统计分辨率边界**：
今晚在同一批样本上按严格配对口径共做 **190 次检验**（搜索型 158 / 机制型 32）；
把全部检验计入后，test 窗认证一个改进需要 **+16.6bps/周**（P23 稳定版，
baseline 全部 alpha 35.2bps 的 47%），而观测到的最好正向效应只有
**+6.57bps/周（t=1.14）**，差 2.5 倍；按这个效应量需要约 **38 年**独立周数据。

**唯一能认证的改善是「更稳定」**：Top-40 相对 Top-20 在三窗降低周波动率
（约 4%）与下行波动（约 3%），收益中性，部署组合层同样迁移；
但 P21 复现门显示该效应在 3 个单 seed 上**方向 3/3 一致、显著性仅 1/3**，
强度部分依赖 3seed 融合降噪；Sharpe / MDD 的置信区间全部跨零。
**不构成替换 baseline 的理由。**

**一个有价值的口径发现**：按真实逐票成本计（P11 γ=0.5），K=40 反而略优于
K=20（test 24.32%/0.954 vs 22.95%/0.886，交互 +1.53bps/周），
因为 21–40 名票更流动且换手更低。但这是**执行成本修正，不是 alpha**。

## 3. 主要发现（按证据强度排序）

1. **分辨率边界是今晚最重要的结果**（P13/P13b/P16/P23）。
   最终分窗 `max|t|` p95 门：**val 3.826 / test 3.579 / vintage 3.708**
   （P23 稳定版，M=2000 + 每窗独立固定 seed，重复运行逐值一致；
   P13b 早期为 3.76/3.51/3.80）。test 观测 max|t|=2.81
   （P=0.356）、vintage 2.71（P=0.454）都在零分布内；唯一超出的是
   **val 的 4.84（P=0.003）**，全部来自 P12 分数平滑，而同一方案在 test
   只有 +0.59bps / t=+0.10 —— 真实但不可迁移的窗内效应。
2. **只有二阶量可测**。同一对曲线上（K20 vs K40，test）：均值差 +0.04bps，
   SNR t=0.010；波动率差 −0.001574，SNR=4.38 → **波动率比均值精确 449 倍**。
   这解释了 P14/P15 能认证方差改善、却完全认证不了收益改善，
   也解释了 P22 交互项 t≈11.8 为何是会计恒等式而非 alpha 证据。
3. **真实成本折扣**（P11）。固定 10bps 低估薄票冲击；按
   `clip(10·(median_amount/amount_i)^0.5, 3, 60)` 计，Top-20 有效费率
   ~17.7bps、组合 ~16.4bps，baseline 从 27.31%/1.011 降到
   **22.95% / 0.886 / +28.4bps**。所有「更高收益」主张都要带这个折扣读。
4. **空头瓶颈是券源，不是模型**（P6/P9/P10）。理论负尾部极强
   （bottom-10 在 test 为 −116.7bps/周），但两融名单过滤单独吃掉
   52–78bps/周，借券费再吃 15.4bps/周；用历史高相关可融券票替代
   无法复制特异负 alpha。优化空间在真实券源，不在规则或补位。
5. **IC ≠ P&L 第五次复现**（G1/G2）。4 个训练臂 RankIC 全部略升
   （0.0778 → 0.0783/0.0787/0.0791/0.0786），账本全面变差。
   第二批 G3 反过来（h8 IC 降到 0.0716 而 Sharpe 升到 1.1527），
   同样被 P20 证明是伪影 —— 双向都说明 IC 不能当收益证据。
6. **VAL 能选方向、不能估大小**（P17/P17b）。全局 val↔test Pearson +0.734
   但符号一致率仅 0.55；去趋势后 p12（双参数网格）残差相关仍 +0.948
   （形状真迁移），而 p2（单参数单调）塌到噪声。但 p12 的
   |test/val| = **0.14**：val 报 +37.4bps、test 只有 +6.6bps。
   失败模式是 **AMPLITUDE，不是 ORDERING**。
7. **一个此前没人注意的混淆变量**（P20）。`best±1` 融合在
   `best_epoch=1` 时只有 2 个成员（`[1,2]`），而 canonical 是 3 个
   （`[2,3,4]`）。G3 的「改进」在统一窗口下归零、剂量响应形状随窗口
   规则翻转。台账 §566 写「研究用 ens3 保持 best±1 以免历史臂不可比」，
   P20 恰好证伪了这句理由（详见 §7.7）。
8. **基准错配**（P15 前核对）。部署口径是 50/50 多空 combo
   （修复后 test 25.57% / **Sharpe 1.766** / −19.68%，两腿相关 −0.628），
   而今晚所有配对检验对照的是纯多 canonical（1.011）。单腿 +1~6bps 的
   改进在部署口径下被 50% 权重稀释。详见 §7。

## 5. 为什么「更高收益」找不到：一个统一的解释

P8、P13b、P16、P17b、P23 五组独立计算指向同一个结论：

- val 只有 148 周，年化 Sharpe SE ≈ 0.593 → 任何 0.04–0.08 的
  「改善」都在噪声里；
- test 283 周、配对差周波动 83.3bps、配对 SE 中位数 ~4.95bps：
  过最终多重比较门 t=3.579 需要 **+16.6bps/周**（baseline alpha 的 47%）；
- 今晚最大正向 test 配对效应 **+6.57bps/周 (t=1.14)**，差 2.5 倍；
- 反推样本量：6.57bps 需 1985 周（38 年），不做多重比较校正
  （t=1.96）也要 11.9 年；即使效应等于 baseline 全部 alpha 35.2bps，
  也需 69 周（1.3 年）。

**所以「没有胜者」是分辨率问题，不是策略不存在。** 继续在同一 283 周上
堆实验只会制造更多多重比较噪声。要突破只有三条路：
① 更长/独立样本；② 结构性新收益来源（P9/P10 指向真实券源）；
③ 把目标从一阶均值改成二阶方差（已证明可测，但幅度弱且部分依赖融合）。

## 6. 「更稳定」：今晚唯一可认证的候选（但不替换 baseline）

**Top-40 等权**（K 由 P5 在 val 上预注册选定，非事后挑参）：

| 指标（test，10bps） | K=20 → K=40 | 95% CI | 可认证？ |
|---|---|---|---|
| 周波动率 σ | 0.03841 → 0.03684 | Δσ −0.001574，CI [−0.00230,−0.00089] | **是**（三窗一致，安慰剂 K=10 方向翻转） |
| 下行波动 | 0.02410 → 0.02332 | CI 全负（三窗） | **是**（约 3%） |
| 年化收益 | 27.31% → 27.72% | Δ +0.04bps，NWt +0.01 | 否（中性） |
| Sharpe | 1.011 → 1.055 | Δ +0.044，CI [−0.080,+0.188] | 否（跨零） |
| MDD | −28.97% → −29.92% | Δ −0.95pp，CI [−1.70%,+6.79%] | 否（点估计变差） |
| 换手 | 1.038 → 0.920 | — | 低约 11% |

**部署组合层（P15）**：frozen combo（Sharpe 1.766 / −19.68%）
换用 K=40 多头腿后 test Δσ −0.000738、CI [−0.001163,−0.000338]
（方差效应可迁移），MDD 点估计改善到 −17.85%，但 ΔMDD / ΔSharpe
CI 跨零。解析最小方差配比 w*=0.563 在 test 上 Δσ CI 跨零 → **KILL**。

**稳健性与其限定（P18 + P21）**：3seed 融合书上 6 次 Δσ look 的
Holm 校正 6/6 全过、test 逐年 6/6；但 **P21 复现门**在 3 个单 seed 上
给出 Δσ 方向 3/3 为负、逐年 **5/6、4/6、5/6**、bootstrap 显著仅 **1/3**
（s43 CI [−0.002329,−0.000239]），融合书 Δσ 幅度是单 seed 的 1.3–3.0 倍
且逐年 6/6。→ 该效应**方向稳健，强度部分依赖 3seed 融合降噪**。
这是本轮对自己此前「三窗一致、逐年 6/6」概括的**下调**，必须一并引用。
四本书的 Δmean / ΔSharpe / ΔMDD CI **全部跨零**。

**成本阶梯（P19）**：固定费率 10→60bps，配对收益差线性增长，实测斜率
与理论 Δ换手×成本逐值吻合 → 收益差 **100% 来自省换手**；
18 个格子最大 |NWt|=2.76，达到认证门需 96–223bps/边（真实 ~17.7bps）
→ 经济上不可能。毛 alpha 截距三窗符号不一致。

**真实成本交互（P22）**——今晚唯一带来正收益增量的机制：

| test（γ=0.5 逐票费率） | ann | Sharpe | MDD | σ | excess | 有效费率 | 成本/周 |
|---|---|---|---|---|---|---|---|
| K=20 | 22.95% | 0.8855 | −30.29% | .038381 | +28.44 | 16.45bps | 17.08bps |
| K=40 | **24.32%** | **0.9538** | −31.05% | .036814 | +30.01 | 15.63bps | 14.38bps |

交互项 `d_net(γ=.5) − d_net(γ=0)`：val +1.76 / test +1.53 /
vintage +1.01 bps，三窗 CI 全正（K=40 书内 impact rate 比 Top-20
低 0.42bps，加入的票确实更流动）。但交互项 t=8.8–11.8 是
**会计恒等式**（毛收益在两种成本口径下相消），不是 alpha 证据；
真正该看的配对净差 test +1.57bps、CI [−5.83,+9.17] **跨零**，
且远低于 +16.6bps 认证门；MDD 还略差。

**边界**：波动率下降是分散化恒等式（~1/K），不是 alpha；
P15 只有 val/test 两窗，属探索性读数——**不能补 vintage 的原因是
2016–2017 缺历史两融名单**（242 周里 95 周短腿会空仓，§7.3 / P25），
不是「脚本没跑」。
→ 可记录为「收益中性、波动低约 4%、下行波动低约 3%、换手低约 11%、
回撤未分辨、单 seed 显著性偏弱」的**候选风控变体**，
**不是更高收益策略，不替换 baseline**。

4. **val 窗 4 周数据差异**：`combo_curve_val.csv` 的 long 曲线与当前

   是错的** —— P14/P15/P18 的 K=40 正是方差维度胜出方案，复现门有对象
   （已用 P21 补做）。因此这是明文违反 §128，不是分支无对象的合理替代；
   按 §5，G3/G4 全部读数证据等级 = **线索**。

   已读到的 G1 h400 val 读数」，但 G3 标签平滑同样是事后新发明。
   两者都只能记线索，不能记认证胜者。
7. **ens 窗口口径风险（P20 新发现）**：`pick_epochs(rule='window')`
   在 `best_epoch=1` 时给出 `[1,2]`（2 成员），canonical 是 `[2,3,4]`。
   同一个 canonical 模型仅换成单 epoch 1，val Sharpe 就从 0.9306
   掉到 0.8160（−0.1147），与 G3 声称的 +0.2221 同量级。

   但研究侧 ens3 刻意不用。建议统一口径或至少在跨臂比较时固定窗口。
   本轮只记录，未改 `src/` 或历史臂定义。
8. **队列 bug 的教训**：one-change config 的 diff assert 只保证
   「配置只改一处」，**不保证引擎真的实现了这一处**。派生引擎新增
   门控键时必须同步更新队列分发判定，并用「等价控制臂 + 门控生效打印」
   双重校验（详见 §10 与日志）。

## 9. 诚实性声明与折扣

- **幸存者偏差**（台账 §26.7）：universe = 2026 快照 580 只全员存活，
  2015 年前仅 521 只有行情 → **高估收益、低估左尾，本数据不可修**。
- **涨停开盘不可成交**：Top-20 平均 0.44 只/周，剔除后
  27.31%→26.97%、1.011→1.000；且这些票平均 −130bps，
  「买不进」实际在保护回测。
- **未来函数**：台账 §26.7 逐条核查未发现；本轮所有 rolling/tranching
  都投影到各自窗口的有效交易周，禁止跨空分周回填。
  G3 的多周标签平滑用未来 h 周收益定义**训练标签**，但
  `train_dates` 已截断到 `train_end−h−1`，不跨训练/验证边界，
  回测未使用任何未来信息。
- **成本**：固定 10bps 不含薄票冲击（P11）与借券费（~8%/年）；
  空头券源未按券商实际可用性验证。
- **多重比较**：严格配对口径共 **190 格**（搜索 158 / 机制 32）；
  P23 稳定版门 val 3.826 / test 3.579 / vintage 3.708
  （M=2000、每窗独立固定 seed，重复运行逐值一致）。
  这些检验并非独立（同 grid 相邻参数高度相关），独立假设的
  `max|t|` 零分布偏保守；但即使把 test 门降到 3.0，仍远高于
  观测到的最大正向 t=1.14。P22 的高 |t| 属会计恒等式型，已单列。
- **1 seed**：训练臂只跑 seed 42，按预注册无臂过门就不扩 seed。
  因此训练层结论是「未发现增益」，不是「证明无增益」。
- **IC ≠ P&L**：RankIC 改善不作为任何收益结论的证据。
- **本轮多次自我推翻**并全部写入日志：P13 硬编码结论、P13b 用错尺子、
