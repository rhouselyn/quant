## 结论及限定范围

建议只追加两个互不组合的候选，各 seed42、8轮：**P4GROUP**在P4上增加相对行业误差投影损失；**BDIFF2**在B0上增加共享K/V的双Q差分注意力。前者检验有限容量下是否应更重视跨行业共同收益误差；后者检验另一种时间信息混合方式。二者均没有已证实的金融收益优势。

| 候选 | 唯一研究变化 | 主要对照 | 固定默认值 |
|---|---|---|---|
| P4GROUP | 保留P4个股半MSE，另加中心化行业投影半MSE | 同批口径P4 | 投影权重1；无组内pair loss；新增参数0 |
| BDIFF2 | 双Q、共享K/V、token/head差分系数；保留原输出门 | 同批口径B0 | d=128、4层4头、FFN=384；lambda投影零初始化，sigmoid后0.5；新增68,112参数 |

既有P6gap/FOX常数衰减是另一批已登记方向，不再次包装成新增候选。不开P4GROUP×BDIFF2、组合排序项、额外seed或更长预算，不用已经读过的2021+历史收益来选择超参数。已有完整三年验证与历史复检口径保持不变。

## 1. P4GROUP：只提高相对行业方向的平方误差权重

### 现有依据

P4输出`mu_log = market_log + industry_log + alpha_log`；forward的市场/行业/组内中心化由当时可用输入集合决定，尺度分支与均值梯度隔离。原目标和已有实证见[P4协议](research_20261114_finance_faithful_protocol.md)及[P4结果](research_20261114_finance_faithful_results.md)，实现入口是[financial_return.py](../src/quant_mvp/financial_return.py)。

[P6诊断§2](research_20261114_p6_fox_diagnostics_results.md)中，P6相对P4验证多头的行业基准贡献−3.96bp/周，组内选择+4.13bp/周，彼此抵消。这支持检查跨行业比较与组内排序目标是否错位；它不是“加强行业监督一定提高收益”的证明。诊断同时表明缓冲损失主要在组内保留/替换决策，故本候选不宣称直接解决高换手。

损失与预测对象须匹配：平方误差对应条件均值，结果依赖于标签的权重和观测机制。这一原则来自[Gneiting的点预测研究，§2–4](https://arxiv.org/html/0912.0902v2)。下面的中心化行业投影是本项目的线性代数推导，不是该论文提出的金融方法。

### 精确定义

每个日期只在监督集合`O_t = available_t & valid_y_t`内计算，`N_t=|O_t|`。行业身份取forward已经生成的`effective_group`，不依未来标签重新把小行业并入OTHER。定义标准化残差、组均值和截面均值：

```text
e_i = (mu_log_i - y_i) / s_ref
e_bar_g = sum_{i in O_t, group_i=g} e_i / n_g
e_bar = sum_{i in O_t} e_i / N_t
L_relative_group,t = sum_g n_g * (e_bar_g - e_bar)^2 / (2*N_t)
L_mean,t = sum_i e_i^2 / (2*N_t)
L_total = mean_{t:N_t>0}(L_mean,t + 1.0*L_relative_group,t) + L_risk
```

`L_risk`保持P4的停梯度Gaussian NLL：mu和输入风险头的共享表示均detach，均值/尺度分别裁剪。`s_ref`沿用冻结训练统计，父P4协议数值为0.0348588114；它不是新增调参量。Faithful原论文说明了均值/方差优化隔离的作用；新增投影改变了均值目标，因此**不能继续声称本候选与原P4个股MSE训练轨迹相同**，只能声称风险分支不干扰新的均值目标。[原论文§2](https://arxiv.org/html/2212.09184v1)

不得直接把`market_log + industry_log`拟合成监督子集的组标签均值：alpha在forward输入集合内中心化，在标签缺失后的子集内未必均值为零。应先形成完整预测mu的残差，再仅在loss内投影；因此不改变推理分解、不把未来缺失信息送进forward。

日期等权范围与原P4一致。只有一个有监督组时附加项为零，该日期仍应计入平均；全部没有标签时返回无监督标记，由训练循环跳过整个优化器。OTHER沿用当前可用输入的小组/未知组规则，其经济含义较弱，不能声称它也是同质行业。

### 数学性质及边界

令`P_G`把向量映射为每个成员所属组的均值，`P_M=11ᵀ/N`映射为全体均值。由于分组穷尽当前监督集合，`P_GP_M=P_MP_G=P_M`，故`Q=P_G-P_M`是对称幂等投影。于是：

```text
L_relative_group = ||Qe||²/(2N)
L_mean + L_relative_group = eᵀ(I+Q)e/(2N)
∂L_relative_group/∂mu_i = (e_bar_g - e_bar)/(N*s_ref)
```

相对行业方向特征值从1提高到2；整体市场常数方向与组内零均值方向仍是1。新增输出梯度在同组内相同、整个截面求和为零。按`n_g/N`而非每组等权可以避免给小组成员额外的反人数放大；单成员组仍可能有噪声，尤其在成熟标签缺失时。

条件于当前输入及一个固定监督集合，若分组/权重不依赖收益值、二阶矩有限、模型能表达条件均值，正定二次型`I+Q`的总体最优预测仍是该条件下的均值。证明是对期望损失求导得到`(I+Q)(mu-E[y|information])=0`。若未来标签是否存在与收益相关，实际目标仍是观测机制条件下的均值，不能借此证明全候选均值无偏；原P4同样继承该限制。

有限容量、共享编码器和有限优化预算下，提高某一方向权重会改变误差分配；它没有提供额外信息，也不保证降低原个股RMSE。组均值仅在个股噪声非完全相关时才可能降低部分噪声，不能把组规模当有效独立样本数。平方误差仍受极端标签影响，当前行业分类也非PIT。

此目标不给组内两股分差直接新增梯度，因此不能自动抑制组内周际翻转。共享参数会让训练后的排序间接受影响，但该影响方向未知。它与pair logistic排序相比保留了二次均值目标的明确解释；代价是没有直接优化Top20边界、换手或成本。

### 最小验收与判读

最小单元验收应覆盖：手算两组不等人数；公共残差平移不变；组内零均值扰动不改变新增项；缺失/不可用标签不入loss且不改变forward分组；单组为0但日期不被跳过；全空监督；有限梯度；关闭权重复现原P4损失。风险头不应收到新增项梯度。

评价同时看日期等权log RMSE、相对行业投影RMSE、RankIC、NLL/覆盖、L20/S10/LS50净指标、换手与成本。只降低附加loss不够，若相对行业误差变好而原个股误差或扣费表现变差，应记录权衡，不能宣布解决了P6瓶颈。具体晋级门槛在执行协议冻结，不据历史追调权重。

## 2. BDIFF2：在原40周时间塔迁移差分机制

原始Differential Transformer以两张softmax图相减，正式论文已被ICLR 2025接收；原文结果主要是语言建模，并非金融回报预测。[原论文](https://arxiv.org/abs/2410.05258)

微软作者2026-01-20发布的V2说明改成双Q、共享K/V、每token每head的sigmoid系数，去掉差分输出后的逐头RMSNorm。页面仍说明正式报告后续准备，因此本页称其为作者技术发布，不能把V1正式接收资格移给V2。[作者说明与伪代码](https://huggingface.co/blog/microsoft/diff-attn-v2)

本地迁移定义如下，h为原pre-LN输出，四头分别对应，不把不对应的头相减：

```text
Q1 = RoPE(Q_norm(W_q1 h))
Q2 = RoPE(Q_norm(W_q2 h))
K  = RoPE(K_norm(W_k h)); V = W_v h
Y1 = causal_SDPA(Q1, K, V)
Y2 = causal_SDPA(Q2, K, V)
lambda[t,head] = sigmoid(Linear(128,4)(h[t]))
Y = Y1 - lambda * Y2
output = W_o(concat_heads(Y) * sigmoid(existing_output_gate(h)))
```

保留B0的Q/K RMSNorm、RoPE、输出门、40×30输入、末时点读出、FFN和训练目标，属于**DIFF V2启发的B0混合设计**，不是作者原版完整复现。Q2可共享原Q norm参数；lambda投影weight/bias置0得到0.5；Q2独立按既有Linear规则初始化，不复制Q1后把两个图从起点强制相同。新增模块用隔离RNG创建，避免改变既有共享参数初始化。lambda默认值是预先固定工程选择，非论文金融最优值。

两次SDPA使用原训练dropout=0.1、评估dropout=0；训练时两个随机mask不同，不能声称带dropout的逐次输出完全抵消公共噪声。保持同一因果可见范围、K/V头与位置；用两次常规PyTorch SDPA即可首筛，不引入自定义CUDA核。禁止与FoX、单锚点查询或时间压缩混用，避免有分支绕过新增路径。EMA teacher的5周输入、40周输入和`return_sequence`接口都要验收。

新增参数每层为Q2的`128*128+128=16,512`和lambda投影的`128*4+4=516`；四层合计68,112。FFN保留384，本轮明确接受容量增加，避免同时修改FFN。该对照检验整个新增架构，不足以单独识别差分算子相对普通额外容量的因果贡献。首筛后若值得进一步研究，再另登记容量匹配/双查询普通组合对照，不在本轮扩队列。

对40周窗口，额外Q投影约655,360 MAC/层，lambda投影约20,480 MAC/层，第二次QK/AV约409,600 MAC/层，总增约1,085,440 MAC/层；相对既有主矩阵估计7,618,560 MAC/层约14.25%。忽略bias、norm、门、softmax、反向、teacher和核调度，不是实测墙钟预测。参数更少的长序列线性attention也不一定适合本项目短窗口。

差分图可以有负权重，不能再解释为概率、收益贡献或可靠的金融归因。B0已有输出门，单纯压低聚合表示并非本候选独有能力；本候选真正新增的是共享同一V空间的两种时间选择相减。它可能取消有用公共趋势，也可能增加优化噪声，金融效果只能由配对验证判断。

最小验收：禁用时旧B0权重/输出兼容；5/40周形状和sequence接口；有限前后向；修改未来位置不改变此前输出；新增Q2/lambda有梯度；手工公式与实现一致；非法组合报错；EMA和完整训练状态恢复；真实尺寸显存/耗时。成功首筛后仍不能直接部署。

## 3. 未采用候选与统一边界

| 暂不采用 | 理由 |
|---|---|
| 不中心化的组MSE | 同时加重市场常数误差，与本轮相对行业假设不如`P_G-P_M`吻合 |
| 对forward industry_log直接监督标签组均值 | 输入与标签集合不同会混入alpha子集均值，改变原分解语义 |
| 更宽Top20缓冲或直接损失惩罚换手 | 诊断已有验证毛收益损失；新阈值及时间耦合目标需独立校准和登记 |
| P6gap与行业项联训 | 已有pair可靠性候选；同时变化将无法判读本次行业重加权 |
| Softmax-off-by-one、额外输出门 | 更小，但原B0已有输出门，首轮新增机制差异较弱；未作新收益首筛 |
| SwiGLU、输入非线性、局部卷积 | 已有同类实现与历史登记，不冒充新方向 |
| ModernTCN、FiX | 前者需换骨干和teacher适配；后者增加细粒度遗忘与数值条件，超出本轮最小改造 |
| DML/两阶段残差校正 | 缺明确新统计对象及训练期时间外残差，不能用已读验证/历史补拟合 |

训练锚、成熟标签、冻结预处理、候选股票信息集、费用和执行代理沿用父批；P4父协议为BQ_F0_r2、779训练锚、2002-07-19至2017-11-24、共同5周预留。完整验证2018–2020的153成熟周逐腿独立选单轮再win3、边界平移；2021-01-08起297成熟周仍是已读历史复检。金融分数按收益单位融合，B0架构臂保持原截面z融合。不得把多seed、改名或本次新模块当作恢复了独立测试。

单seed、8轮只是探索性首筛。两臂机制不同，比较各自父对照；不能把两者做成同等参数/同等目标的统一排行榜。报告验证逐年和配对不确定区间、成本压力及空头退化；历史只作描述。未达到冻结的验证晋级条件就停止，不自动改权重、lambda或预算。
