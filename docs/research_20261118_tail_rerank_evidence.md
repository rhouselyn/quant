## 1. RankNet 优化什么

Burges 等（ICML 2005）§3 式 (1)–(3) 定义成对概率与交叉熵：

\[
p_{ij}=\sigma(s_i-s_j),\qquad
\ell_{ij}=-y_{ij}\log p_{ij}-(1-y_{ij})\log(1-p_{ij}).
\]

原论文允许软目标；相同等级可取 0.5。分数用于排序，论文实验是合成数据与搜索相关性，没有金融收益证明。[原论文（Microsoft Research）](https://www.microsoft.com/en-us/research/wp-content/uploads/2005/08/icml_ranking.pdf)

**本项目推论：** 若目标为未来收益高低的二值比较，损失学习的是成对胜率的受限表示，不直接估计条件收益均值，也不直接最大化 TopK 扣费收益。反例：A 有 90% 概率赚 1%、10% 概率亏 20%，B 恒为 0；A 胜率为 90%，均值却为 −1.1%。因此胜率排序可以与均值排序相反。收益差加权会改变统计目标，但不能仅凭“加权”就称它等于实际组合目标；必须单独推导。

多空可以统一使用“越大越值得持有该腿”的效用标签：多头用 r，空头毛收益用 −r；实际成本、借券和执行约束仍须进入组合评价。若使用损失温度，应明确它作用于分数差，不能将任意排序分数解释成收益单位。

## 2. Set Transformer 哪一部分适合逐股输出

Lee 等（ICML 2019）§3.1 的 SAB/ISAB 编码器满足置换等变：重排输入，输出按相同方式重排。§3.2 的 PMA 对输入置换不变；§3.4 所称整个 Set Transformer 不变性包括该聚合解码器。SAB 的集合交互复杂度为 O(n²)，ISAB 为 O(nm)。[原论文 §3、Property 1 与 Proposition 1](https://proceedings.mlr.press/v97/lee19d/lee19d.pdf)

**本项目设计推论：** 固定基线生成候选集后，使用 SAB 编码器加共享逐行标量头即可得到逐股精排分数；不应直接拿 PMA 的固定数量输出当作与原股票一一对应的分数。忽略任意行位置编码，股票属性、基线分数、所属腿等特征随股票一起置换。候选集 mask 只能由推理时可知信息决定，不能用未来标签有效性筛掉输入股票。论文提供结构依据，不证明跨股交互会提高本项目收益；仍需与同输入、容量匹配的逐股网络比较。

## 3. 平滑受约束 TopK：本文件自行推导

这里仅约束选择总量与单项上限，令整数 0<K<n，分数 s 有限，τ>0：

\[
q_\tau(s)=\arg\max_{0\le q_i\le1,\,\sum_iq_i=K}
\left[s^Tq+\tau\sum_i h(q_i)\right],\quad
h(q)=-q\log q-(1-q)\log(1-q).
\]

严格凹性给出唯一解；熵在边界的导数保证解处于内部。拉格朗日一阶条件为

\[
s_i+\tau\log((1-q_i)/q_i)-\lambda=0,
\quad q_i=\sigma((s_i-\lambda)/\tau),\quad\sum_iq_i=K.
\]

左侧总量关于 λ 连续严格递减，从 n 到 0，故 λ 唯一，可一维求根。其数值实现须验证总量残差，不能把求根结果 detach 后误用独立 sigmoid 梯度。定义 d_i=q_i(1-q_i)/τ，则隐式微分给出

\[
\frac{\partial q}{\partial s}=\operatorname{diag}(d)-\frac{dd^T}{\sum_i d_i}.
\]

该 Jacobian 保持总量不变，也表明共同平移全部分数不改变选择。低温下有限精度可能使 d 下溢，数值稳定性仍需实现测试。K=0 或 K=n 应直接返回常数并取零梯度。

令 q* 是硬 TopK 的指示向量，比较两个目标可得

\[
0\le s^Tq^*-s^Tq_\tau\le\tau n\log2.
\]

若第 K 与第 K+1 分数间有严格正间隙，τ→0 时 qτ 收敛至唯一硬选择；边界并列时不能宣称收敛至特定股票集合。w=q/K 是总和为 1、单股上限为 1/K 的软权重，不是已经选出恰好 K 只股票。训练可用软组合收益，部署仍需硬选择与同口径成本回放。有限温度训练目标与硬 TopK 不完全相同。若增加行业、换手等约束，上述单个 λ 的闭式形式一般不再成立。

## 4. 与 SOFT TopK 论文的关系

Xie 等（NeurIPS 2020）§2 把 TopK 写成运输问题，加入运输熵后获得平滑映射；§3 使用 Sinkhorn 前向和最优性条件求导。其误差界依赖选择边界间隙；实验为 kNN 与 beam search。不能据此称已验证投资收益。[原论文 §2–3](https://proceedings.neurips.cc/paper_files/paper/2020/file/ec24a54d62ce57ba93a531b460fa8d18-Paper.pdf)

**本文件代数核对（不是论文算法复现）：** 两列运输计划可写为 Γi1=qi/n、Γi2=(1−qi)/n，列边际为 K/n、(n−K)/n。将运输目标乘 n 并去掉常数，得到

\[
\sum_i(C_{i1}-C_{i2})q_i
+\varepsilon\sum_i[q_i\log q_i+(1-q_i)\log(1-q_i)].
\]

因此取 si=Ci2−Ci1、τ=ε，就对应上节的 binary entropy 问题。论文的平方距离成本给出 si=1−2xi，故选小 xi 等于选大 si；符号和温度尺度不能直接略去。两种表述有特定代数对应，不能说成毫无关联；本项目的一维求根与 Jacobian 则应明确标注为自行推导，不能称已照搬或验收论文的 Sinkhorn 实现。
