# Leg pooling and return-gap ablations

Reuse the three frozen 2018-cutoff encoder caches, common Top-40 long and eligible Bottom-10 short baskets, and the same training, validation and historical test dates as the attention follow-up. Compare the saved leg-mean BCE model with four single changes. First, apply GELU to each projected stock vector before averaging. Second, add a learned projection of each leg's stock-level standard deviation to its mean vector, initialized at zero. Third and fourth, retain the original mean pooling and replace BCE with MSE or Huber on the signed next-week return difference.

The regression target is the same long-minus-short return difference used to create BCE labels, including assumed short borrow. Divide by the training gap standard deviation without centering, and report regression output in bps. Huber uses delta 1 in those scaled units. Fit up to 100 Adam steps per seed. Choose steps by each arm's validation loss, using only complete labels. Average seed scores before applying the fixed zero boundary. Every arm uses 70% long on positive scores and 40% long otherwise, with the remaining nominal in the short leg. Both allocations come from the prior study. Use the same turnover and short-fee assumptions and frozen Top-40 context. Report paired weekly returns and 8-week block-bootstrap intervals. The test period has been previously examined.
