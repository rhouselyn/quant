# 数学建模研究 C：结构、对称性与可解释归纳偏置

日期：2026-11-13，Asia/Shanghai。状态：complete（只读结构研究；候选实验未执行）。父任务：用户批准的六角度数学建模研究。共同证据：[事实底稿](research_20261113_math_facts.md)；协议：[三年验证](research_20261113_standard_execution.md)。代码版本、源码哈希、数据和历史暴露边界以共同底稿为准。本报告不修改代码、配置、训练或队列。

## 结论

**保留当前时序主干，先解释现有 CB，再把小型加性模型作为可解释性挑战者。当前证据不支持换成更大的图网络或 Set Transformer。**

实际 B0 是共享参数的单股票时序 Transformer，接 LayerNorm、L2 和线性排序头；行业/市场层次注意力虽然被构造，关系门固定为零，有限输入下对股票评分为恒等映射。它不是当前正在利用层次信息的 Mamba 模型。B0 的原始输入仍由当周横截面标准化产生，所以“评分网络无显式跨股路径”不等于“整体系统与其他股票无关”。

CS、CB、ADN 已是三种有明确数学含义的集合条件化结构，无需再造相同功能：CS 修改表示，CB 增加低秩双线性交互，ADN 改变归一化前的方向。CB 能精确分解“本模型自身分数＋行业条件交互＋市场条件交互”，但潜在维度没有自动获得经济语义。可解释结构是可检验的约束，不是未来收益的理论保证。

## 2. 实际计算的数学表达

令 B 为日期批大小，N=580，L=40，F=30，d=128，K=8；a_it 表示日期 t 股票 i 的输入可用性，g_i 为行业。X∈R^(B×N×L×F) 为已经预处理的输入，Eθ 为共享时序编码器。

    X → [BN,L,F] → Linear(F,d)+LN → 4个时间注意力块
      → 最后时点、LN和embedding线性层 → h∈R^(B×N×d)

单个时间块以 LN 后的输入生成 Q/K/V，Q/K 作逐头 RMSNorm 与 RoPE；因果注意力输出乘逐维 sigmoid 门，再作输出投影和残差，随后 FFN 残差。这是有限窗口的非线性时间函数，不是跨日期持久更新的状态空间滤波器。全部输入窗口止于 t，窗口内因果性是额外结构约束；取消窗口内三角 mask 本身不必然造成未来泄漏，但仍需另行登记对照。

设 n(v)=v/max(||v||₂,ε)，ℓ 为带仿射参数的 LayerNorm。B0：

    z_it = n(ℓ(h_it)),    s_it = wᵀz_it+b.

令 c_it=[c^I_it;c^M_it]∈R^(2d)，其中

    c^I_it = Σ_{j≠i,g_j=g_i} a_jt h_jt / max(Σ_{j≠i,g_j=g_i} a_jt,1),
    c^M_it = Σ_{j≠i} a_jt h_jt / max(Σ_{j≠i} a_jt,1).

没有其他可用成员时相应摘要为零；动态未知行业分支只保留市场摘要。当前主批行业是回溯静态分类，此防护不使主批自动成为 PIT 数据。

| 分支 | 实际公式 | 新参数量 |
| --- | --- | ---: |
| CS | s=wᵀn(ℓ(h+Wc))+b，W∈R^(d×2d) | 2d²=32,768 |
| CB | s=wᵀz+b+Σ_k α_k(Uz)_k(Vc)_k | 3dK+K=3,080 |
| ADN | s=wᵀn(ℓ(h)⊙[1+A(Vc)])+b | 3dK=3,072 |
| SELF | 上述 CB/ADN 中 c=[h;h] | 对应分支完全相同 |

U∈R^(K×d)，V∈R^(K×2d)，A∈R^(d×K)。CB 的 α 初值为零，ADN 的 A 初值为零。ADN 本实现没有 shift，没有给条件 scale 加 tanh 界；“adaLN”名称不能替代此处公式。SELF 的重复输入不增加独立信息，也使某些参数方向不可识别；因此它匹配名义容量和计算接口，而非保证所有有效自由度完全相同。

只实例化模型并统计参数，未 forward：B0 总参数1,467,393；CS 1,500,161；CB/SELF 1,470,473；ADN/SELF 1,470,465；各臂 temporal.encoder 均748,800。总数包含实际不影响 B0 分数的关系模块及辅助投影，不能用总参数量直接代表评分函数容量。

## 3. 对称性、信息与风险

**股票置换等变性。** 同时置换 X、available、行业ID及输出对应关系，逐股票共享 E、集合求和和逐股票评分满足 f(PX,Pa,Pg)=Pf(X,a,g)。行业 token 和分组路由需同步维护；只换价格不换身份不是合法检验。等变性以 eval 模式为确定性断言；训练 dropout 只应比较相同随机映射或分布。索引加和的 CUDA 浮点次序可造成微小数值差异，不能要求任意硬件逐位相等。

Deep Sets 提供集合函数与不变/等变结构的理论基础，但其表示定理有定义域和容量条件；本模型固定128维均值摘要不是任意集合函数的充分统计量，均值会丢失离散度、尾部和多峰信息。这是项目推断，不能用普适逼近口号消除信息瓶颈。[Deep Sets 原论文](https://arxiv.org/abs/1703.06114)

**信息路径。** B0 输入经过横截面缩放，故在原始数据层改变其他股票，仍可能改变本股输入。SELF 检验应分两层：固定预处理 X 时测试神经网络隔离；从原始行情重新预处理时测总系统依赖。不能由第一层推出经济上的完全独立。

**缺失与时间。** available 约束当前候选、集合摘要和推理输出；过去缺失周的特征携带并没有作为显式缺失 token 输入普通时间注意力，模型可能把重复的旧值当作连续观测。应先用“携带时长分桶的误差/换手诊断”确认是否有问题，再决定是否加观测龄特征；当前不把这个诊断自动升级为第三架构候选。min_history 约束不消除所有这种差异。

**条件结构的表达能力。** 简单加一个所有股票相同的市场标量会在排序中抵消；CS 的市场向量经 LN/L2 的非线性几何可改变排序，CB/ADN 则通过股票特异表示交互。LOO 市场均值并非完全相同，因为它排除了本股。应区分“真正读取其他股票的信息”和“摘要中的自身扣除项形成额外变换”。

ADN 的逐维调制并不直接等于每维经济贡献：统一正比例缩放在 L2 下抵消，逐维非均匀缩放才通常改变方向；符号翻转亦可能改变排序。CB 的8项可以精确求和，但 U/V 重标度等不识别意味着第 k 项不是天然稳定的经济因子。

**容量与复杂度。** 主干约 O(BN H[Ld²+L²d])，H=4；CS 额外 O(BNd²)，CB/ADN 额外 O(BNdK)，集合聚合 O(BNd)。全股票自注意力含 O(BN²d) 项；Set Transformer 的诱导点方法能降低集合注意力随 N 的增长阶，但本项目现有摘要已线性于 N，换用它会同时改变容量和信息统计量，且没有自动增加解释性。[Set Transformer 原论文](https://proceedings.mlr.press/v97/lee19d.html)

## 4. 两个候选及保持现状

### 候选一：现有 CB 的精确结构分解（先做，无需训练）

不改变预测函数。把 V 按行业/市场列分为 [V_I,V_M]，导出

    q_self = wᵀz+b,
    q_ind = Σ_k α_k(Uz)_k(V_I c^I)_k,
    q_mkt = Σ_k α_k(Uz)_k(V_M c^M)_k,
    s = q_self+q_ind+q_mkt.

这是 CB 同一个 checkpoint 内的恒等分解；q_self 不是独立训练 B0 的分数，两者主干训练后可能不同。新增学习参数0，输出形状[B,N,3]，算术约O(BNdK)，可复用 `_score_context` 已有投影，报告后处理即可。最终窗/seed融合的 z 标准化也需分摊均值和同一标准差，贡献单位标为分数；原始分数分解不能直接冒充组合收益分解。

可证伪检验：浮点容差下三项重构原score；只固定预处理输入去除行业/市场条件，比较真实分数变化；置换条件、保留缺失mask，查看贡献和排序敏感性；跨epoch/seed/年份报告分解稳定性。该诊断能验证模型利用何种条件，不能证明该条件提升收益。若项重构失败则解释实现不合格；若跨股优于SELF的配对证据不足，保留B0/SELF而不据解释图晋级。

涉及报告导出、`hierarchy.py::_score_context` 的只读复用、条件评分测试和标准评分融合说明。第一步应尽量在研究报告脚本读取参数完成，不新增生产forward返回值，以免破坏调用方/旧checkpoint。

### 候选二：按特征历史分组的加性小网络（待单独预注册）

目的：直接解释“哪类特征历史贡献了分数”，而不把128维潜变量强行命名。对每个特征 j 的40周历史 v_ijt∈R^40，用独立小网络 f_j:R^40→R，定义

    s_it = b + Σ_{j=1}^{30} [f_j(v_ijt) - m_j],
    f_j(v)=a_jᵀ GELU(W_j v+b_j)+c_j,
    W_j∈R^(8×40), a_j,b_j∈R^8;
    m_j=训练期固定参考分布下 f_j 的均值。

形状：[B,N,40,30]→[BN,30,40]→各特征40→8→1→[B,N,30]→求和[B,N]。参数30×(40×8+8+8+1)+1=10,111；推理复杂度O(BNF L×8)。m_j 不是额外学习参数，只把贡献常数移到截距。30项贡献可精确重构分数；相关特征仍会分摊替代，不能自动作因果解释。它能建模同一特征跨时间非线性，但刻意排除不同特征之间的交互。

该设计受 NAM 的加性原则启发；原论文逐单特征网络的结果不能直接外推到 A 股40周分组模型。[NAM 原论文](https://arxiv.org/abs/2004.13912)

最小对照：保持相同 X/标签/mask/日期/组合规则，加入1201参数的线性分布滞后模型 s=b+Σ_{j,l}β_jl X_ijl；保留原B0。加性候选不天然提供原128维InfoNCE表示，因此先明确比较是完整学习系统。若要隔离结构效应，需要增加B0关闭InfoNCE对照，并在两臂保留相同其余监督目标；不能一面取消InfoNCE，一面宣称是纯架构改动。学习率、预算和正则选择须在训练/既定验证内预注册；不要复制神经网络优化器参数后当作公平性的充分条件。

通过条件：结构重构误差合格，日期和mask边界合格；验证主指标相对基线满足预先确定的非劣界，且换手/成本没有不可接受恶化，解释跨重采样稳定性达到预注册标准。数值经济阈值由综合协议统一冻结，不能在看到候选结果后定。若非劣未获支持或相关特征贡献高度不稳定，保留现有模型；即使有解释优势也不自动部署。

实现影响：独立小模型、训练入口适配、预测格式、保存/恢复状态、配置校验、评分导出和新模型测试；不要强塞进 HierarchicalRanker 的无关关系层。复用既有数据和回放，保持checkpoint类型显式区分。暂不增加图网络、稀疏注意力、多阶段蒸馏或新的大规模超参搜索。
