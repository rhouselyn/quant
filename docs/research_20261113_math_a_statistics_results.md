## 结论

**当前 B0 是“共享时序编码器上的横截面判别排序模型”，CS/CB/ADN 是加入同周上下文的条件排序模型。** 这些模型有明确数学表达，但目前不等价于条件期望收益模型、概率生成模型、无套利定价模型或已识别的经济因子模型。没有证据要求为了形式上的理论感而换掉 Attention。

最值得先补的是统计对象和简单对照：保持 B0，在同信息集、同交易规则下加入线性排序基线；先检验复杂非线性是否带来稳定增量，再考虑可识别的加性结构。收益均值/分布预测应作为另一个明确任务，而非给现有 score 换名字。

本报告只提出待证伪假设，不报告收益改进。当前日期信息集仍有固定存活股票池与回溯行业分类的限制；数学上的因果前向计算不能消除原始资料中的未来选择。

## 2. 数学对象：能说什么、不能说什么

### 2.1 条件排序模型

令 t 为周五决策锚，i 为股票，A_t 为当时可入选集合，g(i) 为行业；\(\mathcal F_t\) 表示决策时已知信息。\(X_{it}\in\mathbb R^{40\times30}\) 是标准化历史窗口。\(h_{it}=f_\theta(X_{it})\in\mathbb R^{128}\) 为时序编码。记 \(N(v)=v/\max(\|v\|_2,\epsilon)\)，LN为带可学习仿射参数的LayerNorm。

对有限数值且门保持零的B0：

\[
z_{it}=N(\operatorname{LN}(h_{it})),\qquad s_{it}=w^\top z_{it}+b.
\]

这是从 \(\mathcal F_t\) 到相对分数的确定性映射。训练数据、标准化、尾标签与行业惩罚会耦合股票；给定标准化输入后的B0神经前向才是逐股的。

设 \(c_{it}=[\bar h_{g(i),t}^{(-i)},\bar h_t^{(-i)}]\in\mathbb R^{256}\) 为排除自身后的有效同业均值与全市场均值；空同业按实现为零。

- CS：\(h'_{it}=h_{it}+W_c c_{it}\)，再经过LN、N及线性头。代码中的 `cross_summary` 是无偏置线性映射；以实际模块为准。
- CB：\(u_{it}=P c_{it}\in\mathbb R^8\)，\(s_{it}=w^\top z_{it}+b+\sum_{k=1}^8 a_k(Vz_{it})_k u_{it,k}\)。这是低秩双线性条件交互，不自动是八个可交易风险因子。
- ADN：\(u_{it}=Pc_{it}\)，\(z_{it}=N(\operatorname{LN}(h_{it})\odot[1+Su_{it}])\)。此路径没有上下文平移项；不是一般adaLN所有变体的集合。
- SELF：将\(c_{it}\)改为\([h_{it},h_{it}]\)。这检验额外参数和自身非线性，但前处理依然使用当周横截面。

上述为源码推导；市场均值按股票等权，不能解释为市值加权市场组合。

### 2.2 score不是条件期望收益

设\(Y_{it}\)为实际监督收益，\(\widetilde Y=\operatorname{clip}(Y,-0.25,0.25)\)；尾标签\(C\in\{-1,0,1\}\)由当周收益前后20%生成。仅保留尾样本，若单独优化无约束logistic，则条件风险为

\[
R(s\mid X,C\ne0)=p\log(1+e^{-s/\tau})+(1-p)\log(1+e^{s/\tau}),\quad
s^*=\tau\log\frac{p}{1-p},
\]

其中\(p=P(C=1\mid X,C\ne0)\)，而非\(P(Y>0\mid X)\)，更非\(E[Y\mid\mathcal F_t]\)。加入相关性、对比学习、行业惩罚及有限模型约束后，这个单项最优概率解释也不再直接成立。源码依据为 `model.py:787–811`；这是本项目推导。

完整经验目标为

\[
\widehat L=\widehat L_{tail}+0.5\widehat L_{softIC}+0.1\widehat L_{NCE}+\widehat L_{industry}.
\]

尾损失按批内有效尾样本平均；softIC按满足条件的日期平均，并且对分数和收益都使用固定温度sigmoid软秩。故它近似秩相关，但并非精确Spearman，也不是严格单调变换不变。该组合没有明确的“真实收益分布参数”作为唯一总体最优目标。恰当评分规则要求预测对象与损失匹配；若要输出概率或分布，应另定义事件或分布并检验校准。[Gneiting与Raftery，2007，作者原稿](https://sites.stat.washington.edu/people/raftery/Research/PDF/Gneiting2007jasa.pdf)

### 2.3 与状态空间、因子模型的距离

状态空间模型典型形式为\(q_t=A_tq_{t-1}+B_tx_t,\ o_t=C_tq_t\)。Mamba用输入依赖的选择性参数实现序列状态更新；当前B0实际选用Attention，不可因仓库存在Mamba类就称其为状态空间估计。即使换成Mamba，也没有自动得到金融潜状态、观测噪声模型或Kalman后验。[Gu与Dao，Mamba原论文](https://arxiv.org/abs/2312.00752)

条件因子模型可以写为\(R_{i,t+1}=\alpha_{it}+\beta_{it}^{\top}F_{t+1}+\varepsilon_{i,t+1}\)，\(\beta_{it}=g(X_{it})\)。它描述收益及共同冲击；预测还需要\(E[F_{t+1}\mid\mathcal F_t]\)，不能把已实现未来因子作为预测输入。Gu、Kelly、Xiu的条件autoencoder研究为这种结构提供原始文献参照，但本项目没有相应收益重构与定价约束，不能直接继承其经济解释。[原论文条目](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=3335536)

同周行业/市场embedding均值仅是可知上下文摘要；它既不是未来共同冲击，也不是识别后的风险溢价。因此“市场token + 行业token”是归纳偏置，不是无套利证明。

## 3. 可识别性与失效模式

| 问题 | 数学原因与可观察后果 | 必要检查 |
| --- | --- | --- |
| 排序正确不等于金额正确 | 对硬排序，严格递增变换不改变名单，但对仓位和概率解释可能差异巨大；当前软秩训练更受尺度影响 | 报分数尺度、硬RankIC、Top20命中与收益，禁止以score直接替代预期收益 |
| 潜坐标缺乏唯一语义 | 对纯读出\(s=w^Tz\)，正交变换\((Qz,Qw)\)保持输出；这说明读出坐标本身不赋予经济命名，并非断言完整含LN网络存在任意旋转参数对称性 | 比较子空间或功能输出，不逐维强行对齐seed |
| 双线性分解不唯一 | CB中任一分量的\(V_k\)乘常数、\(P_k\)除同一非零常数可保留该项输出；符号/次序也可重标记 | 报可重构交互总贡献，不能把rank8逐维命名为8种经济风险 |
| 行业中性与个股α混淆 | 降低行业均值解释方差，只约束score，不能证明组合行业权重或收益β中性 | 分开测score行业η²、持仓行业权重和实现收益暴露 |
| 横截面依赖被当样本增量 | 同日股票共享市场冲击与尾阈值，40周窗口重叠 | 按时间块配对推断；seed仅衡量优化随机性 |
| 非平稳与异方差 | 共享参数假设跨时期条件关系有足够稳定性；排名可能稳定而绝对风险、成本和尾损失变化 | 预先定义分年、波动/流动性分层及校准漂移诊断，不看结果后找最佳分界 |
| 厚尾截断改变估计对象 | 截断可能把不同极端收益变成同值，软秩仍依赖间距；稳健化不能替代尾风险测量 | 用原始回放收益；报告截断率、边界并列率和极端期表现 |
| 缺失非随机 | 停牌、退市与标签成熟影响监督样本；可用集本身携带选择信息 | 分开输入候选mask与未来标签mask，量化被删失样本与持仓风险 |

## 4. 最小候选与反证设计

### A0 保持现状

保留B0与已有配置，先准确命名输出为排序分数。增加报告中的分层诊断不等于改变选模规则。若B0相对简单基线已有稳定、可交易且成本后增量，保持结构是合理结果。

### A1 同信息集线性排序基线（优先）

令\(v_{it}=\operatorname{vec}(X_{it})\in\mathbb R^{1200}\)，\(q_{it}\)为监督收益在当周有效集合内的居中分位秩，拟合

\[
\min_{\beta,b}\frac1{|T_{train}|}\sum_{t\in T_{train}}\frac1{|A_t^y|}\sum_{i\in A_t^y}(q_{it}-b-v_{it}^T\beta)^2+\lambda\|\beta\|_2^2.
\]

\(A_t^y\)仅在训练中表示候选且标签有效集合；预测使用\(A_t\)。保留完整40×30信息可减少“简单模型只看最后一周”的信息不公平；线性系数可按特征、滞后相加重构每个预测，解释是模型贡献，不是经济因果效应。

仓库已有 `scripts/r1111_ridge.py:83,106,141` 和 `scripts/probe_dataset_ridge.py` 可复用拟合/评分思想；后者固定旧外层2020诊断，不能原样拿来认证现行三年主协议。完整窗口设计矩阵、标签成熟、按日期权重及评分适配须单独核实，暂未实现。

可证伪假设：非线性B0相对完整信息线性模型的成本后增量不足以支持其复杂度。冻结单个正则规则；若必须选λ，只在训练内部按时间选择，记录试验次数，禁止对历史测试搜索。沿用同验证153周、同L20/S10/LS50交易代理与选轮/选择边界；线性闭式解没有epoch，比较对象是两套完整建模流程，不能宣称仅比较网络层。实际训练日期必须与B0的779锚及同样的监督/共同资格mask对齐；旧ridge脚本仅按counts和train_end筛选日期不能直接替代该契约。线性闭式解无需人为复制三个seed；对比B0三seed集成时按完整系统解释，另列B0单seed敏感性。

否决“复杂模型必要性”的证据需预注册等效/非劣界并给配对区间，不能用区间跨零认定相等。若B0的净收益差下界超过预注册最小经济增益且风险/换手约束通过，则线性基线作为主模型候选失败，保留诊断价值。数值阈值由综合协议统一冻结，本报告不另造阈值。

### 收益分解的理论边界（不新增候选）

若讨论\(\hat\mu_{it}=m_t+a_{g(i),t}+\sum_j f_j(v_{it,j})\)，应先注意公共加性\(m_t\)对同日所有股票相同，完全不改变横截面排序。它只能影响绝对收益预测、现金配置或总风险预算；要影响选股，市场状态必须与个股暴露/特征交互。行业截距和加性函数还需参考分布居中才能约定贡献基准，高度相关特征仍可能互相替代。这里是公式审查原则，不登记第二个实验候选。
