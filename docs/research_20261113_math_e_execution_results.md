# 数学建模研究 E：A股执行机制、组合决策与约束

日期/时区：2026-11-13，Asia/Shanghai。状态：complete（只读代码与原始来源研究；候选未实施）。父任务为用户批准的六角度数学建模研究；[共同事实](research_20261113_math_facts.md)、[三年协议](research_20261113_standard_execution.md)、[归档规则](research_recording.md)。主对象为 standard_v1 的 Q1 周级执行代理，不认证实盘。

## 结论

**目前最需要补的是“排序分数如何变成满足交易约束的持仓”，而不是再给神经网络加一个风险损失。** 分数行业惩罚、平滑分数与低换手都不等于可成交、持仓中性或成本后收益。应保留现有网络及标准主表，先让固定预测通过一条可追溯的意向—订单—实际持仓—现金账本链路。

当前标准回放与已有原价日账本是两个对象。前者可做同口径模型研究，但不承接受阻退出订单；后者已有原价、残单、借券数量和权益事件状态，然而输入覆盖和脚本中的假设情景仍不足以认证实盘。数学优化不能填补不存在的券源、成交或历史制度证据。

本报告仅提出一个最小候选 E1：固定分数和原选股规则，在数据允许的范围内做约束投影与日账本配对；不新增训练损失、不新增网络、不改变选轮。

## 3. 一个明确的数学决策模型

### 3.1 状态、单位和信息时点

令d为交易会话，t为周决策锚。状态包含现金C_d（元）、带符号持仓q_id（股）、已可卖多头库存q_id^sell、借券库存L_id（股）、未成交订单o_id、应收权益A_d（元）。以原价p_id估值：

    V_d = C_d + A_d + Σ_i p_id q_id
    w_id = p_id q_id / V_d

负q是证券负债。卖空所得现金不等于可自由再投资现金，需额外扣除受限现金和保证金。模型分数s_it仅为排序效用；如果使用均值—风险目标，必须先取得由训练内时间交叉拟合产生的 `μ̂_it = E[R_i,next | score, F_t]`，验证校准与漂移。不得将score直接代入收益率而把超参数称作经济风险偏好。

以下是解释决策层的候选数学形式，并非本轮已实现算法。令w^-为再平衡前漂移权重、u=w-w^-、Σ̂为决策时已知过去数据估计的PSD协方差，b_i为年借券率，Δd为预计持有自然日。全部收益/成本以净资产比例计：

    max_w  μ̂_tᵀw − (γ/2) wᵀΣ̂_t w − C_t(u) − Σ_i b_it (Δd/365) max(−w_i,0)
    C_t(u) = Σ_i [c_it^+ max(u_i,0) + c_it^- max(−u_i,0) + κ_it |u_i|^(3/2)]

γ为风险权衡，c是方向性比例费，κ是已按NAV和历史成交能力换算的冲击系数；本项目尚未校准κ。用过去成交金额估计容量不能把未来整日成交量提前用于订单大小。连续且凸的成本/约束可以形成凸优化；整数股、最低收费、固定持仓数、非连续交易状态会破坏这一简化，不应声称完整A股交易问题天然是凸的。[Boyd等，2017原论文](https://arxiv.org/abs/1705.00109)、[Lobo等，2007作者页](https://stanford.edu/~boyd/papers/portfolio.html)

约束至少包括：

- 预算：总多空名义敞口不超过登记资本，现金和保证金不能透支；组合比较保留L20、S10、LS50、LONG_CASH各自分母。
- 暴露：单股上限及 `l ≤ B_tᵀw ≤ u`，B为时点可知的行业/风格暴露。净行业暴露与多头行业集中度不同，纯多不可能对所有行业同时零暴露，应相对登记基准设置偏离限制。
- 交易方向：停牌禁止买卖；涨停/跌停方向限制与实际可成交数量分开；受阻目标保留订单或按预登记取消策略处理，不把没卖出的股票置为现金。
- 库存：卖出多头量不超过可卖库存；新增卖空量不超过可借数量，已有空头受期限/召回状态制约。无实际locate时账户可执行短仓上限为0；资格代理只能留作另一假设情景。
- 整股：申报属于该日该板块的数量集合；四舍五入后的订单重新检查现金、敞口和最小数量，禁止先用分数权重算收益再声称已处理整手。

这些约束应在订单/组合层强制满足。用有限权重损失惩罚无法保证它们每次满足，也难以表达停牌和借券库存的离散状态。

### 3.2 状态转移与自融资

实际成交Δq由已提交订单、可成交旗标和数量上限决定，不等于目标q的差额。普通交易后：

    q_(d+) = q_(d−) + Δq_d
    C_(d+) = C_(d−) − Σ_i p_fill,id Δq_id − fees_d − borrow_d + cash_payments_d

拆分等事件另更新股数/参考价格，现金分红先形成应收后按支付时点入账；不能同一事件重复算进复权收益和现金。`dataset_ledger.py:213–220`已用NAV归因恒等式检验会计平衡，后续应复用。T+1和召回状态说明此问题天然是带状态约束的序贯决策；当前固定周频可使用简化单周期决策，不必因此立即新增强化学习网络。

## 4. 唯一最小候选：E1固定意向的可行性投影

E0保持现状：标准Q1表继续用于同口径研究，注明周代理；不要以日账本模块的存在重命名历史业绩。

E1保持已锁分数、选轮、Top20/Bottom10意向名单及预算不变。在已核实执行输入覆盖的日期，先把意向权重w*转换为目标股数，再按现有日账本处理现金、卖出库存、整股、无券和残单。若需要连续近似，使用 `min ||w−w*||²` 的可行性投影；它只最小化跟踪偏差，不冒称最大化预期收益，不需要为score拟合收益校准器。受限现金规则缺实证时分别列登记情景，不挑选盈利最好的保证金。

假设：周级代理低估受阻退出、未成交与借券约束造成的跟踪偏差及成本。可能失败：日账本与周代理差异很小，或差异主要来自未验证权益事件而无法归因于交易规则。报告应分解“候选意向变化=0、订单未完成、持仓漂移、现金、费用、权益、估值未知”；不把所有差异归因于网络质量。

公平对照必须分两步：同一完整覆盖子集上周代理对日账本，另列覆盖子集与全样本的选择差异。不能只留下能顺利成交的日期后把结果称作总体可执行性。真实券源缺失时首先报告纯多及no_locate；公开资格无限券源只作标明假设的敏感性，不作晋级依据。

验收要求：

1. 成交后现金/保证金/库存约束违反次数为0；NAV归因误差在既有账本容忍度内；同一权益事件仅入账一次。
2. 每笔无法成交有原因，残单延续或取消可追溯，未知估值不能静默当0收益。
3. 输出各腿净收益、换手、跟踪误差、现金占比、最大受阻天数、可估值覆盖和成本敏感性；收益差及统计区间只作执行偏差诊断，不适用R1/S1的收益晋级门；更可信的执行处理即使降低收益也可能通过会计与约束验收。
4. 约束覆盖未满足则结论为partial/代理，不以提升Sharpe替代执行验收；保持现有模型是合法结果。

实施影响：优先复用 [dataset_ledger.py](../src/quant_mvp/dataset_ledger.py) 及 [replay_dataset_ledger.py](../scripts/replay_dataset_ledger.py)，新增standard锁定分数的适配才是所需工作；现脚本意向来源仍为旧v4，不能直接当standard一键复现。可能涉及raw quote输入契约、制度版本字段、已有标准评价适配和 `tests/test_dataset_ledger.py` 的边界用例；不需要改神经网络、训练调用或权重格式。数据依赖未补齐，本轮没有可声称已准备好的完整运行命令，也不安排GPU预算。

## 5. 与其他方向交叉审查

[A统计报告](research_20261113_math_a_statistics_results.md)准确指出score不是收益均值，故本报告把均值—风险优化作为需校准的理论接口，E1采用无收益假设的可行性投影。[B损失报告](research_20261113_math_b_losses_results.md)指出分数行业η²不等于持仓中性，必须在组合层测量/限制真实权重。[C架构报告](research_20261113_math_c_architecture_results.md)的CB精确分解只能解释分数来源；由于TopK、禁止交易和整股造成非连续映射，分数贡献不会自动等于实际盈亏贡献。公共市场加性项不改排名，但可在另登记的风险预算决策中影响现金/总仓位，不能混作选股增益。

本报告没有按ADN等历史赢家来决定执行规则。已有历史测试已暴露；未来E1重放仍是历史诊断，不能恢复独立测试身份。
