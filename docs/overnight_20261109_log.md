## 01:56 P14 预注册（读数之前冻结）：分散化的"方差改善"能否被认证？

**为什么转向方差**：P13b 给出分层功效——均值型改进在 test 需要

原则上**在同一段样本上更容易被测出来**。这不是降低标准，而是换一个
有正确统计功效的可测量。P5 已经暗示这个现象：K=40 在 test 上

→ 不做任何「换执行规则省佣金」或「按行业/流动性平衡」的重复实验。

**该选择在任何 test 读数之前已经冻结**，此处只做一次确认性检验。

**预注册判据（三窗 148/283/242 有效周，配对 8 周 moving-block bootstrap，

- KEEP「更稳定」候选：① 三窗 Δσ = σ(K40) − σ(K20) **全部为负**，

  （收益不显著劣化）；③ test 窗 ΔSharpe > 0。
- 否则 KILL。④ 附加安慰剂：把同样的检验用在 K=20 vs K=10（更集中）
  上，Δσ 必须**为正**；若方向不能翻转，说明仪器没有分辨力，结论作废。
- **重要边界**：即使全部通过，这也只是「收益中性 + 波动更低」的
  风控变体，不是「更高收益」，**不替换 baseline**；且按 P13b，

## 02:32 P19 成本阶梯：**封闭「K=40 靠省换手变出 alpha」这条最后机制**
