# D3-PV / D4：已有价量快照上的配对试验

日期：2026-11-13，Asia/Shanghai。状态：registered。父实验：standard_v1；用户最新指令允许按依赖范围启动，不等待全量二源、券源、财务修订。

## 范围与假设

固定现有 Q1 的 580 股票、30 个价量特征、历史复权桥接、静态行业分类。财务修订不参与输入；券源不参与训练。二源下载独立继续，下载中的文件不混入冻结训练快照。

本轮只新训 seed=42、8 epoch 的三组 B0 架构，复用已有 B0 的三年验证和完整测试评分：

| 组 | 唯一干预 | 主对照 |
| --- | --- | --- |
| D3_ZERO | 原 30 维后添加 3 个全零输入，其他设置不变 | B0（容量/初始化变化参考） |
| D3 | 添加 observed_bar、原始特征非有限比例、距最近 observed 周的年龄/40（截断40，上市前为1） | D3_ZERO（同参数量、同初始化） |
| D4 | 训练日期权重 `2**(-age_years/5)`，固定训练锚点上均值归一到1 | 复用 B0 |

D3 在基础特征预处理后追加通道，不重新拟合、不改变 eligibility、标签或样本；指标不宣称区分停牌/供应商漏报。推理冻结通道模式。D3 只是原缺失实验中的价量子集，不代表财务缺失分支已完成。

D4 年龄截止训练拟合边界 2018-01-01；训练日期、排列、batch、更新次数不变。权重进入 score、RankIC、InfoNCE、行业暴露四项损失的分子，保留各项原分母，不按当前 batch 的权重和再次归一化。score 原本按有效尾部股票数归约，其余按有效日期归约；不把这种差异偷偷改成等日目标。CPU 预检有效日期779，半衰期5年的 ESS 约578。此次暂不新增近10年硬截断组。

## 统一评估和解释

训练截止2018；验证2018–2020，153个成熟决策周。各模型各腿独立按完整验证扣费 Sharpe 选最佳 epoch，再做中心±1的win3，边界平移；不是固定4–6轮，也不固定多空不同轮段。锁落盘后才评分完整测试：2021-01-08至2026-10-23，297周。不根据测试选择种子或追加实验。

沿用 standard_v1 的10/30bp单边交易费、8.35%/12%借券假设、缺失退出−20%压力情景；独立列L20、S10、LS50及多头加现金，资本分母不变。验收含净年化、Sharpe、换手、年度、配对周差及block bootstrap。D3必须对D3_ZERO有验证改善，单比B0不足以归因信息；D4无新增参数。两者均不是跨股关系实验，不推断跨股架构有效。

历史测试已多次暴露，因此结果属于Q1探索，不能称全新未触碰的外部测试。正结果需根据验证再登记三种子；边界最佳需登记延长且保持完整训练状态，不自动把所有模型续训。

## 分层门槛与缺口

局部通过条件：训练前缀与原B0一致、D3基础张量/标签/可用性不变、通道前缀因果、D4权重仅用训练日期、快照与源码哈希冻结、三年选轮锁及完整测试、断点状态保存。此门槛只允许Q1价量探索，不把全量严格门槛改成通过。
