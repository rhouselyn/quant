## 0. 反不诚实协议（本文件最重要的部分）

1. **两窗分离**：`val = 2018-01-05..2021-01-01`（157 周，模型训练见过的选模窗），
   `test = 2021-01-08..2026-10-16`（302 锚点 / 283 有效周）。
   任何"选哪个臂/选哪个参数"的决定**只能**用 val 读数；test 只在方案冻结后读一次。
2. **写队列脚本只打印 val 指标**，训练臂的 test 读数在冻结选择前不进入我的判断。
   冻结动作 = 在日志里写下"选择 X，理由 …，此时尚未看 X 的 test 读数"。
3. **多重比较**：本仓库台账 §1-§25 已在同一 test 窗上读过几十个臂，
   因此单臂 t≥2 **不构成证据**。晋级需同时满足：
   (a) paired 周度差（NW5 t）≥ 2.5；(b) val 与 test **同号**且逐年 ≥4/6 年非负；
   (c) 至少 3 seed 复现（先 1 seed 只是筛选）；(d) 不在 test 上重新调任何参数。
4. **零训练实验**没有拟合参数时可直接读 test，但依然按 (a)(b) 判；
   有拟合参数的（日历规则）必须 val 拟合 → test 单次外推。
5. **禁止**：用 test 挑 epoch / 挑阈值 / 挑融合权重 / 挑分桶；
   任何"再试一档"必须写进日志并说明是先验推理还是事后反应。
6. **会计口径统一**：`np.expm1` 转简单收益、单边 10bps、Top-20 等权、
   基准=全体 580 等权、缺失收益记平、无期末清算；一律用仓库现成
   `long_only_backtest`，不自写会计（§7-A4 的两种陷阱）。

## 1. 审计发现（已读代码，先记录，不含新实验读数）

- **特征/标签因果性通过**：`aggregate_weekly` W-FRI 窗口只用当周日线；
  `add_features` 全部 rolling/diff 回溯；日径 6 特征来自"本窗口自己的日线"；
  `arrays()` 的 `open_open` 标签 = log(open[t+2]/open[t+1])，
  特征停在 t 的周五收盘，买入在 t+1 周一开盘 → 无前视。
  全局标准化 mu/sd 只用 `[:train_end]` 拟合；per-week z 用当周截面。
- **待查 A2（重要）**：`predict()` 导出的 `predictions.parquet` 带 `tradable`
  （周一开盘缺口 < 涨停才可买），但 `ensemble_best_window.build_ens()` 与
  `merge_seed_runs.py` **都把这一列丢掉了**。冻结参考书的
  `long_only_backtest` 因此**没有执行可成交过滤**，可能把"周一开盘一字涨停
  买不进去"的票按开盘价计入收益。必须量化：Top-20 里不可成交占比、
  这些票的收益、过滤后书的变化。若影响大，冻结基线的数字需要打折声明。
- **待查 A3（宇宙）**：580 = 申万一级 29 行业 × 20 只"当前快照"随机股，
  行业分类也是当前快照回溯。这本质是用 2026 年存活/分类信息挑选 2000 年的
  样本 —— 严格的幸存者偏差，属"未来信息进入样本定义"，不是价格泄漏。
  只能声明与粗量化，本晚无法重建无偏宇宙（需历史成分股快照）。
- **待查 A4（脆弱性）**：283 周超额是否集中在极少数周 / 极少数票；
  块 bootstrap CI；逐年；MDD 归因。
- **"理所当然"的默认值核查**：解析全部 621 份 config（`configs/*` +
  `outputs/*/config.yaml`）发现若干旋钮在**整个项目历史上从未变过**：
  `extreme_frac` 恒 0.2、`score_temperature` 恒 1.0、`rankic_temperature`
  恒 0.05、`score_weight` 恒 1.0、`rankic_weight` 恒 0.5、`dropout` 恒 0.1、
  `industry_exposure_weight` 恒 1.0。它们是从 2004-yahoo 时代继承的先验，
  **从未在 ak2000（1399 周 / 30 特征）上重新验证**。这是本晚训练实验的主线之一。

## 2. 零训练实验（CPU，先做）

| ID | 内容 | 完整执行理由 |
| --- | --- | --- |
| Z0 | 可成交过滤审计与"修正书" | 见 §1-A2。若过滤后显著变差，说明冻结数字含不可执行成分；这本身是"真理"级结论，且修正书是更诚实的候选策略。 |
| Z1 | 收益脆弱性 + 日历规律（用户点名） | 描述性：逐月/逐年/周内/节假日、Top-k 周贡献、块 bootstrap。推断性：只允许**一个**预注册函数形式——在 val 上用 `excess_t ~ 1 + sin(2πt/52)+cos(2πt/52)+sin(4πt/52)+cos(4πt/52)` 拟合（5 参数，148 周），取拟合季节项 ŝ_t，按 `w_t = clip(1 + ŝ_t/σ_val, 0.5, 1.5)` 缩放纯多仓位（缩放通过"部分持币"实现，现金零收益，成本按换手计），κ 固定不调；test 上单次外推。理由：低维傅里叶是先验最保守的季节模型，annual+semi-annual 覆盖A股"春季躁动/年中/年末"叙事；用 val 拟合、test 确认，避免在同一段数据里挖日历。同时报告"月份均值在 val/test 是否同号"作为不带策略的描述性判决。 |
| Z2 | 秩聚合替代 z 融合 | 现有融合把每个 epoch/seed 的分数逐日 z 后等权平均；而决策只用**序**。z 对分数分布尾部形状敏感，尾部形状随 epoch/seed 漂移，是纯粹的测量噪声。在高斯 copula + 各模型给出潜变量带噪估计的模型下，最优聚合是**逆正态秩（van der Waerden / normal scores）平均**，这是分布无关且对异常值稳健的充分统计量。无拟合参数，可直接在 test 上做 paired 检验。主变体 = normal-score 平均；稳健性变体 = 简单秩平均。重建 3 seed × best±1 = 9 个分数面，先验证 z 版能复现冻结参考。 |
| Z3 | 跨模型分歧度作不确定性惩罚 | 9 个分数面给出每周每票的**均值与标准差**；现有融合只用了均值，标准差（模型间分歧）被丢掉。在均值-方差/鲁棒效用下，选 Top-20 应按 `mean − λ·std`（λ 先验固定 =1，稳健性 0.5）而不是 mean，等价于避开"只有一两个模型看好"的噪声票。这与 §10/§11 的 Kelly 不同：那里用分数**幅度**（横截面 gap），这里用**跨模型时间/种子分歧**。无 test 拟合参数。 |

## 3. 训练实验（GPU，串行，1 seed=42 先筛）

派生纪律：从 `configs/abl2000_base.yaml`（= canonical 30 特征）**只改一处**，
跑前写明预期与 kill 条件；用 `run_monopen_arm.py` 同流程；val 选臂、test 确认。

| ID | 一处改动 | 数学/原理理由 | 先验预期与风险 |
| --- | --- | --- | --- |
| T1 | `extreme_frac: 0.2 → 0.10` | `extreme_score_loss` 给头尾各 116 只打 ±1，中间 60% 忽略；而真实决策是 Top-20（3.4%）/Bottom-10。监督支撑与决策支撑相差 6 倍：模型没有动机去排好"最好的 20 只"，只需把"前 116"和"后 116"分开。收缩支撑是对齐损失泛函与部署泛函（learning-to-rank 里的 target/decision mismatch）。 | 正：尾部判别更锐，Top-20 更准。负：有标签样本从 232/周降到 116/周，方差上升；§7-C2 警告"把技能推到截面中段"会伤书，但这里相反，是把技能推向更极端的尾部。 |
| T2 | `extreme_frac: 0.2 → 0.05` | 同上，更接近部署的 20/10；与 T1 构成**剂量响应**（§7-B2：非单调 = 噪声签名）。 | 若 0.2→0.10→0.05 单调改善才算机制证据；单点存活不算。 |
| T3 | `rankic_temperature: 0.05 → 0.20` | `_soft_rank` 用 sigmoid((s_i−s_j)/τ) 构造软秩；τ=0.05 时 Δs>0.2 即饱和，梯度几乎只来自分数相近的样本对。而部署要分开的是 Top-20 与其余 560 只（Δs≈2）。τ 从未被审视过；放宽到 0.20 让"远离决策边界但序错"的样本对保留梯度，是偏差-方差意义上的平滑带宽选择。 | 可能改善整体序，也可能只是把 RankIC 的权重有效放大（等价于调 `rankic_weight`），需要用 val 的 RankIC 与 Sharpe 一起判。 |
| T4 | 输入特征改为**逐周横截面逆正态秩**（新建 rank 缓存 + 仅改 `cache_path`） | `arrays()` 先按 2000-2017 全局 mu/sd 缩放并 clip ±8，再逐周 z-score clip ±6。逐周 z 只自适应一阶/二阶矩，**假设 26 年里特征分布形状不变**；价量特征重尾、A股 2000→2026 波动/流动性/涨跌停制度全变，clip 后的尾部被压平且随制度漂移。逐周 rank→Φ⁻¹ 是非参数、分布无关、自动适应当前截面的归一化（van der Waerden），数学上是"消除分布漂移"而非"增加信息"；市场级绝对水平仍由 6 个市场特征保留，不丢失状态信息。 | 正：OOS 更稳、更少极值伪信号。负：丢掉特征幅度信息、可能削弱"极端值"信号；需要重建缓存并核对未改动的其它列完全一致。 |

> **架构方向（Transformer）先不烧 GPU 的正式理由**：台账 §14/§20/§24 已把
> 特征轴注意力、非因果注意力、跨股票注意力、Mamba2、市场 FiLM、深度/宽度
> 全部实测为 KILL；§24 的 mamba2 同 seed 同配方书差 −1.0bps(t=−0.18)。
> 从原理上，周度个股收益的不可预测部分占绝大多数，容量不是瓶颈，
> 增加表达能力无法降低标签噪声（Cramér–Rao 意义上信息量由标签信噪比决定）。
> 因此本晚把 GPU 预算放在**目标函数 / 输入分布 / 集成测量**三处，
> 而不是再换一个编码器。若前三处全败，再考虑架构。

## 4. 判据（冻结）

- **主门**：候选纯多 Top-20 净超额 vs canonical 的**逐周 paired 差**，NW5 t ≥ 2.5。
- **稳定性门**：Sharpe ≥ 基线、MDD 不差于基线 −1pp、逐年 ≥4/6 年非负、val 同号。
- **复现门**：过主门才扩 seed 43/44；3 seed 融合后仍过才算"真"。
- **失败也报告**：所有臂的完整读数、val/test 双窗、剂量响应曲线。
- **不替换 baseline**，只给"候选 / 线索 / 否决"三档结论与部署路径建议。
