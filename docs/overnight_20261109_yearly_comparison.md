# 过夜实验：优于 baseline 但不显著的方法清单 + 统一逐年对比

> 全部由 `tmp_on2_yearly.py` 从审计级周度曲线重建。收益率 = 当年 `∏(1+r_weekly)−1`；Sharpe = `mean/std(ddof=1)×√52`。不同成本口径的 block 之间不可直接横向比数字。

**逐年周数（非完整年，勿当自然年化）**：2021 年 52 周、2022 年 46 周、2023 年 46 周、2024 年 49 周、2025 年 52 周、2026 年 38 周。2026 截至 10-09，只有 38 周；2022/2023 因长假周剔除各 46 周。

## 1. 判定口径

- 主门：配对净超额 NW5 t ≥ 2.5；
- 今晚最终多重比较门（P23, M=2000，独立随机流可复现）：val 3.826 / test 3.579 / vintage 3.708；
- 「优于」= 与**同成本/同窗口/同会计口径**的 baseline 配对净超额 > 0；
- 「不显著」= 未过上述门，或跨窗不同号 / bootstrap CI 跨零 / 属会计恒等式；
- P20/P24 训练臂只有 VAL 窗（test 按协议从未读取）；
- 纯描述性理论层（P6 尾部、P9 L0/L1 空头信号层、P10 A 全局理论空头）不是可交易策略、也没有配对检验，不计入清单。

共扫描 160 个配对格，其中 73 个为正；按方法族归并为 7 类。

### 2.2 收益维度不显著、但稳定性维度显著的另一类

K=40（P14/P15/P18/P19/P21/P22 的共同对象）在**收益**维度 test 配对 仅 +0.04bps / t=0.01（10bps 口径）或 +1.57bps / t=0.41（真实成本口径），属于「优于但不显著」；但它在**波动率**维度是今晚唯一可认证的改善：周 σ 降约 4%、下行 σ 降约 3%、换手降约 11%，test 逐年 6/6、Holm 校正 6/6。P21 复现门又显示 3 个单 seed 方向 3/3 为负但显著性仅 1/3，所以它的强度部分依赖 3seed 融合降噪。**定位是收益中性的候选风控变体，不是更高收益策略。**

### 2.3 展示性重算声明

`Top-40 / 真实成本 γ=1.0` 是已测方法在已测成本档的交叉展示（P22 只预注册了 γ∈{0, 0.5}，P12 测过 γ=1.0）。它不是新训练臂、不参与任何判决，仅为让逐年表在该口径下有对照行。

## 7. 结论

- 今晚没有任何方法在 test 窗产生**可认证**的更高收益；最好正向效应 +6.57bps/周 (t=1.14)，需 +16.6bps 才过多重比较门。
- 所有「优于但不显著」的读数都集中在 val 窗或高成本口径；val 的最佳 +37.38bps 在 test 缩到 +6.57bps（1/6），是幅度失真而非排序失真（P17b）。
- 逐年看，没有任何方法跨年稳定领先：在已冻结的搜索口径里，最好的 `P3 linear_up (Top20 递增权重)` 也只赢 4/6 年，K=40 类 3/6 年，P12 分数平滑 3/6 与 4/6 年；优势在年份间来回抵消，与 test 窗正向配对 t 最大仅 1.61（远低于主门 2.5）完全一致。分数平滑的 test 优势还高度集中在 2021 单年（γ=0.5 +12.4pp、γ=1.0 +17.8pp），其余年份基本被 2024/2025 的落后抵消。
- baseline 不替换。
