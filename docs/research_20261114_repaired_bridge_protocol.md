# 补录数据后的配对实验

2026-11-14，状态 registered，基于 data_trials_v1 和 standard_v1。原测试已在先前研究中暴露，本批测试是历史复检。

580只固定股票池与本轮4,238条BaoStock补录相交30条，其中28条早于2000-01-07快照起点；000729.SZ和000962.SZ在2000-01-26各1条进入本批。上海医药、上港集箱、北交所停牌证券均不在该池。修补只改变这两条行情，保持原证券池、标签逻辑、训练截止、费用和回放口径，修补输入和来源哈希由快照manifest登记。

两条缺失原价使用已核验的BaoStock原始数据，后复权价按截至前一交易日的Sina后复权收盘/原始收盘比缩放当日四价。复权比例来自2000-01-25，不读取1月26日以后的数据；预收盘和前日收盘差异为0.064%、0.107%，这一比例仅是近似，不应称为真实历史复权值。原始复权及二源的历史版本未存档，本批只能标为Q1 latest-history探索，无法证明严格PIT。若用户要求严格PIT的结果，必须先获得当日可用的行情与复权版本，不能把Q1结果冒充严格PIT。

验证快照物理截止2021-01-08，验证决策2018–2020；独立历史快照截止2026-11-03。构建器只用当日及以前历史计算特征，训练拟合截止2018-01-01，标签仅在收益成熟后有效。验证与历史前缀的周面板和市场输入逐项相同。旧与新快照标签完全相同；训练期输入和活动量拟合有变化，不复用旧checkpoint作为新数据训练结果。

冻结种子42、43、44各8轮的D3与D3_ZERO，另训练seed42的B0、CS、ADN，沿用原架构、损失、训练步骤。各模型各腿独立在完整153周验证上按扣费Sharpe选择最佳epoch，win3融合并锁定后评估2021-01-08起的全部297个成熟测试周。主口径单边10bp、年化借券8.35%，并保留已有压力测试；多头、空头、多空、换手、逐年、配对置信区间分开报告。原8轮旧数据模型保留在旧报告，与本批按相同模型和种子比较。三种子不是三段独立市场。

GPU任务串行，先跑三组seed42，再跑剩余种子并自动汇总；启动前冻结源码、配置、快照、回放和依赖文件哈希。每epoch保留优化器、EMA及随机状态。各seed选轮只读验证，禁止根据测试挑选种子、阈值或续训。原测试已暴露，结论仅用于探索。训练期间继续核对二源缺口；不改既有快照或旧报告。
