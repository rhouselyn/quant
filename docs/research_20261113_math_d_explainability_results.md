## 结论

**先给现有 CB 做可精确重构的评分分解，再用固定模型扰动检验其忠实性；没有必要为了画解释图重训网络。** 当前可解释的是同一模型的数值计算、哪些输入条件改变了分数，尚不能解释为“市场、行业、个股各贡献多少预期收益”，更不能视为因果效应。

CB可以直接给出“本模型自身项＋行业条件交互＋市场条件交互”。ADN的L2归一化使各条件耦合，不能照抄CB的线性分摊。最终多轮/多seed标准化融合也必须纳入解释链。B0不读取显式跨股神经关系，但原始特征的横截面标准化已经共享信息。

唯一优先建议是D0：冻结模型的解释审计。结构性可解释挑战者复用[A报告的完整40×30 ridge基线](research_20261113_math_a_statistics_results.md)，不新增第三个训练候选。是否采用更强加性约束应等简单对照结果；本轮不能声称已提升解释稳定性或收益。

## 1. 四种解释对象应分别验收

| 对象 | 可以回答 | 不能直接推出 |
| --- | --- | --- |
| 单checkpoint原始分数 s_it | 本股表示和条件支路各贡献多少score单位 | 预期收益、上涨概率、实际赚钱原因 |
| 融合后分数与相对名次 | 相对其他股票和入选边界，为何分数更高 | 固定某个绝对分数必然成交 |
| 最终组合与成交 | 评分、资格、持仓、现金及交易约束怎样决定目标/实成交权重 | 分数贡献可以按比例分摊真实收益 |
| 实现收益 | 持仓收益、费用及风险暴露的账本/统计归因 | 某特征对未来收益的经济因果效应 |

最后一项已有可复用入口：`scripts/eval_dataset_experiments.py:152,175` 的因子归因和滚动beta；`src/quant_mvp/dataset_ledger.py:213–219` 的NAV恒等校验。它们与当前周级执行代理并非自动同一账本，应先对齐来源、成本和日历；现有代码存在不等于本轮已执行归因。当前score由复合目标训练，并非校准收益参数，见[A](research_20261113_math_a_statistics_results.md)。

## 2. 从当前代码推导的精确分解

证据位置：`src/quant_mvp/hierarchy.py:331–350` 构造条件参数，`:452–467` 评分，`:472–504` 生成leave-one-out摘要。CB/ADN要求冻结零关系门，且与CS等分支互斥。配置身份见事实底稿。以下均是源码推导，不是文献关于A股收益的结论。

令 h_it∈R^128 为本股编码，x_it=LN(h_it)，z_it=n(x_it)，n(v)=v/max(||v||₂,ε)。c^I_it、c^M_it分别是其他有效同业、其他有效股票的128维均值，空集合按代码为0。参数U∈R^(8×128)、V=[V_I,V_M]∈R^(8×256)、α∈R^8，w∈R^128、b∈R。

### 2.1 CB：三项可以严格相加

    q_self = wᵀz+b
    q_ind  = Σ_k α_k (Uz)_k (V_I c^I)_k
    q_mkt  = Σ_k α_k (Uz)_k (V_M c^M)_k
    s      = q_self+q_ind+q_mkt

q_self是**同一个CB checkpoint**中条件项关闭时的自身分数，不是独立训练B0的预测；CB联合训练后主干权重可以不同。三个名称表示输入路径，行业成员也是市场集合的一部分，q_ind与q_mkt不是互斥的经济信息集合。

低秩分量可以重标度、重排及等价重参数化；单个k没有稳定经济名称。对固定h和有效双线性映射，可以比较行业/市场两组总贡献；跨seed应比较总贡献、输出差异和集合行为，不把“第3潜因子”强行一一对应。

固定预处理输入、h、mask和权重，只把c^I设0时，CB原始分数变化精确等于q_ind；c^M同理。这是**神经路径消融**，不是删除某个真实行业或干预市场的因果实验。零上下文可能偏离训练分布，必须与现实范围内的替换检验分开报告。

### 2.2 ADN及CS：先做整体差值，再约定交互分摊

ADN实际为

    s(c^I,c^M) = wᵀ n(x ⊙ [1+A(V_I c^I+V_M c^M)])+b.

L2分母同时依赖两个上下文，不能将scale投影的逐维乘积当成可加score贡献。固定h，定义s00=s(0,0)、s10=s(c^I,0)、s01=s(0,c^M)、s11=s(c^I,c^M)，得到精确恒等式：

    s11 = s00 + (s10-s00) + (s01-s00) + I
    I = s11-s10-s01+s00.

最透明的报告保留四项：自身、单独行业、单独市场、交互余项。若界面必须只显示三项，可按两种加入顺序平均，把I各分一半：

    φ_I = 0.5[(s10-s00)+(s11-s01)]
    φ_M = 0.5[(s01-s00)+(s11-s10)]
    s11 = s00+φ_I+φ_M.

这是已明示的分摊约定，不是唯一自然的行业/市场贡献。CS也在LN/L2前混合上下文，适用同类四状态差值方法。对SELF只能称自身条件非线性，不能把重复的两半命名为行业/市场。

统一正比例缩放会被L2抵消，因此“条件scale幅度很大”并不保证对score有大影响。报告应优先显示实际分数差和排序边界变化。

### 2.3 融合阶段必须继续保持恒等式

当前 `scripts/eval_weekly_architecture.py:32–58` 每epoch截面z、平均、再次z，seed平均后再z；`evaluate_dataset_three_year.py:283,302` 调用该路径。设某一标准化前s_i=Σ_a q_ia，使用相同有效股票集合，则逐项定义

    q'_ia = (q_ia - mean_i(q_ia)) / (std_i(s_i)+ε).

有Σ_a q'_ia=z(s_i)。**分母必须是总分数的同一个标准差，不能各贡献分别z标准化。** 在每个epoch完成此步，按原权重平均，再对所有项按新总分数重复同一转换；seed阶段亦然。使用同样NaN/mask和ddof=0，保存每层均值、标准差及权重，才能重构最终分数。常数偏置会在截面居中消去。

这种分解解释固定观测横截面的融合值；消融后的总分数分布会变化，反事实融合须重新走原标准化链，不能用原贡献直接代替反事实名次。

## 3. 单股解释输出样例（全部为示意数值）

标识必须包括日期、股票、模型/epoch、checkpoint哈希、候选mask、原始或融合分数单位，以及解释基准。以下只说明表格格式，不是真实股票或实验读数。

| 同一CB checkpoint，股票示例甲 | 原始score贡献 |
| --- | ---: |
| 本模型自身项 | +0.60 |
| 行业条件交互 | +0.25 |
| 市场条件交互 | −0.05 |
| 合计 | +0.80 |
| 重构残差 | 0.00（示意精确算术） |

解释文本：“固定该模型自身表示，行业条件路径使原始分数增加0.25，市场条件路径减少0.05。去行业条件后的分数为0.55。它们是模型计算贡献，不是收益百分点。”

如另一候选原始分数0.74，两者分差0.06可由两股对应贡献之差重构。真正的Top20边界解释必须读取完整候选集合及执行规则，分别报告原始名次、融合名次、相对第20/21名的margin、资格/成交阻碍及最终权重，不能从上表推断“必然买入”。

## 4. 特征解释方法的选择与限制

| 方法 | 本项目适用方式 | 主要限制 |
| --- | --- | --- |
| CB结构分解 | 首选，零新参数且直接覆盖条件支路 | 潜表示不具天然经济语义，不解释所有原始特征 |
| ridge逐项贡献 | 后续A候选用β_jl X_ijl按特征/滞后求和 | 相关特征可互相替代，系数稳定性仍待检验 |
| Integrated Gradients（IG） | 第二阶段解释固定模型score相对预注册参考输入的变化 | 基准、路径、数值积分及分布外样本会改变解释 |
| 相关特征分组替换 | 对收益/动量、波动、量价等预定义组做现实范围扰动 | 单项遮零会破坏特征间关系，替换本身不是经济干预 |
| 加性网络/概念瓶颈 | 需要结构约束时另注册；本轮不新增候选 | 前者牺牲交互，后者缺已验证概念标签，不能只给潜变量命名 |
| 注意力图或代理模型 | 可作探索显示，附输出忠实度检验 | attention非完整计算路径，代理模型只是近似原模型 |

IG对标量F(X)和参考X⁰定义A_j=(X_j−X⁰_j)∫₀¹ ∂F(X⁰+u(X−X⁰))/∂X_j du。在满足积分条件时Σ_j A_j=F(X)−F(X⁰)。这提供重构检查，但不证明经济因果或唯一正确基准；该论文也指出扰动可能产生不自然样本。原始出处：[Sundararajan等，ICML 2017](https://proceedings.mlr.press/v70/sundararajan17a/sundararajan17a.pdf)。

对B0，给定标准化X后可以只解释本股40×30输入；若声称解释原始行情，必须纳入前处理。`hierarchy_data.py:150–176` 使用训练缩放、当周横截面统计、截断和历史携带；改变别股原始数值可能改变本股输入。当前NumPy前处理不会自动包含在torch梯度里。原始行情扰动应使用登记的历史参考、重算相关派生特征和横截面处理；固定mask的数值敏感性与改变交易资格的系统情景分开统计。

注意力是否有解释价值须用完整模型检验，不能直接视为因果贡献。Jain与Wallace在NLP任务发现注意力与其他重要性度量不一致；Wiegreffe与Pinter指出结论依赖解释定义并提出完整模型检验。这些是方法警示，非本项目Attention已失效的证据。[NAACL原论文](https://aclanthology.org/N19-1357/)、[EMNLP回应论文](https://aclanthology.org/D19-1002/)。

## 5. D0：冻结模型解释审计的验收设计（planned）

保持现状对照是原模型原分数；解释导出必须不改变预测。不新增训练候选、不重选epoch。先对锁定验证集的既有CB窗口做结构解释，ADN仅作已登记的非线性差值附读；历史测试不用于选择解释方法或参考基准。

| 检验 | 具体做法与完成/失败标准 |
| --- | --- |
| 恒等重构 | eval、相同mask下原score、融合score分别与贡献和比较。建议FP32容差abs≤1e−6+1e−5·|score|；逐项记录最大误差。任一超界先查实现，不能发布完整解释主张 |
| 反事实一致 | CB固定h去条件的真实输出差与q_ind/q_mkt相符；ADN四状态恒等式闭合；只检验计算，不把零条件的结果作收益结论 |
| 失活与mask | 冻结零门的关系路径贡献为0；无效股票不进入摘要；单例行业均值为0；置换股票及身份后贡献同步置换 |
| 排序忠实 | 对预先确定的全部Top20边界股票，报告扰动前后margin、入选集合变化；不只挑有说服力个案 |
| 真实范围扰动 | 用训练期冻结参考、按相关特征组替换；记录被裁剪率、相对训练支持的距离，单独报告超出支持的样本。扰动效果须和同幅度随机组对照 |
| IG数值与基准 | 若第二阶段启用，冻结一组训练期参考，积分步数增加后检查残差收敛；保留有符号贡献及基准差异，不只画绝对值热图 |
| 模型依赖 | 固定输入，对内存中随机化head/编码层的诊断副本比较解释与输出变化；不修改原权重文件。若解释完全不随预测函数变化，否决其“模型特异解释”用途 |
| 稳定性 | 按锁内epoch、可用匹配seed和预登记年份/股票分组报告功能总贡献、margin及符号稳定性；当前Q1条件臂只有seed42，不虚构跨seed验证 |

模型随机化检验借鉴[Adebayo等原论文](https://arxiv.org/abs/1810.03292)，本项目只迁移检验思想，不假设图像研究的效果数值适用A股。随机标签重训检验超出本次不训练边界，明确不安排。

对跨时期变化，应同时观察输入分布和预测变化：不同市场状态下贡献改变不必然说明解释失效。稳定性数值只作描述，只有恒等、mask及逻辑负对照先作为硬门；若未来要按稳定性筛选模型，必须预先冻结容许阈值和选择规则，而不是看完图再定。
