## 1. 目标、边界与阅读路线

目标是建立可以按日期、证券、市场板块和数据类型复用的历史数据仓库，并检验数据改进是否提高扣费后的投资收益。数据工程成功不以回测收益上升为条件；纠正偏差后收益下降也是有效结果。

本轮未来执行范围：

1. 归档沪、深、北交易所 A 股的可得历史，包含退市、暂停上市、风险警示、改名和换码证券。先完整覆盖日线及其解释所需元数据，再补财务、行业和借券数据。
2. 将原始事实、时点解释、训练样本、执行账本分开，建立版本、查询、增量下载和自动质量验收。
3. 在当前 B0 / CS 架构上依次测试股票池、清洗、时效、采样、增强和辅助标签；用少量可证伪实验决定是否扩大。
4. 分开评价多头、空头、同多头加现金、多空组合；开展分腿选轮，以及预测下一周两腿相对收益、动态调整多空配比的独立比较（AL1，§8.3）。
5. 数据和收益候选通过门槛后，测试横截面、时间和模型规模的学习曲线；允许得到“不支持 scaling law”的结论。

“所有范围”定义为供应商合法可得的**每个数据集的完整可得历史**，不是承诺获得不存在或未授权的逐笔、盘口、历史券商库存。日线从各证券最早可得日期归档；2000 年以前数据也保留，但主训练起点暂保持 2000 年，以隔离扩大历史的影响。北交所和早期板块没有的数据不补造。

### 2.3 四个优先问题

1. 当前 580 股及行业属于当前快照回溯。扩到当前 5,000 多股仍不能消除幸存者偏差。
2. 后复权不等于拥有历史数据版本；财务报告期加法定滞后不等于真实公告 PIT。当前 30 特征没有财务列，这不是当前模型已使用财务未来信息的证据。
3. 现有评价器仍有受阻退出按周收盘代理；训练标签与修正后的交易日历可能不一致。正确性修正应同时应用于所有对照。
4. 2018–2020 已用于开发，2021–2026 已反复查看。重新切折、换股票或换随机种子不会恢复独立测试资格。

## 3. “好数据集”的验收标准

质量、研究可用性、收益增量分别验收。质量通过而策略亏损时，保留数据，否决策略。

| 维度 | 必须交付的证据与阈值 |
| --- | --- |
| 身份完整 | 官方/供应商上市、退市和换码名录联合，逐证券登记起止、状态和缺口；归档名录中的 100% 证券都有成功、空范围、权限不足或失败记录 |
| 覆盖诚实 | 按年份×市场×板块×状态列预期/实得交易日，区别停牌、休市、未上市和缺失；严格发布池内未解释缺失为 0，归档有缺口就标 incomplete |
| 时间正确 | 每条特征的 available_at 不晚于 decision_at；训练 label_available_at < fit_cutoff，选轮 label_available_at < selection_at；未来扰动和截断重建测试通过 |
| 历史版本 | 原始响应与规范化表内容哈希、来源、参数、抓取时间、schema 版本可追溯；历史修订新增版本，旧快照重放不变 |
| 价格及权益 | 交易用未复权价格；复权/总收益用于信号并有事件解释；分红、拆合股、配股、退市、代码迁移有样例账本 |
| 数据一致 | 活跃非异常样本无重复主键，无负成交量/额，无非法 OHLC；异常隔离后给原因，不靠删极端收益提高表现 |
| 缺失语义 | input_observed、scoreable、label_valid、order_fillable、held 分开；缺失收益不得自动等于 0；停牌仍可估值但不能虚构成交 |
| 可复现 | snapshot_id + recipe + code_hash + split_hash 可重建相同样本、成员次序和标签；无需网络即可完成一次训练与验收 |
| 查询可用 | 日期/代码/类型/板块/历史成员/as-of 查询一致；在固定硬件记录冷/热 p50/p95 和内存，目标见第 4 节 |
| 可扩展 | 全市场常用快照不发生内存换页/爆显存；时间、股票和有效监督量可分别统计 |
| 外推能力 | 至少分别报告旧 580、历史全池、退市股、新上市股、板块、年份和流动性分组；不给一个整体指标掩盖缺口 |
| 经济价值 | 同预算净 CAGR、累计收益、回撤、换手、容量和分腿现金增量；同时报告因子暴露，不能只报 IC |

上述 0 缺口要求针对**声称已发布且适合严格研究的范围**。无法取得早期退市行情时，仍完成归档审计，但不能把“供应商没有”变成“这只股票不存在”，也不能声称完成无幸存偏差全市场回测。

数据等级：

- Q0：有 provenance 的原始档案，可以不完整。
- Q1：重建历史行情与公司行动；交易状态清楚，修订历史未知的列有标志。
- Q2：用于模型的全部信息具有可验证的历史可用时点；研究快照通过所有时序和覆盖门。
- Q3：在 Q2 基础上有足够真实执行信息，包括券源/报价/数量/费率，能完成对应策略的执行验收。

价格重建可进入 Q1 的探索；没有财报版本证明的财务不进入 Q2。券源代理可以用于研究空腿，但不能把整个多空策略标 Q3。

### 4.1 首次下载的优先级

| P2 | 分钟、竞价、资金流、公告文本及额外另类数据 | 建 capability 清单；只有已有权限且明确实验需要时排队 |

来源优先次序和接口见 [来源研究](research_20261113_dataset_sources.md)。首版确定性选择规则：已有 Tushare 对应授权且哨兵通过时，优先用其结构化接口；否则先验收既有 AKShare 源，以 BaoStock 及交易所资料补核。无论选择哪一路，都不能默认其退市/北交所/历史版本完整；失败范围继续登记。跨源补充按字段和日期保留 provenance，并重新通过单位/复权一致性门。不要直接运行旧 download_full_universe.py 当“下载全部 A 股”：其默认名单是本地 1893 股，来源为 Yahoo，起点和结束时间固定，缓存只看最后日期。

步骤及完成条件：

1. 建 capabilities.json，记录每个接口的历史起点、市场、退市覆盖、频率、版本语义、额度、授权和实测状态。未知就是 unknown。
2. 合并名录并保留来源差集；先完成 ID 映射。以 date×venue 的预期证券名单核对，不能只数总股数。
3. 先取 30 只固定哨兵的小批次：三个交易所、不同上市年代、退市、换码、停牌、分红、拆股、ST、恢复交易；至少覆盖这些事件。记录每请求耗时、行数和压缩字节。
4. 下载任务按 dataset×security_id×年月/年拆分，分页保存游标。并发初始 2，按官方额度降速，429/限额遵守 Retry-After；指数退避加抖动、最多 5 次，然后记 FAILED 可续跑。
5. 哨兵通过后扩展历史全集。优先完成“旧 580 完整新口径”的桥接快照，再完成沪深核心全池，北交所及资料较弱区段并行归档；它们只能在自身质量门通过后参与实验。
6. 每个请求先写 .partial，校验再原子发布。空响应与断网不能标完成。达到最新日期不代表中间和最早历史完整。
7. 对照第二来源抽查：固定哨兵全部事件、每市场/年份固定哈希抽样 1% 日线；价格差超过一个实际最小报价单位或量额超容差，逐类解释。容差按源单位契约规定，不写一个跨单位常数。
8. 出覆盖账、失败清单、源差异和 release manifest。即使某源不可用，也可发布明确范围的子快照；全集状态保持 incomplete。

增量更新：每个交易日完成后补新记录并回看最近 20 个交易日，月度复核公司行动及关键主表。回看长度是成本默认值，不保证捕获更早修订；供应商提供修订日志则据此补扫，否则定期抽查旧区间并在版本限制里说明。更新永远生成新 snapshot。

## 5. 时点、标签、清洗与交易的统一契约

### 5.1 时间不是一个 date 字段

每类事实至少分清 event_at / effective_from / available_at / recorded_at；有修订时加 revision_id。available_at 是市场参与者首次能用该版本的时刻，recorded_at 是本仓库取得它的时刻。今天下载的历史公告不因 recorded_at=今天就失去历史用途，但只有最新修订值且未知其版本时不能伪装成当时已知。

决策默认安排在交易周结束且所需数据已到齐的时间；首版规划为周五 18:00 Asia/Shanghai，须由源实际延迟验证。兼容键 anchor_week 仍可用 W-FRI 桶，last_observed_session 保存实际最后会话；两者都不代替 decision_at。晚到的数据使该字段本周不可用或本次决策顺延，不能把“日线日期为周五”当作 15:00 已可见。订单在下一个可交易会话处理；整市休市周不产生新股票排序，已有持仓继续记账。半周和个股停牌由日历显式解释。

训练样本保存：

~~~text
decision_at, security_id, input_start_at, feature_available_at,
entry_scheduled_at, exit_scheduled_at,
label_end_at, label_available_at, supervised_valid,
input_observed, scoreable, membership_at_decision,
label_kind, censor_reason, snapshot_id
~~~

严格条件：feature_available_at ≤ decision_at；训练 label_available_at < fit_cutoff；选轮 label_available_at < selection_at（冻结模型/轮窗的时刻，严格早于首个外层下单）。例如 F0 拟合截止 2018-01-01，选轮在 2020 首个外层决策前完成；不能拿拟合截止过滤整个内层标签。五周 InfoNCE、H2 等辅助目标也保存各自结束时刻，并分别 purge，不能只给主标签减两周。训练内部未来标签可以作为监督目标，绝不能进入该时刻输入、候选池或归一化。

### 5.2 标签与执行账本各司其职

主排序标签先定义为计划入场会话到计划退出会话的、公司行动一致的总收益 log1p；全部计划日期用交易日历生成。无报价或未到成熟时刻的标签不能随意落到周收盘。保留 censored 标签和理由，报告其与退市/停牌/未来亏损的关系。

监督的 valid 只控制可算的损失；候选池与订单只取 decision_at 已知事实。正常停牌可以没有某段监督标签，但其历史存在、持仓及最终损失不能从投资账本消失。到研究末端仍无法定价的持仓列明悬而未决；保守估值/回收率敏感性单列，不能用未来清算结果回写更早的已知状态。

执行账本使用 raw 价格、真实股数、现金、分红应收、借券负债：

- 受阻卖出/回补保持仓位，下一会话再试；资金没有释放前不假设可以买满新股。
- 开盘涨跌停是否成交用该日正式参考价、限价、交易状态及保守撮合规则；日线 OHLC 本身不证明竞价成交。
- 根据开盘结果补位的订单只能在可实施的后续时间成交，不能所有替补都事后拿同一个开盘价。
- 个股除息、拆合股、配股、换码、终止上市按事件更新数量/现金/应收；现金分红除息确认权益、到账日才可再次使用。
- 交易费、税、过户费等按实际生效日；券费按真实经过日数和可得报价。保留 10/30 bp 总费用敏感性时说明是否已含税，避免重复扣费。
- 建真实数量约束时按证券/板块/时段交易单位，而不是永远 lot=100。历史代理继续保留，但与严格执行结果分栏。

### 5.3 清洗规则

原始行情永不 winsorize。先识别单位、公司行动、数据错误；每次隔离保存原值、原因、规则版本和影响股票周数。对退市前暴跌、涨跌停和真实极端收益不删不平滑。

输入层可以比较稳健标准化，收益层始终用原始可执行结果。暖机不足、停牌、供应商缺数、财务未披露用不同缺失类型；允许过去特征有限前填，输出 age/staleness；严禁前向填价格以制造交易。当前对所有 30 列完整性的要求也要记录覆盖代价，不能默认它最合理。

持仓估值和新开仓资格分离。基本准入：当日已上市、证券类别为 A 股、基础元数据可信；默认新开仓再要求上市 120 个实际交易会话、当期未停牌/未处于预先定义风险警示状态、过去 20 会话至少 15 个有效量额观测。120/15 是首版工程假设，另做明确消融；退市、ST 数据仍归档并计入已有持仓。ADV/容量门由账户规模决定，不从未来整段均值筛选。

## 7. 时间切分、选轮和测试纪律

### 7.1 开发与历史复验

首轮沿用 2000–2017 训练，2018–2019 为内部选轮，2020 为首筛。它们统称**已暴露开发历史**。先以固定三轮窗比较机制；完整算法才使用内部窗口选择。

| 折 | 拟合数据截止 | 内部选轮 | 外层历史回放 | 说明 |
| --- | --- | --- | --- | --- |
| F0 | 2018-01-01 前已成熟目标 | 2018–2019 | 2020 | 首轮全部候选；空腿主覆盖很短，固定轮窗 |
| F1 | 2019-01-01 前已成熟目标 | 2019–2020 | 2021–2023 | 仅晋级候选与匹配基线 |
| F2 | 2022-01-01 前已成熟目标 | 2022–2023 | 2024–冻结数据末日 | 仅晋级候选与匹配基线 |

每折日期按真实会话和标签成熟生成，表中不是可直接代入索引的 train_end。拟合预处理只用拟合段，选轮只用其当时已成熟内层标签，外层只在规则和 checkpoint 锁定后读取。外层之间非独立，全部属于事后历史回放，不能把三折当三次独立证明。缺少早期券源数据的折，其空头结果为 NA 或指定单市场诊断，不将未知资格当可借。

首轮数据缺口可以使可用起点晚于 2000；必须在同可用区间重训匹配对照，并另报覆盖损失，不把不同起点的收益直接相减。

真正前瞻从**最终协议签名后的首个决策时刻**开始，不预设从 2026-10-24 起的未下载数据就是未看过的测试。记录研究者/脚本已接触的数据范围。先做 26 个成熟决策周的影子运行作为运营证据；时间仍短，不据此宣称长期稳定。到冻结验收日统一读主比较，日常只检查运行与数据正确性；必要修复产生新版本和新的观察起点。

### 7.2 多空独立选轮

对每个 seed 缓存 1–8 轮的逐周分数，一次推理后完成以下 CPU 比较：

1. 固定窗参考：B0 用历史登记窗，CS 用 [4,5,6]。
2. 共用选择目标：B0、CS 各自按自己的纯多净 Sharpe 选连续三轮窗，分别得到窗口。这里共享的是指标，不是把 B0 选出的窗口强行给 CS。
3. 分腿算法：多头按纯多净 Sharpe，空头按纯空扣券费净 Sharpe，分别直接比较 [1,2,3] 至 [6,7,8] 的**融合分数**。

三者种子、日期、成本、持仓规则相同。完整顺序：每个 seed 的每个候选窗，先逐 epoch 截面标准化、轮内均值并重标准化，生成内层净账本；根据指定腿的效用在六窗中选一个并锁定；最后才将已选的三个 seed 分数等权融合。候选和父对照都运行同一种算法，不能只给候选挑轮。

内部合格周不足 80 或仅单市场覆盖时，不优化该腿轮窗，回退预登记固定窗并说明证据不足。80 是防止在极短样本大范围选择的工程下限，不是显著性保证。并列 Sharpe（数值容差 1e-8）取换手低者，再取较早窗。不得看外层后换目标、选单轮或另挑 8.35% 之外最有利费率。

额外只换多轮窗、只换空轮窗的 2×2 归因可以做，不增加训练。将“空腿选得更好”和“相对同多头加现金仍然赚钱”分开报告。

## 8. 数据实验矩阵

### 8.1 对照及顺序

S4 先得到 BQ：同旧 580 在新正确性契约上的 B0/CS；BU：历史时点新股池、30 特征、自然 40 周覆盖的新 B0/CS。旧 matched_lookbacks=[20,40,80] 是窗口消融留下的共同掩码，不应悄悄继承为永久数据筛选。桥接保留旧共同掩码另报；主 BU 使用 min_history_weeks=32/40，训练起点依据实际日期生成。

正确性修正（代码身份、成熟时间、权益、会计）不是可选择的 alpha 因子；先同时应用对照和候选。以下“新数据变化”逐一相对 BU，首筛用同样训练种子/预算：

| ID / 优先级 | 假说、具体改动 | 对照与验收重点 |
| --- | --- | --- |
| D1 / 必做 | 历史全池替代当前快照；包含退市与新上市，时点资格筛选 | BQ vs BU；同时在旧 580 共同评估池与各自自然池报告，区分训练增量与投资机会增量 |
| D2 / 高 | 按当期可见截面 median / MAD 标准化、clip±6，替代训练 pooled clip±8→截面 z | 同原始数据、特征、监督 mask；重尾稳健性、尾股收益和覆盖变化 |
| D3 / 高 | 缺失类型+staleness：保留基础价量可用样本，财务缺失走 mask；新增少量缺失指示 | 先仅改变输入表示，再单独放宽 eligibility；同容量零/随机 mask 控制，不能多做两件事 |
| D4 / 中 | 时间再权重：按训练末日过去 5 年半衰期赋权，逐周 loss 归一 | 对比原全历史均匀；再和最后 10 年硬窗口对比；这是三种训练分布，不混称更多数据 |
| D5 / 中 | 按市场/行业/流动性分层训练采样；固定有效周数，层权重 cap=3，floor=0.2 | 复用 cell_sample_weights；报告改变后的目标分布、微盘暴露、成交容量，不按未来表现挑难例 |
| D6 / 中 | 按 PIT 财务构造盈利增长、经营现金流收益率等最小组；1 组 2 个特征起步 | 对比 BU+同维噪声；报告公告后滞后 1/5 会话敏感性，严格 PIT 不够就不训练 |
| A1 / 高 | 每个训练股票窗口以 p=0.2 选中，将一个特征组连续 1–4 周遮蔽为标准化 0，保护最后 2 周；记录实际遮蔽比例 | 标签不变；推理不增强；同训练步数，对照原 dropout；实现见附录 |
| A2 / 条件 | 使用更广历史股票上的无标签历史窗口预训练，再回到同一个主任务 | 复用现有 temporal InfoNCE，不使用验证/外层未来窗；随机初始化与等 FLOPs 继续训练控制 |
| T1 / 条件 | 市场/风格残差收益训练标签，原收益评价；raw 与 residual 两头权重 1:0.2 | 先做 CPU 线性探针；不能将中性化后的评价当真实总收益，标签实现见第 9 节 |
| T2 / 条件 | H2 辅助标签在新日历/权益规则上重构，权重 0.2 | 只在 H1 主头有稳定基线后重开；H2 未来信息只用于监督，交易时点单列 |
| AL1 / 高，低成本复验 | 冻结 B0 多头与 CS 空头候选，mean-pool BCE 预测下一周哪条腿的净收益更高；多头预算只取 45%/55%，空头为余下部分 | 静态 45/55、50/50、55/45、60/40；内部固定平均暴露、延迟信号对照；只训小头，不联训选股主干，详见§8.3 |

不同时打开所有臂。第一波训练最多 D2、D3、A1 三项；D1 是基线建设必须做，D4/D5 先 CPU 探针和分布诊断，再择一补充；D6 取决于公告版本。另登记 A0：仅将已有 temporal_weight 从 0.1 改为 0，保持相同日期/监督覆盖，用一个 seed 判断新增强是否有必要依赖现有 InfoNCE。A0 归入机制预算，追加前先完成第一波。A2/T1/T2 和 scaling 属有条件后续。

AL1属于独立的组合层 CPU 小头预算，不挤占上述三个数据臂；正确性门和自身数据成熟门通过后就执行，不必等数据臂产生收益赢家。首版只比较普通BCE与第10步冻结投影两种既有配方；不扩到RL、连续自由配比或重新联合优化选股。

负对照：随机打乱**训练日期块的标签归属**（保留横截面共同结构）、增加同维独立噪声特征、只增加训练重复次数。它们诊断优化/容量/捷径，不应成为每个臂都跑三种子的巨大网格。先一个固定 seed；若无信息标签模型也持续高额超额，停止晋级并查泄漏/基准暴露。

### 8.2 首筛、复验与增量

- 首筛不是最终显著性裁决：数据门通过、同费用净平均周收益和 CAGR 至少一项提高，另一项不出现明显恶化，主档回撤不比父项恶化超过 2 个百分点，压力费率下候选相对父项净差不为负，即可列为最多 2 个补种子候选。固定主比较 L20；空腿使用对固定多头加现金的增量。小正数加宽区间标“待证”，不自动放弃也不宣布成功。
- 若无候选过此预算门，可选一个成本/容量显著改善且收益损失在预登记容忍范围内的工程候选；修改容忍范围必须在看结果前登记，不能临时放宽。
- seed43/44 复验保留全部单 seed 与固定等权融合；两个以上单 seed 方向相反时列出原因，避免只报融合。
- 至多两个成功候选 A、B 做父项、A、B、A+B 四格；增量相对更强父项验收。重复机制、同一覆盖筛选的收益不可简单相加。
- 每轮新增组合最多 2 个；一次历史外层读取后再产生的后续组合登记为新开发版本，不把同一外层再当确认。
- 若提升只来自微盘、某板块、单年或一个大事件，报告浓度与成本敏感性；保留“未确认”而不是强行 KEEP/KILL。

这些门是限制计算和回撤的工程政策，不是证明 alpha 的统计定理。最终报告完整效应与区间，允许推翻任何旧经验。

### 8.3 AL1：预测下一周多空相对收益，调整两腿预算

**值得接入，但仍是待检验的择时机制。** 旧 v3 篮子上，历史 295 周、10 bp/8% 券费时，第10步冻结投影的旧 BCE 信号用45/55窄档，比50/50多3.99 bp/周；比静态55/45多2.38 bp/周，区间[−0.70,+6.45]。信号来自另一套候选，2020验证仅38周且几乎总选高多头档，因此没有证明“下一周预测”本身有效。来源：[旧配比实验](research_20261113_followup_execution_results.md#分腿选轮配比与-w60)、scripts/followup_combo_controls.py::compare_allocations。旧40/70宽档先不重开。

**固定什么：** 每周仍由同一个冻结的B0/CS父策略决定多空股票名单、腿内等权、排重及借券资格；AL1只改变名义预算。高档多55%/空45%，低档多45%/空55%，总目标敞口始终为1。未成交或借不到的预算留现金，不额外补成更高另一腿仓位。权重在原周频决策时刻冻结，执行按同一日账本；配比调整造成的额外换手必须扣费。

**预测什么：** 目标为下一计划持有周的单位预算收益差 g_t=R_long,t−R_short,t，空腿收益已经包含卖空方向及券费，不能再取负一次。BCE拟合 P(g_t>0 | 决策时信息)，正logit取高档，负logit取低档，恰好零或信号缺失回50/50。它是两档预算规则，不宣称分类概率等于数学最优配比。单位腿标签只作监督代理；真实资本约束、残单和配比变化的费用由完整账本验收，不能只用两腿收益线性相加代替回放。

**训练与时间隔离：**

1. 先复用S5的F0架构：主干拟合至2017年末，轮窗只用2018–2019成熟标签冻结；空腿资料不足按§7.2固定窗。所有主干、轮窗、预处理必须在配比训练样本起点之前冻结。不得把用2018–2020甚至2023选出的主干分数当作2020配比训练时已知的信号。
2. AL1采用专用顺序：两市覆盖允许时，以2020–2022的成熟周拟合小头，2023作小头checkpoint选择，2024至数据冻结日作已读历史复检。实际起点为冻结父模型和两市合格数据均就绪后的首周；训练标签须早于2023-01-01成熟，选轮标签须早于2024-01-01成熟。每步同时检查真实时间戳。此分支不冒用F0/F1/F2的独立验证标签。
3. 输入使用父模型冻结表示与当时已知的篮子，不能含该周未来收益、未来成交率/实际券费或按未来标签筛出的股票。相同主干可处理2020以后样本，是因为这些周未参与其拟合或选轮。以后更换主干vintage需重新建立此顺序，或另做严格按时间产生的样本外表示，不能直接拿主干训练内表示训练配比头。
4. 小头训练至少104个合格成熟周、选择至少40周且两类训练标签各≥10；数量是预算下限，不是统计保证。不满足则标INCOMPLETE，仍可完成静态/旧信号的描述重放，不能用未来数据补成早期训练集。缺输入周回50/50并保留日期；标签未成熟只影响训练损失，不能提前移除交易周。
5. 复用mean-pool BCE、Adam lr=0.001、weight_decay=0.01、100个full-batch更新；主候选在第10步后冻结投影，与全程训练的小头作机制对照。按2023内层BCE最低选step，三seed42/43/44只用于小头优化随机性；组合权重规则事前固定，不再扫阈值和宽档。具体输入与代码见实施规格§6.5。

**必须比较：** 静态多头权重0.45/0.50/0.55/0.60；主候选freeze10；普通BCE；将2023内层预测的平均多头权重冻结到外层的常量配置；上一决策周logit延迟一周使用。静态主对照从上述常量中仅按内层净Sharpe选出并锁定，全部静态结果仍公开。外层真实平均权重匹配仅作事后beta归因，不作为可部署基准或用来选规则。

**验收：** 主档10 bp/8.35%及30 bp/8.35%、30 bp/12%压力档，对50/50和内层选定的静态配置逐周配对；同时公开Brier/BCE、类别基率、两档使用比例、gross/net CAGR、回撤、换手、借券费用及滚动市场beta。相对静态主对照有正净均值/CAGR、回撤恶化≤2个百分点、压力档未反转，才有追加/影子观察理由；区间跨零保留SHADOW/待证，不能称已确认。若只胜50/50却不胜静态偏多，记录为平均暴露效应；若预测指标好而净收益不提高，停止升级。报告独立父策略与配比变化的影响，不把改变多腿预算后的“对现金增量”全算作空腿alpha。

完成G_CAUSAL、G_LEDGER、父模型时间锁及AL1成熟覆盖检查后，可在D2/A1训练期间，用CPU构建篮子标签和拟合小头；缺表示时只提交一次冻结模型导出GPU任务，然后缓存复用。先seed42 smoke，再补两seed和两配方；耗时先实测，不为此重训整套主干。AL1成功后才追加“数据赢家×配比”的2×2增量比较，沿用新的内层选择与前瞻纪律。

## 9. 收益、alpha / beta 与统计

主目标是同资本、同会话、同执行规则下的净财富增长。报告累计收益和按实际经过天数计算的 CAGR；周度收益只从连续每日 NAV 聚合，休市/停牌不删掉资本时间。年化波动/Sharpe 需要明确日/周频与现金收益口径。

每个臂必须有：

1. L20 纯多、S10 纯空、50/50 多空、同多头+50%现金；资金规模先用 100 万元、另报 1,000 万元敏感性，都是容量假设。
2. 固定预算下的 gross/net、交易费、借券费、现金收益、最大回撤、最差年、换手、成交率、残单天数、容量占比。空腿归因用逐笔相同的已实现多头路径与资本预算，核对多头订单/成交/hash；真实联合资金账本另报。如果保证金、残单或排重改变多腿，差值包含长腿执行影响，不能全称空腿 alpha。
3. 同历史可投资池等权基准、宽基可投资代理、行业×规模×流动性匹配组合、简单动量/反转及线性 Ridge 基准。所有基准成员、费用和再平衡时点也必须因果。
4. 同周配对净差和区间；bootstrap 重抽完整周度向量，块长 8 为主、4/13 为敏感性，5,000 次；不把股票行或多个 seed 当独立市场样本。采用连续账本解决旧方法遇休市删周后的抽样问题。
5. 试验族账本：所有已尝试 ID、选轮次数、未晋级/失败/事后改动；多重比较诊断仅作补充，不用 DSR/PBO 自动认证。

风险归因：

~~~text
r_portfolio,t - r_cash,t
  = alpha + beta_market * f_market,t
          + beta_size * f_size,t + beta_value * f_value,t
          + beta_momentum * f_momentum,t + beta_liquidity * f_liquidity,t
          + industry exposures + epsilon_t
~~~

先验证因子来源与时点可用性；缺少可靠价值因子时报告受限模型，不能补一个未来财务因子。全评价段回归可用于事后解释；预测和真实对冲使用的 beta 必须仅用 t 前数据估计，例如过去 104 周、最少 52 周。明确“模型条件 alpha”依赖选定风险模型，不能证明不可解释的因果收益。中国市场因子不能简单机械照搬美国设定；[Liu、Stambaugh、Yuan 的中国规模与价值研究](https://www.nber.org/papers/w24458)说明本地因子构造会改变异常解释，本轮只借此要求多种合理基准。

T1 标签：先用 t 之前的历史估计每股市场 beta（104 周，至少 52 周，退化时用训练期收缩值），然后在标签区间形成 y_resid = R_i - beta_i,t * R_market。未来市场收益属于目标定义，绝不进入 t 输入。风格多因子残差只在因子也可审计时增加。市场/行业共同成分可以是真实可交易 beta；保留总收益账本，不为了追求“alpha”删除赚钱的 beta。

因子匹配后优势消失：结论写“该收益主要对应已测暴露”，并比较更简单、更便宜的 beta 替代策略。多空 beta 也不必为 0，50/50 名义预算不等于市场中性。

有关回测选择偏差，参阅 [PBO 原始论文](https://escholarship.org/uc/item/4w1110bb)及方法附录。事后清除亏损股票、按未来表现筛质量、只报最好成本档，均使结论不可验收。

## 10. 规模实验：先问增长来自什么

触发：S2/S3 全部通过，至少一个数据配方在补种子与历史滚动中保留经济价值，完整训练吞吐/显存/可监督周数已记录。否则只交覆盖和学习曲线的实施计划，不空耗大模型训练。

四条独立轴：

| 轴 | 第一轮取值 | 必须固定的东西 |
| --- | --- | --- |
| 监督量 N_label | 稳定 ID 哈希的嵌套 1/8、1/4、1/2、全量，仅改变主监督 mask | 所有输入、截面标准化参考池、CS 上下文、InfoNCE、时间、评估池、模型固定；loss 按有效标签归一 |
| 上下文量 N_context | 小池/全池两点端到端扩池，记录逐周实际 N | 另成曲线；改变截面统计/CS 摘要/投资池的影响单列，不能称纯监督数据量规律 |
| 时间量 T | 最近 5/10 年、2000 年以来全部；同一结束时刻 | 股票抽样规则和评估范围；与时间衰减的域偏移效应分开 |
| 参数 P | d64/d128/d256，4 层、4 头，embedding 同步 d；CS 可额外核参数量 | 数据、训练目标及费用；规模变体只用于 scaling，不宣称新最优架构 |
| 计算 C | 同数据重复 1×/2× 更新；另做等可监督样本曝光/近似等 FLOPs | 数据版本、每步有效股票周数、验证访问次数 |

先只跑 N_label 轴 4 点，含已完成的全量基线，seed42；两端和拐点补种子。趋势稳定才做 T 轴，再做 P 两端；N_context 先复用 D1 的数据诊断，不与 N_label 混合。首个完整阶段最多新增 10 个训练任务，后续以 gate 扩展，禁止一开始 4×3×3 全组合。

必须做两种预算报告：固定完整 epoch（更多 N 就更多算力）和固定有效样本/计算预算。N 个股票被强相关冲击驱动，N×周数不是独立样本量。记录周数、有效监督对、证券数、行业覆盖、相关结构有效秩；有效秩或自相关 N_eff 只是诊断近似，不当精确独立样本数。

候选描述模型为 L(N)=L_inf+a*N^(-b)，先用可比、非负的 OOS 预测损失；具体用固定评估截面的预测/目标 percentile 平方误差，另报 RankIC。不同 N 下 InfoNCE 分母会变化，其训练 loss 不能直接比较。净收益曲线单独画，不强拟幂律。只有 3–4 点时参数不可辨识风险高，仅作探索拟合并明确自由度不足；要主张幂律须另登记更多规模点、误差模型和留一规模检验。比较常数/对数/幂律和 seed/时间块区间；b 不稳、loss 降但净收益降、成本增长吞掉收益，都可得出“不支持有用的规模规律”。下一规模最多外推 2 倍并实际验证，不从小网格预言无限增长。

## 11. 并行排程与队列

### 11.1 分工和依赖

未来执行可以让 3 个 agent 并行；各自使用隔离目录或 worktree，集成负责人串行合并共享 src 修改：

- 数据 agent：来源能力、名录、下载、覆盖、查询；只写 data/ashare_v2 与归档脚本。
- 因果/执行 agent：标签、权益、日历和 Ledger，先用合成 fixture；与主分支集成后统一验收。
- 实验 agent：快照适配、训练入口、配置、排队和 CPU 评估；GPU 同一时刻只有一个任务。

训练和评分用已有 weekly_followup_queue.py 的任务结构。队列以依赖门+needs_states 释放任务，完成一个合格配置就发布到当前队列，无需等全部候选写完。**运行中的代码必须冻结**：训练进程会懒加载和评分会重新 import，不能边跑边改其 cwd 中的共享源码。每次代码变更复制/冻结受影响源码和配置到新任务快照；采用新 cwd，或冻结批次源码并在另一 worktree 开发。仅写 cfg_sha256 字符串不能实现这一点。

CPU 训练吞吐保护：初始下载 2 并发、构建 1 worker、评估 1 worker，torch_num_threads=4；训练步耗时较单任务基准增加 >20% 时暂停全量压缩/重扫描。降低每步日期 batch 时，用梯度累积保持有效日期 batch=16；损失按实际日期数加权，尾批正确处理，候选及基线一致。

### 11.2 关键路径时间表

| 相对时间 / 预计工作量 | 网络/CPU | GPU | 可提前做的收尾 |
| --- | --- | --- | --- |
| H0–2 | S0、能力/名录、哨兵、schema与账本 fixture | 空闲，直到正确性 smoke 通过 | prereg、试验表、报告骨架、结果 schema |
| H2–8（源允许时） | 全量日线归档；先建 580 桥接；并行权益/日历/查询测试 | 仅在 G_CAUSAL/G_LEDGER/G_BRIDGE 后启动 BQ/BU | 配对/因子/成本分析脚本、coverage 报告 |
| 首个基线训练期间 | 完成 D2/A1，跑单元+小样本梯度检查，原子入队 | BQ/BU seed42 → D2 seed42 → A1 seed42 | 校验 epoch 分数读取、现金基准、图表渲染 |
| 第一波 3–6 个任务期间 | 完成 D3、D4/D5 CPU探针；下载继续；AL1在自身门通过后建篮子标签、CPU训练与静态对照 | 就绪候选依次运行，CPU判门后可追加 seed43/44；AL1仅缺表示时插入一次冻结导出 | 逐任务立即写评估 JSON 和失败归因，准备最终汇总 |
| 首筛结束 | 锁定至多 2 个候选，生成 F1/F2 与分腿选轮清单 | 对照+晋级候选的配对复验 | 提前完成所有报告，等待最后结果只需填表 |
| 复验结束 | 判断组合/scaling gate；未触发则收尾 | 仅触发的增量任务 | 校验实验族完整、资源统计、数据卡、索引 |
| 队列真正完成 | 发布 queue/closed，核对 pending/failed/BLOCKED | worker 退出并释放自身锁 | 一次总验收，旧模型/线上仍不变 |

现有 resources.json 中 B0 580 股 8 epoch 约 2,278–2,284 秒（约 38 分钟），峰值显存约 1,189 MiB；不同批次 CS 也有约 15–38 分钟差异，不能据此假设同硬件全池提速。全市场 N≈5,800 仅为排程示例，朴素线性外推约 6.3 小时/任务，行业 padding 和拷贝可能更慢。先 20 个训练 step + 1 epoch 实测后估计。

因此首轮可以用时点分层的约 1,500 股训练子池筛机制，再将晋级候选和对应基线扩到全量。评估池仍统一，子池训练效果不能冒充全市场训练结果；子池也必须来自历史全集，不从今天存活名单筛。

估时公式：

~~~text
T_download ≈ 请求数 × 哨兵中位延迟 / 合法并发 + 限速等待 + 重试
disk ≈ 样本压缩字节/行 × 预计总行数 × 版本/临时文件系数
T_train ≈ 每epoch有效batch数 × 实测秒/batch × epochs + 评分/保存
T_finish ≈ 工程关键依赖 + max(网络尾部, 已释放GPU任务和) + 最后验收
~~~

首次归档建议预留估计数据量 2 倍临时空间，再加现有盘剩余余量；空间不足停止新增下载，保留已有档案。源权限/退市资料可能将完整归档拉长到数天，训练队列也可能持续数日；以实测进度更新，不承诺“一夜全做完”。

## 12. 交付与一次验收

每个任务成功的定义是产物可读、内容符合契约、hash 一致且业务验收通过，不能只看 exit 0 或文件存在。

输出：

~~~text
outputs/dataset_v2/
  registry/{prereg.json,source_manifest.json,exposure_ledger.csv,trials.csv}
  gates/{G_ARCHIVE.json,G_CAUSAL.json,G_LEDGER.json,G_BRIDGE.json,...}
  configs/  runs/  scores/  eval/  logs/  queue/
  reports/{coverage.csv,quality.json,yearly.csv,paired.parquet,
           factors.csv,cost_capacity.csv,scaling.csv,report.md}
  acceptance.json
~~~

最终逐项验收：

- [ ] 归档与下载缺口按证券/日期/类型公开，未把当前列表当历史全池。
- [ ] 查询示例含单股、换码证券、退市股、跨市场板块、按时点财务，能离线重现。
- [ ] 未来数据扰动、标签成熟边界、未知状态、复权事件、增量幂等、错位单位测试通过。
- [ ] 旧 v4 复现成功；新账本差异逐类解释；旧报告未覆盖。
- [ ] 相同数据/费用/资本/日历下所有候选与父项配对，新旧策略区分。
- [ ] 交易资金恒等式、残单、真实时间券费、缺价持仓和公司行动验证通过。
- [ ] 每个实验包含完整配置/代码/数据/轮窗/seed/hash/耗时/显存和所有失败重试记录。
- [ ] 收益、alpha/beta、成本、容量、分腿现金对照及覆盖均有结果或明确 NA。
- [ ] AL1完成动态多空配比与静态偏多/同暴露对照，或记录具体未满足的数据门；父模型→配比拟合→配比选轮→历史复检的时间锁、换手和费用可审计。
- [ ] 已读历史、开发首筛、事后改动、前瞻观察明确分开。
