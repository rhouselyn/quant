# Score MLP first-pass registration

Use the fixed epoch 3 of `abl2000_base_r2021` as a frozen encoder. The model is trained through its configured 2021 boundary. Generate its scores and representations after that boundary. Compare fixed weekly candidate sets: 40 largest scores and up to 10 smallest scores in the preceding-quarter eligibility proxy. Each calendar year from 2024 onwards fit on earlier, matured weeks, excluding the final two anchor weeks before the new year.

For each leg fit the same 128→32→1 MLP with seed 42, 40 full-batch Adam steps, MSE, learning rate 0.001, weight decay 0.01. Train separately on directional absolute simple returns and on directional returns minus that week's candidate mean. Normalize inputs using the fitting period only. Train target units are percentage points. Evaluate equal weight and 80% equal weight plus 20% softmax, with temperature one percentage point, identically for both models. The old-score softmax control uses each candidate set's score standard deviation as temperature. The signed old score is also an input. No hyperparameter or epoch search.

Compute simple-return weekly proxy P&L, full drift-adjusted L1 turnover at 10 bps per traded notional, 8% annualized short holding fee, and a 50/50 combination. Missing realized returns are zero for legacy comparison and counted. Selection uses only scores and previous-quarter eligibility, with no future-label or entry-tradability filter. Missing execution and short-inventory data limit this to a historical signal diagnostic. Equal-weight comparison on the same candidates is the primary comparison. Report all years and the number of weeks, concentration and turnover. This vintage and historical evaluation period have previously been examined and are not a fresh final test.

Second stage uses the same fixed candidates and equal weights within each leg. Compare fixed 50/50 against a mean-pooling MLP and learned-query attention, each trained on earlier mature weekly observations to predict the following long-minus-short net return. Both use 32 hidden dimensions, the same Adam settings and 40 steps. Map predicted percentage-point spread `x` to a long allocation `0.4 + 0.2 * sigmoid(x / 2)`, with the balance allocated to shorts. Refit annually. Evaluate with drift-aware combined portfolio turnover and an 8% annual short fee. Also compare with a static allocation matching the realized average allocation as an attribution diagnostic; this static weight is selected retrospectively.
