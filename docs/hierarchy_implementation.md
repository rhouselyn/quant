# 580股分层模型实现与对照

实现：`src/quant_mvp/hierarchy.py`、`hierarchy_data.py`、`hierarchy_engine.py`。

## 实际结构

原40周Mamba时序编码器输出未L2归一化的128维向量。每行业20股+1个行业身份/动态均值代表做局部SA；29个行业代表+1个市场token做全局SA。L→G→L→G→L后取股票表示，LayerNorm、L2归一化、单线性score头。注意力为4头，与score头数无关。局部层跨行业共享参数；不同深度不共享参数。Pre-LN、FFN宽度256、dropout0.1、逐维tanh残差门控初值0.1。没有股票直接cross30。

市场token包含一个可学习向量、行业池化表示与六维市场特征MLP。六项为股票池等权当周收益、4/12观测周累计收益、20观测周波动、上涨比例、估计成交金额相对20周均值的对数偏离。只使用当时可知行情，市场特征只按训练期统计标准化。token每次forward重新初始化，不跨日期携带隐状态。

## 数据修复与可用性

新缓存 `data/sw_580_observed_features/`。复用580股原始日线，先聚合实际有行情的周，在包括2016年前数据的历史上计算24个特征；再对齐520周日历。空周只前向携带既有特征，不填原始价格或收益，不做反向填充。初始历史不足的真实预热缺失保留。修复后验证期vol60/mom60/volume_z60/range60不再全部缺失。

股价、成交量、金额与原下一日历周target经过逐值核对保持一致。原600/580/500缓存均保留。市场空周在时间输入中携带过去状态，当前候选及attention mask仍标为不可用。

当前可用股票要求本周有正成交量和有效特征、最近40个日历周至少32周有可用特征观测。横截面标准化仅以本周观测有效股票拟合；空周携带上一周已标准化输入。训练期缩放参数、符号顺序与行业映射保存到每组的preprocessing.json。

## InfoNCE实验协议

固定三组：off（0）、h2（权重0.1、未来两周）、h5（权重0.1、未来五周）。三组同股票池、同输入处理、同市场特征、同架构初始化、seed42、10epochs、batch16、学习率0.0008。共同预留5周训练边界，监督训练日期相同。每轮日期排列由独立固定seed确定。

对比学习在关系层之前的时序表示上计算，使用独立LayerNorm/Linear/GELU/Linear投影头。未来key由EMA时序编码器+投影头生成，EMA0.99；未来数据不进入关系注意力、市场token或预测分支。仅当前可用且未来整个key窗口可用的股票参与对应日期的对比损失。其他有效股票为负例，同业不特殊排除。

主损失为Score头尾各20%等权+0.5×全量RankIC。score标签、RankIC mask使用当前可用性与未来收益有效性；推理候选mask不使用未来收益。全580横截面先恢复再做关系建模，时间编码的显存分块不改变行业分组或InfoNCE负例集合。

训练目标在loss准备阶段截断到±0.25；验证/测试预测文件中的realized_return保留原始收益，再转简单收益做回测。首个未完成off试跑发现回测误继承训练截断，已停止并归档到`.invalid_clipped_returns`，不参与正式比较。回归测试覆盖超出截断边界的正负收益及缺失标签。

选模：每组以验证Top20净Sharpe保存best，平局保留早轮。三组完成后，先写selection.json冻结验证胜出方案，才计算测试对照。测试结果不会改变默认选择。主指标为简单收益、漂移持仓、双边10bps成交成本的Top20净回测；旧多空辅助图沿用旧会计口径，应与主指标分开解释。

## 复现与产物

`python scripts/run_hierarchy_comparison.py` 顺序运行三组，不覆盖既有未完成实验。每组保存best.pt/newest.pt、训练CSV、验证预测、输入缩放和协议。对照目录为 `outputs/hierarchical_580_comparison/`，实时页面 `/hierarchy-comparison`，正式运行日志 `training.log`。

全部完成后运行 `python scripts/report_hierarchy_comparison.py` 生成中文指标表、净值与逐周行业/行情代理暴露诊断。它先逐条核对验证和测试的realized_return等于原始target，然后计算分数对行业哑变量及六个行情代理的样本内R²和Top20行业集中度；不改动selection.json或默认配置。六个代理为ret1、ret20、ret60、vol20、vlog、amount_z20，不能当作完整风险因子模型；解释比例也不等于有害风格比例。

小规模验证使用真实580股的早期训练/验证日期，产物 `outputs/hierarchical_580_integration_check/`，不参与方案选择。

验证项目包括股票顺序等变性、日期隔离、空行业/无效股票不会污染有效股票、市场和跨行业梯度能经最后局部层传回、mask对比样本无梯度、空周不会破坏滚动历史、未来行情变化不改变过去特征，以及现有回测/权重/去相关测试。

当前行业分类仍是2026年快照回溯，原股票样本有存续筛选偏差。结构与输入修复同时相对旧模型改变，旧500或600实验不能作为注意力的单因素因果对照。三组InfoNCE比较固定了这些因素，但单seed结果仍需后续稳定性检验。
