加权 BCE 的损失逐样本乘绝对行业收益。令 A=E[max(R,0)∣x]，B=E[max(−R,0)∣x]，条件风险为 −A log q−B log(1−q)。最优 q=A/(A+B)，故 q>0.5 当且仅当正负收益贡献之差 A−B 为正。新增联合分布头用方向 BCE 和按符号选取的幅度损失 log m+|R|/m。求条件期望对 m 的导数为 (m−E[|R|∣符号,x])/m²，因此拟合的是条件幅度均值。进场信号来自 p m₊−(1−p)m₋，与先前概率到收益的固定幅度映射不同。两者估计的对象都是行业级，最终执行还有 B0 个股排名、缺额、交易费用与融券费用。

验证 112 周共享 3,196 个成熟覆盖标签，原 BCE / 加权 / 联合的方向准确率为 54.79% / 53.75% / 53.97%，幅度加权准确率 56.75% / 56.07% / 54.99%。历史 297 周 8,603 条标签，普通准确率为 49.70% / 49.22% / 49.76%，幅度加权准确率 48.03% / 49.73% / 48.26%。历史 10 bp 下，原 BCE / 加权 / 联合的空头净贡献为 +2.95 / −1.36 / −1.52 bp，后两者的较弱空腿贡献解释了组合下滑的一部分。
