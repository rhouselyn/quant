# M6 八周市场表示与 AdaLN

2026-11-16，Asia/Shanghai。状态为已登记。父实验为 [P6](research_20261114_group_fox_protocol.md)，沿用 [三年选轮与回放协议](research_20261113_standard_execution.md) 和 [P6 数据及损失口径](research_20261116_p6_tail_protocol.md) 中的 P6 基线定义。

第一阶段比较 P6、M6SUMMARY、M6GRU。逐锚点读取截至当周的 8 个标准化 M6 周向量，沿用快照的休市前向携带及训练期标准化。摘要为逐维均值与首末差，GRU 为单层宽度 8 的最终状态，两者各以零初始化线性投影加到现有四维状态。风险尺度直接输入仍为当周 M6。序列与摘要参数量不同。

第二阶段在第一阶段报告生成后执行预先固定的 M6FROZEN 和 M6ADALN 对照。每个种子读取第一阶段同种子 GRU 第 8 轮权重，按验证评分 sidecar 校验检查点哈希并冻结 GRU。两臂各自从相同 P6 随机初始化训练八轮。末端臂仍加到四维状态，AdaLN 臂通过一个跨四层共享的零初始化投影调节 attention 与 FFN 前的 LayerNorm，保留当周 M6 的末端接口。投影为 32 对 2,048 参数，比较包含接入方式及容量差。

每臂种子 42/43/44，复用 P6 已完成的 seed42，补训 14 次，每次 8 轮、batch 16。BQ_F0_r2 训练截止 2018-01-01、共同预留 5 周，继承固定 580 股票池、静态行业和代理成交限制。保留 P6 Gaussian faithful mean NLL 与 0.1 行业内配对损失。三年验证共 153 成熟周，每模型、每种子、每腿按净 Sharpe 选单轮后取相邻三轮，锁定后生成 297 成熟周的历史评分。两段市场历史均已读。

主指标为同周 L20 扣费均值与最差 10% 周净收益均值，两者正差为好。使用 5,000 次同索引 8 周块 bootstrap，列种子和三种子分数融合结果。标准账本另附 S10、LS50、换手、最大回撤、逐年结果及缺失收益惩罚。主档每边 10 bp / 年借券 8.35%，压力档 30 bp / 12%。升格信号要求验证三种子的 L20 扣费差和尾部差均为正、融合主档两项区间下界均为正且压力档均值增量为正。第二阶段的比较对象和结构预先固定。

执行入口为 python scripts/queue_m6_history.py register，批次目录 outputs/m6_history_v1。冻结源码、数据、配置、对照产物和任务清单。GPU 沿用 outputs/dataset_v2/gpu.lock，每阶段先做真实批次 CUDA 前后向。训练预算为 112 轮，另有两阶段评分、回放及归档。证据保存在本机。
