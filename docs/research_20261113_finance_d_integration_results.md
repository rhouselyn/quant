## 1. 裁决：方案可闭合，但收益改善依赖四个可失败的假设

推荐保留40×30→128 Attention主干，采用共享行业/市场摘要、小均值头、M6低秩状态交互和同中心双尺度Gaussian log收益分布。它比继续扩大旧无量纲score头更直接表达“同业共同条件均值＋组内异质响应＋条件噪声”的建模假设。首版关闭旧BCE、RankIC、InfoNCE、总分行业η²，旧B0完全保留。这里的明确方向是结构和目标的改变，不能写成已获收益提升。

四个潜在改善机制是：共享池化降低共同预测量的估计噪声；小头限制自由度、让组间与组内函数分工；M6使同一股票信号对不同市场状态产生不同响应；似然利用全部有效标签并让宽尺度成分减弱部分极端残差的影响。行业均值不可预测、摘要丢失信息、状态漂移、尺度吸收均值错误时，这些机制都可能失败。

**中心化本身是贡献定义和可识别约束，不是收益提升定理。** 若共同头能吸收raw个股头的行业均值，未中心化总函数可重参数化为中心化三个输出；总预测假设空间未必实质缩小。应把预测增量归给具体共享结构、信息路径、容量和优化分工，而不能说“恒等式正确，所以预测更准”。m是共同加数，对单模型横截面排序没有直接作用；它有助于水平和概率任务，改善选股必须来自行业或个股差异。

## 2. 唯一首版规格与A/B/C冲突裁决

设A_t为当时输入available集合；行业成员数只按A计数。已知行业少于5只与未知行业归OTHER；空组不参与求均值，保留原行业ID和effective_group。首版使用登记快照既有静态回溯行业，不能因新公式就声称PIT；未来dated行业是另一个数据版本。设z_i为保留LN/L2后的128维表示，c_g、c_M分别是A内组和全体均值，包含自身。

| 组件 | 统一计算 | 参数 |
| --- | --- | ---: |
| 基础市场 | m0=MLP(c_M)，128→16→1，GELU | 2081 |
| 基础行业 | q0=MLP([c_g,c_M])，256→16→1，末层无bias | 4128 |
| 基础个股 | a0=w_aᵀz_i，无bias | 128 |
| 状态 | c=MLP(M6)，6→8→4；u_i=Uz_i，128→4无bias；m=m0+b_Mᵀc；q=q0+Σγ_G ū_g c；a=a0+Σγ_A u_i c | 616 |
| 尺度 | v_i=b_s+w_sᵀz_i+v_sᵀM，s_i=s_ref[.01+softplus(v_i)] | 135 |

基础头6337、状态616、尺度135，总decoder7088参数；是解析计数，未实例化。状态只走这616参数的均值路径：**不再把M拼到m0/q0，也不叠旧market_film**。独立尺度M线性项在所有概率对照都开启，因此均值状态消融不会同时改变尺度信息。此裁决取代A初稿含M的基础头，也取代B首版尺度不默认读M的建议。

均值内部采用固定s_ref的无量纲坐标，p_g=n_g/|A|：

    delta_bar_g = q_g - sum_h p_h q_h
    alpha_bar_i = a_i - mean_{j in g(i), A} a_j
    mu_log_i = s_ref * (m + delta_bar_g(i) + alpha_bar_i)
    market_log = s_ref*m; industry_log = s_ref*delta_bar; alpha_log = s_ref*alpha_bar

s_ref只用共同已成熟训练样本估计，方法采用C的日期等权MAD参考；保存数值、样本身份和定义，评分必须读取。目标不逐周z、不clip到±.25；原log单位NLL保留单位换算常数。尺度s为窄成分标准差，总log标准差是√1.8s，不应输出为同名sigma误导消费者。

原log收益的分布固定为0.9N(μ,s²)+0.1N(μ,9s²)。loss先在V_t=A_t∩有效成熟标签上求平均，再日期等权。μ与三个贡献均为log单位，score=μ；简单收益均值只在sidecar按C公式导出，不自动排序。概率输出是逐股边际模型，没有联合协方差。

## 3. 必须保留的数学限定

### 贡献识别不等于风险定价识别

给定A、有效行业和等权权重，总μ唯一对应市场均值、行业均值相对市场的偏差、行业内剩余。raw头权重、潜表示及U的各维不唯一；raw a组内常数和raw q全体常数被消除，不能据潜维命名宣称经济因子识别。对总预测做行业中心化也不意味着TopK持仓行业中性，更不意味着对市场β或其他风险暴露中性。

传统条件因子模型区分r_{t+1}=B_t f_{t+1}+ε和E_t r_{t+1}=B_t λ_t；未来实现f与可预测λ不是同一输入。本方案固定行业指示矩阵，仅预测条件均值及边际尺度，没有估计风险β、可交易因子组合、因子残差协方差或施加无套利约束。Gu/Kelly/Xiu的条件autoencoder原文明确包含非线性条件暴露和经济限制；不能把本方案三头结构写成它的等价复现。[作者机构原始研究页](https://www.aqr.com/Insights/Research/Working-Paper/Autoencoder-Asset-Pricing-Models)

### 模型内均值不等于错设下真实均值一致性

固定同中心混合内E[Y]=μ，方差1.8s²；但受限模型族的NLL最优location通常不等真实条件均值。log score对完整预测分布是严格proper、期望差对应KL；这不保证真分布不在模型族时某个参数仍精确估计均值。[Gneiting与Raftery原论文](https://sites.stat.washington.edu/people/raftery/Research/PDF/Gneiting2007jasa.pdf)

本轮纯内存反例：真Y以.9概率为0、.1概率为1，真均值.1；取候选s=.1，在μ=.1处混合NLL的总体位置导数为7.5631249137而非0。因此应称μ为“模型隐含log均值”，同时用训练外均值误差和排序检验其预测价值。该算术未运行优化，不是市场实验。固定Gaussian族的均值最优性在相应总体条件下较强，故保留单Gaussian机制对照有价值。

双尺度Gaussian比单Gaussian尖峰厚肩，固定峰度8.3333，但远尾仍由宽Gaussian支配，log密度渐近二次衰减；它不是幂律尾，也没有偏度、涨跌停原子或违约原子。简单收益指数矩有限，但有限公式不代表数值安全，极大s会使指数溢出；sidecar应在log域计算矩并明确报告非有限输出，不能为方便静默截断s或把异常均值送入排序。Y=log(1+R)支持R>−1，不覆盖R=−1的点质量。

异方差似然中大s会减弱μ梯度，可能掩盖均值欠拟合；log(s)项不能保证优化质量。现有原论文证明某些设置下会出现差而稳定的估计，不等于本任务必然失败，也不要求首版增加β-NLL等补丁。[Seitzer等原论文](https://arxiv.org/abs/2203.09168)

### 缺失标签不能参与forward投影

A定义组与投影，V只定义loss。V内的α均值一般不为0，因此不能把V内观察到的行业未来收益均值当m+δ真值。只用总μ的有效标签似然；完整标签日期的分解可做诊断。改变未来valid_y不得改变forward、OTHER分组或候选输出。非随机退市/停牌缺失会使似然估计选择后的分布，中心化无法补救。训练标签缺失不可当0收益，未确认尾部异常不可靠结果大小删掉后仍宣称原始总体概率。

## 4. 梯度、空组与数值边界

中心化梯度会在同组股票间传播：一个有标签股票的μ误差可以通过组均值更新无标签候选的表示。这是使用当时可知输入的模型计算，不是标签泄漏；但不能再声称各股票训练独立。对raw a梯度施加组内去均值，组常数方向是零空间；对q去总体均值同理。不要加未约束score旁路来绕开这些定义。

状态增益b_M/γ_G/γ_A可置0，U和状态MLP必须保持正常非零初始化；初步只有增益有梯度是正常启动。若所有乘法因子一起零初始化，交互可能永远打不开。基础均值的末层残差零初始化也会暂缓其上游梯度，应记录而不是误判死支路。尺度初始化使s=s_ref，避免任意score量级直接作为周log收益。

先mask填安全值再求group sums，不能NaN×0；空组不能用虚假的分母1生成有效行业输出。单股组α=0，全体只有一股时δ=α=0；A为空返回全部无效，不能伪造市场均值。已有训练日期门要求有效标签至少10只，概率版保留共同779训练日期；一般函数仍须安全处理空监督batch并跳过optimizer，以免纯weight decay更新。

全局梯度裁剪阈值1可先沿用，但NLL的新尺度会改变裁剪频率，需记录均值/尺度/主干梯度及clip比例，不能把持续裁剪造成的欠拟合当作架构失败。floor命中率、尺度分位数、按尺度分层均值误差、状态分层校准均为必要诊断，不自动加训练补丁。

## 5. 五臂以内的必要机制拆解

以下是可供预注册的最小矩阵，不是新队列授权。所有P臂同主干、同原始标签、同日期、同s_ref、同尺度M路径、同选择与概率融合；单Gaussian用标准差√1.8s，以使初始总方差与mix一致。

| 臂 | 均值 | 噪声 | 用途 |
| --- | --- | --- | --- |
| B0 | 现有score、旧四损失 | 无概率定义 | 总系统基线，不参与概率NLL比较 |
| P0 | 同信息未分解头＋M均值状态 | 单Gaussian | 结构包参照 |
| P1 | 结构化m+δ+α，关闭均值M616残差 | 单Gaussian | 状态参照；尺度仍读M |
| P2 | 结构化m+δ+α＋M616 | 单Gaussian | P2−P0结构包；P2−P1均值状态 |
| P3 | 与P2相同 | 固定双尺度mix | P3−P2噪声族；唯一完整推荐 |

P0可具体取共享单均值MLP([z_i,c_g,c_M])，384→16→1、GELU，共6177参数；将B相同616参数的b_M·c、γ_G·ū_g⊙c、γ_A·u_i⊙c直接加到总均值，使用同135参数尺度头。P0共6928参数，P2/P3为7088，相差160；全部输入、池化与状态信息相同，预算接近但不是严格容量匹配，不补无用参数凑数。P2−P0只支持结构化共享/分工包，不能独立证明池化、中心化或每个头各自有效。若必须精确参数匹配，可另选同m/q/a但不center的P0定义；它只检验约束和优化分工，不能同时声称检验共享池化。两种P0执行前只能冻结一种，不能看结果后切换。

本矩阵没有固定M容量臂、尺度M独立臂、纯InfoNCE移除臂、pair排序辅助或FiLM重试，因五臂无法识别所有原因。P2−P1混合了616参数与状态变化，不能写成排除了容量的因果证据。若完整候选无增益，先结束或依据明确诊断另登记；不把有限拆解扩成网格，也不用ridge或额外硬秩限制替代主模型。

单轮选模仍按完整2018–2020验证的各腿净Sharpe，近邻三轮和seed规则不因NLL存在而变化；固定训练779锚与共同h5 reserve、种子、8轮预算先保持。候选各自选轮衡量整个选择系统；同时列固定轮诊断可显示选轮敏感性，但不重新挑有利窗口。2021+已读历史只作描述复检，不用其决定模型、融合或噪声参数。成本、资本预算、L20/S10与缺失持仓压力沿用登记。

## 6. 评分融合必须当作另一层策略变化登记

概率主路径对锁定成员做p_ens=Σw_j p_j，模型隐含均值μ_ens=Σw_j μ_j；按该均值排序。2J成分混合的NLL要logsumexp，分位数由混合CDF求，尺度不能直接平均后当两成分分布。所有成员mask必须一致，缺成员参数时报错，不自动重归一权重。

旧每轮截面z再融合会重分配不同成员的横截面幅度权重。它与原单位均值融合不等价；公共m在z时完全消失。纯算术例：两成员三股票分数分别(−2,0,2)和(.2,.3,.1)，原单位平均选第三只，分别z后平均选第二只。一次最终z不改均值排名，但逐成员z会改。

因此P3同时输出原单位概率主结果与同成员legacy-z排序附读，不需新增训练臂；这份配对差显示融合算法影响。B0保持旧pipeline；P3主结果相对B0只能是整体系统改善，不能把融合贡献全算作金融头。多空可能锁到不同成员集合，应分别输出腿对应的概率分布/均值，不把两个不同选择的分布合称单个通用校准预测。原单位贡献按相同权重可重构ensemble均值；展示z分数贡献时各项减相应截面均值、共除总μ的标准差，禁止各自独立z。
