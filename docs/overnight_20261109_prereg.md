   除非在日志里写明是先验推理而非对 test 读数的反应。

## 1. 批判性审视：把"理所当然"重新摆上台面

上一轮（11-08）已经证明：训练层 9 个单点干预全 null；单 seed val 的种子噪声
sd=0.055 大于臂间效应；val 排名对 test 的 Spearman = −0.119；组合层里
分数平滑是成本效应不是 alpha；beta 对冲更稳但不更赚；一半超额是流动性暴露。
因此今晚**不重复**这些方向，改从以下六条被默认为"不需要检验"的前提入手：

**(a) 每周把 100% 仓位押在单周分数截面上，是估计方差最大的执行方式。**
实测分数横截面秩 lag1 自相关仅 ≈0.48（val/test 一致），即每周约一半排序是
新噪声。若分数是 `s = a + ε`、`a` 慢变、`ε` 周间独立，则对**决策向量**
做因果移动平均能把估计方差降 √k 倍，而对**分数**做平均会把每期的独立
信息先模糊掉再重新选一次，二者数学上不是同一个算子。上一轮只试了后者
（干净口径下 Sharpe 1.011→0.976，失败）。**前者从未被检验过。**

**(b) "平滑分数"与"分摊仓位"是不同算子，别混为一谈。**
`argmax(mean(s_{t-k..t}))` 引入 (k−1)/2 周滞后并丢弃各期独立的非线性选择；
`mean(argmax(s_{t-j}))` 保留每期的离散 Top-20 选择，只是把资金分成 k 份错期
进入（动量文献的 overlapping portfolios / tranching）。后者不滞后、无新参数，
且天然把换手降到 ~2/k。这是本晚组合层主线 P2。

**(c) 训练样本等权隐含"市场平稳"，而这是错的。**
939 周（2000–2017）等权喂给模型，部署在 2021–2026。非平稳环境下加权 ERM /
指数遗忘是先验上正确的做法，能降低旧制度对梯度的贡献。翻遍 621 份 config
与台账：**所有训练臂改的都是损失形式、输入分布、标签、架构、选模指标，
从没有人改过样本的时间权重**。这是训练层唯一还有清晰数学依据的空白。
（注：`hierarchy_engine` 里 `sample_weight` 机制存在，但只用于行业/cell 平衡，
与样本时间无关。）

**(d) 本仓库所有"择时"实验都在预测方向，从没测过纯风险缩放。**
季节性（§26.6）、下周大盘（§25）、动态 beta（§26.4）全部失败——但这三者
都在赌 `E[r]` 的符号。条件波动的**可预测性**与方向可预测性是两件事；
若 `r_t = σ_t z_t` 且 σ_t 有明显持续性，则 `lev_t ∝ 1/σ̂_{t-1}` 在
均值不变的前提下就能提高 Sharpe（Moreira–Muir 型的风险管理学结论），
它不需要预测方向。**从未测过。** 必须先验证机制前提（σ 可预测性），
并配随机波动安慰剂，否则就是又一场数据挖掘。

**(e) 极端分数可能是噪声极值，不是最优标的。**
带噪估计的极大值有回归均值/赢家诅咒：Top-5 的实现收益未必高于第 6–20 名。
项目试过 Kelly 式"按分数幅度定权"（§10/§11，参数化且被换手吃掉），
但**没做过非参数的「分数分位 → 实现收益」双窗曲线**。若顶部反转，
则"跳过极端 / 内部倾斜"是零参数改进；若单调，则等权 Top-20 得到支持。
先诊断、后决定要不要做策略，避免先射箭再画靶。

**(f) 主动决定「不换 Transformer 编码器」**。
§14 / §20 / §24 三次同 seed 同配方实测：iTransformer 式特征轴注意力、
窗口内非因果注意力、市场 FiLM、跨股票注意力、Mamba2 vs attn 全部 KILL
（最后一次书差 −1.0bps, t=−0.18）。从信息论看，周度标签信噪比约 IC 0.08，
Cramér–Rao 意义上信息量由标签噪声决定，增加表达能力不能降低标签噪声，
容量不是瓶颈。因此本晚 GPU 预算放在 **(c) 训练分布** 与 **决策对齐损失**，
而不是再换一个 attention 变体。这条"不做"与"做"同样需要理由，故写在此。

## 2. 零训练实验（CPU，先跑，全部理由见 §1）

| ID | 内容 | 完整执行理由 | 判据 / 可证伪点 |
| --- | --- | --- | --- |
| **P0** | 仪器校验：自写"给定每周目标权重 → 账本"的通用会计，用等权 Top-20 复现 canonical | §0-3；上一轮两次因自写会计产生假结论（短腿 log/simple、别名 bug） | 逐周 `max|diff|<1e-12` 且全部摘要指标一致，否则 P2/P3/P4 不许开工 |
| **P1** | 分数 20 分位 → 实现简单收益 / 超额，val 与 test 分开画 | §1(e)。纯描述性诊断，不产生策略 | 只有 val/test 两窗**同号**的顶部反转或单调结构，才允许启动 P3 |
| **P2** | **重叠组合 tranching**：`w_t = (1/k)Σ_{j=0..k-1} Top20-等权向量(s_{t-j})`，k∈{1,2,3,4,6,8}，val 选 k、test 单次外推 | §1(a)(b)。严格因果、零训练、无拟合参数（k 是唯一离散选择且在 val 上定）。与"分数平滑"构成干净的对照实验 | 剂量响应应单调或至少有机制解释；换手应 ~2/k；做 10/20/30bps 成本阶梯，若增量随成本单调上升 = 省成本而非 alpha；若 val/test 反号 = KILL |

| **P4** | **纯风险缩放**：`lev_t = clip((σ_target/σ̂_{t-1})^α, .5, 1.5)`，σ̂ = 过去 26 周组合已实现波动（严格滞后），α∈{0,.5,1} 先验固定，σ_target 由 val 归一 | §1(d)。现金零收益，`|Δlev|` 计换手成本。不预测方向 | 先报 σ̂ 对未来 `|r|` 的 val/test 相关性（机制前提）；配"随机打乱 σ̂ 序列"安慰剂；val 选 α、test 单次；跨窗反号即 KILL |

## 3. 训练实验（GPU 串行，8GB 4060 严格单进程；1 seed=42 先筛）

派生纪律：复制 `configs/abl2000_base.yaml`（= canonical），**只改一处**；
需要改代码的臂用 `outputs/overnight_20261109/ov_engine_*.py` **副本**，
由脚本从 `src/quant_mvp/hierarchy_engine.py` 生成并静态 diff 核对改动行数，
`src/` 保持只读。队列脚本**只输出 val 指标**（自己从 `val_scores.parquet` 算），
不调用 `run_monopen_arm.py` 的 `summarise`（它会打印 test）。

| ID | 一处改动 | 数学/原理理由 | 先验预期与风险 |
| --- | --- | --- | --- |
| **G1** | **训练日期按指数遗忘重采样**：`P(t) ∝ exp(−ln2·(train_end−t)/H)`，H∈{400, 200} 周两个剂量（H=∞ 即 canonical 对照）。每 epoch 抽样数不变，不改 loss/架构/推理/标签 | §1(c)。局部平稳假设下加权 ERM 降低旧制度梯度；两个剂量构成**剂量响应**（非单调 = 噪声签名）。此前全部训练干预都保留了"2000 年与 2017 年样本同权"这个隐含假设 | 正：OOS 更贴合近年制度，尾部选股更稳。负：有效样本量下降（H=200 时有效约 300 周），方差上升、可能欠拟合；A 股 2015 后涨跌停/流动性制度变化大，也可能把有用的历史状态丢掉。**不看 test 决定剂量** |
| **G2** | **decision-aligned 辅助损失**：在总损失加 `−λ·Σ_i softmax(scores/τ)_i · (y_i − mean(y))`，直接优化可微的 Top-k 加权组合收益代理 | §1(f) 的例外：不是换架构，而是**把部署泛函写进目标**。§7 三次证明 IC≠收益、§24 证明"边际信息在截面中部、书只吃尾部"，说明现有损失（头尾各 20% 二分类 + 全截面 RankIC）与 Top-20 等权书的泛函错配。λ、τ 由先验固定，val 判 | 风险：新增两个超参、标签噪声大时 soft-argmax 会过拟合；若它只是把 extreme_frac 换个形式，读数应与 T1/T2 一样 null。**这是本晚最可能失败但最值得证伪的一条** |
| **G3** | 复现门 | 只有 G1/G2 中过 val 资格门（val Sharpe > s42 参考 0.931 且 val IC ≥ 0.0778 且 val 超额 ≥ 32.9bps，与 11-08 冻结规则逐字相同）的臂才扩 seed 43/44 | 若全败，GPU 余量用于把**组合层胜出方案在 3 个单 seed 分数上各跑一遍**（检验它是否依赖 3seed 融合的特殊性质），不临时发明新训练臂 |

**选臂规则（写死，在读到任何 val 读数之前）**：val 资格门 → 合格者取 val Sharpe 最大；
无合格者 → 不扩 seed，直接进组合层复现门。规则不因中途读数增删。
