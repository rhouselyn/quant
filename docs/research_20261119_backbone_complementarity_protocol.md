# B0 主干四组端到端互补试验

2026-11-19，Asia/Shanghai。状态 planned，用户已授权入队、回放、验收与四组比较。[提案与旧头尾 RankIC 复算](research_20261119_backbone_complementarity_proposal.md) · [样本外弱周来源](research_20261118_complementary_books_protocol.md)

| 组 | B0 主干从同一随机初始化重新训练后直接输出的损失 |
| --- | --- |
| B0 | 原损失 |
| RANK | 原损失 + 跨实际入选界线的 RankNet |
| MEAN | 原损失 + 扰动硬 20/10 的负半仓平均收益 |
| JOINT | 原损失 + 同一个硬篮子均值项和双向正收益缺口 |

四组 seed42、八轮、128 宽四层、40 周价量、batch16，共用 BQ_F0_r2、2018-01-01 前拟合与五周辅助标签预留。保持 B0 的优化、初始化、交易标签和辅助监督。全样本均按项目各周实际输入可用条件处理。前两折用当前批之前已存在的 2010/2014 截止 B0 第八轮样本外分数及对应 SHA，按各自截断日内成熟标签构造 2010–2017 参照多空篮子，取各腿名义收益下侧 20% 与亏损的交集定义共同弱周。缺失名义股票估值在成熟日按零收益，计划空腿仍扣券费。三种额外损失共用辅助训练周、相同标的可用性和同一截面成交额前 40% 空侧门，早期融券用流动性代理。成熟监督取原算术开盘收益；资格、选股和外推日期独立于未来收益有效性。

RANK 在预测名单的入选与未入选之间取可行 pair，多效用为个股算术收益、空效用作符号反转，单周单腿按裁去 20% 价差以上的跨界换位收益绝对值加权，保留截面其余 B0 监督。硬选择每次先用 B0 分数对可用股票选最多 20 多，再从剩余资格池用负分选最多 10 空。选不足时保留标准分母并留现金。MEAN 与 JOINT 对同一个截面标准化的分数加标准差 .15 的高斯误差，使用 8 对正负对偶扰动。每对逐次计算硬篮子收益并用高斯平滑梯度反传；正式打分和选股时关闭扰动。空腿名义借券按实际持有期 8.35% 计，交易费在连续账本中扣。JOINT 在均值目标上加两侧 +2% 的 hinge 缺口，各除以其训练事件频率，系数 γ=1。没有后置精排模块。

每个非空辅助项首个含辅助日期的训练批把校准项对共享主干表示的梯度范数固定为原损失的 25%。RANK 按自身配对项校准。MEAN 和 JOINT 都按同一个均值项校准，要求初批相同及系数一致。随机扰动使用独立 PRNG，不改变模型 dropout、采样和 B0 可复现初始化。以固定第 8 轮作不受选轮影响的机制对照。

正式训练前的真实 Q1 预检复核出 404 个共同辅助日，多弱与空弱各 81 周，名义阈值分别为 −2.4385% 与 −3.1987%。三组真实 B0 前向均能把新增梯度反传给共享表示，MEAN 与 JOINT 的预检校准相同。实训第一次校准写各运行目录。

统一 153 周三年验证，长短分别按 10 bp 验证净 Sharpe 选单轮，锁定中心三轮，B0 同一规则。四份锁齐全后才读取新模型 295 周历史分数（2021-01-08 至 2026-10-09 完整会话）。50/50 是主组合，报告相对同规则 B0 的意向与开盘可成交代理的实际换股、两方向参照弱周净收益和达到 +2% 的频率、候选自身弱周及双亏、净年化、Sharpe、最差 10% 周、逐年净收益与回撤。对 JOINT−MEAN 保留双方向和整体 net 三个配对指标，8 周移动块 95% 区间。两档单边 10/30 bp，年券费 8.35%/12%。第二套仅以同一已锁的旧固定 5% BCE logits 映射为全多/全空，沿用原 295 周历史信号；异常成交与历史券源为代理，已读历史不能作为独立前瞻。

批次 `outputs/backbone_complementarity_v1`，入口 `python -u scripts/run_backbone_complementarity.py`。源文件、数据和初始校准保留指纹，组合目标接在独立冻结副本的原反传前。跑前用 CPU 合成用例核对入选配额、真实收益差和高斯梯度。四臂串行取得 `outputs/dataset_v2/gpu.lock`；登记时最后的排名集成已完成且共享锁空闲。单臂约 8–18 分钟，以当前实测为准。重启复用提交的 epoch 或已完成阶段，保留失败日志，不改其它队列。完成要求为四组八轮、全部验证锁、共 9,528 行对齐和闭合的周账本、逐年表和调查结果。
