# 冻结 baseline 的双侧候选池精排：数学与架构提案

日期：2026-11-18，Asia/Shanghai。状态：proposal，未实现、未训练、未入队；不是可执行预注册。用户需求：额外网络改善 top/bottom 的精细排名。父研究：[P6TAIL](research_20261116_p6_tail_results.md)、[零训练归因](research_20261116_p6_tail_attribution_results.md)、[候选池行业筛选](research_20261117_industry_freeze10_protocol.md)、[样本外配比头](research_20261117_longshort_oof_bce_protocol.md)。[一手文献核验](research_20261118_tail_rerank_evidence.md)。

## 1. 锚点与研究问题

设计锚点为 group_fox_v1/catalog.json 指向的 research_B0_F0_s42_a1，而非生产策略或旧三种子账本。实际核对了 B0 config.yaml、manifest.json 和 standard_v1 的 lock.json：580 股、30 特征、40 周输入、128 维表示、4 层时间注意力、关系门冻结；训练 cutoff 2018-01-01，8 轮。锁定多头 1–3 轮、空头 6–8 轮，验证 153 周，费用 10bp/年券费8.35%。三轮分数按原流程融合，不能直接替换为某一轮分数。数据快照 ID 为 ee9539898960321aa828e8d5f7af6a01243bf09144467384b603cda84ab4760c。

发现旧 config 仍带 selection_at=2020-01-01、outer_start=2020-01-01 等旧切分字段；后续 standard_v1 lock 明确为完整 2018–2020 验证。此处按后续锁设计，不修改旧配置，不以旧字段重切数据。本次未重算哈希、未加载权重或重新审计全量快照；未查询运行状态，也未操作任何队列。

以 Top20/Bottom10 为主；Top40/Bottom10 是另一个明确登记的使用场景。最近[等权核对](research_20261117_equal_weight_model_books_protocol.md)区分了两者。精排目标是让第20名与第21–100名、空头第10名与第11–50名之间的取舍更好。等权名单内的排列不会改变收益；改变名单、排序定权、择时是不同实验，本提案只改变名单。

P6TAIL 的尾分类会经共享表示传播梯度；其验证改善而历史退化，回退 mu 也未恢复 P6。它没有检验“完整冻结的 B0 + 独立精排头”。所以本提案有独立假设，但不把此前负结果当作新增网络有效的证据。

## 2. 共同数学框架

决策时信息为 F_t，下一持有周算术收益为 R_it（与实际开盘到开盘标签对齐）；符号 d=+1 为多头，d=-1 为空头。U_t^d 只依赖 F_t 和父实验执行规则，不读取未来收益或未来标签 mask。基线两腿可以有不同的锁定分数 s_it^{0,d}。

令 b_it^d=d·Z_t(s_it^{0,d})，Z 使用当前输入可用截面及原融合规则。两腿统一为“越大越值得持有该方向”。从基线候选池 C_t^d 内取 K_d 个：主设计 M_+=100、M_-=50，K_+=20、K_-=10，候选大小是提案默认值，不是已验证最优值。

候选必须包含原基线实际选择所需的股票；无冲突、流动性、券源代理、无法成交补位与留现金规则需复用原回放。数学式先按两侧候选不重叠书写。一个保守的建池办法是先获得原 B0 的两侧决策名单 L0/S0，再令多池从 U+ 排除 S0 后取前100，空池从 U- 排除多池后取后50；这保留 L0/S0，限制两侧竞争。它是待登记的限制，不能隐含引入。若采用允许重叠的原候选池，需沿原优先级处理冲突；方案C的软选择也必须增加联合互斥约束，不能独立软选后宣称对应同一个组合问题。候选池下的零修正回放必须先复现原 B0，否则不进入主比较。

冻结完整基线路径（参数、运行统计、预处理、选轮锁；推理 eval），使用：

    q_it^d = b_it^d + δ_it^d
    δ_it^d = ρ_d tanh(f_θd(v_it, context_t))
    A_t^d = TopK(q_t^d, K_d), within C_t^d

ρ_d 是无量纲修正预算，训练前固定，小范围候选只能由开发/验证选择；不让其无界训练。最后输出层零初始化，ρ 固定非零，初始 q=b；不能把输出和乘法门同时初始化为零而阻断学习。若 b_i-b_j>2ρ，则有 q_i>q_j，故大分差关系必然保留；小分差允许翻转。这是排序扰动界，不是换手数、收益或风险保证。分数仅表示优先级，不称为预期收益或校准概率。

忽略费用且可足额成交时，腿内等权的条件最优决策是：

    argmax_{A⊂C, |A|=K} (1/K) Σ_{i∈A} E[d R_it | F_t].

固定名义预算 α+=α-=0.5，最终关心：

    r_t^net = Σ_d (α_d/K_d) Σ_i 1{i∈A_t^d} d R_it - TC_t - Borrow_t.

因此“收益更高的概率”不等于“期望收益更高”；费用与持仓状态也能改变净最优集合。训练代理和实际回放分别验收。

## 3. A：有界残差 MLP + 边界收益差加权配对（首选）

输入 v 包含固定坐标的128维冻结表示（因果生成见第6节）、基线融合分数、候选内秩百分位、距原第K名分差，以及少量已有波动/成交额特征。所有标量标准化只拟合训练前缀。两腿分别使用 D→32→16→1 MLP，GELU、轻量权重衰减；约每腿五千量级参数，最终按实际D核计。不再添加时序主干；先采用两套独立小头，避免多空目标相互干扰。线性 D→1 是必要容量对照。

候选内 i<j 的有效标签差：Δ_ijt^d=d(R_it-R_jt)。令 y=sign(Δ)，相等收益跳过；位置权重只看基线候选名次 r：

    g_i = exp(-|r_i-K_d| / h_d)
    ω_ij = ε + g_i + g_j,  ε>0
    m_ij = min(|Δ_ij| / a_d, c_d).

h、ε、c 固定；a 是训练期收益差尺度。所有配对均在同一决策周同一方向的预测候选池内；不能用未来真实Top100建池。正ε保留池内远处候选被提拔的机会。

    L_pair,t^d = (1/|P_t^d|) Σ_(i,j) ω_ij m_ij softplus[-y_ij(q_i-q_j)/τ_d]
    L_A = mean_t mean_d L_pair,t^d + λδ mean_(t,d,i) δ_it².

日期等权、两腿等权，避免大候选池支配梯度；a 和τ分别定义收益单位与分数单位。空标签日期单独记数，不通过未来标签mask改变forward候选池。若抽样配对，按采样概率校正或明确目标变为采样加权风险。

理论解释：固定F_t及一对股票，不截断幅度时，令 A=E[(Δ)+|F_t]、B=E[(-Δ)+|F_t]。加权逻辑风险为 A·softplus(-z)+B·softplus(z)，最优 z*=log(A/B)，其符号与 E[Δ|F_t]相同。A/B为零时取相应极限。普通RankNet只考虑胜负频率，没有这一幅度性质。边界权重在给定F_t时固定，不改变单对最优符号；不能把每周收益权重和作为随机分母再照搬这个推论。

仍有三项限制：截断m后针对的是截断加权偏好；多个股票共用标量分数一般不能同时满足所有最优pair logit；非凸有限样本训练和TopK指标没有改善保证。m截断是防噪折中，原始未截断收益必须用于最终评价。

## 4. B：候选集合注意力 + 同一个精排损失

在A输入和残差界不变的前提下，用一层集合交互判断“这只股票相对同批候选是否更有价值”：

    H_i = W_in v_i                 (D→32)
    H' = H + MHA(LN(H), mask)      (4 heads，每头8维)
    H'' = H' + FFN(LN(H'))         (32→64→32，GELU)
    δ_i^d = ρ_d tanh(w_d^T H''_i + a_d).

每侧独立一套块，输出层零初始化；损失沿用L_A，以隔离网络交互效应。mask只来自当时输入，padding不进入attention或池化。不添加股票在输入数组中的位置编码；基线秩作为随股票移动的属性可保留。须满足 f(PH)=P f(H)：逐股输出置换等变；不是将候选集pool成一个不变的单标量。Set Transformer提供集合注意力设计依据，但这里是小型等变精排器，不照搬完整PMA池化decoder。

M为100/50时直接attention的O(M²d)较小，没有必要添加诱导点、图构造或多层大模型。候选收益相关、行业共同暴露使交互有建模理由，但该网络没有显式行业中性或风险约束，不能因加了attention就声称消除了集中度。

必需对照：A；输入/参数量尽量匹配的逐股SELF网络；集合池化context MLP可作更便宜的替代，但不默认增加实验臂。只有B相对SELF有稳定增量，才支持候选间信息优于纯容量。

## 5. C：同一小网络 + 直接针对TopK集合的平滑目标

架构先固定为A，不同时更换网络和损失。用二元熵正则的受约束选择作为hard TopK的连续代理：

    a(q) = argmax_{0≤a_i≤1, Σ_i a_i=K} Σ_i a_i q_i + τ H_B(a)
    H_B(a) = -Σ_i [a_i log a_i + (1-a_i)log(1-a_i)].

对0<K<M、τ>0，严格凹性保证唯一解；KKT给出：

    a_i = sigmoid((q_i-ν)/τ),  Σ_i a_i=K.

ν可用单调一维求根。若第K与K+1分数无并列，τ→0时趋于hard TopK；并列时不保证收敛为唯一离散名单，实盘按原稳定tie-break。这里是自推导的binary-entropy capped-simplex形式，不称为论文SOFT TopK的直接实现。

令 D_i=a_i(1-a_i)，则

    ∂a_i/∂q_j = [D_i 1{i=j} - D_iD_j/Σ_l D_l]/τ.

梯度集中在软边界；非常小的温度会使大部分梯度消失或数值不稳。拟合使用软选择，验收必须hard TopK回放。M≤K时直接全选，不对无选择空间的日期做上述求根。

对不重叠候选，将软目标映射到全股票坐标 w_it^d=α_d a_it^d/K_d，训练代理：

    L_C = mean_t[-Σ_(d,i) w_it^d dR_it
                 + c_t Σ_(d,i)|w_it^d - w_pre,it^d|
                 + Σ_i borrow_it w_it^- Δt]
          + λδ mean δ².

w_pre是同一训练策略上一期仓位经截至t已知收益漂移后的可交易仓位，不能总用B0上一周仓位冒充新策略成本，也不能随机打散日期后计算换手。换手系数必须与现有费用约定一致；候选退出、强制持仓、现金和受阻成交都需映射至原执行器，软公式仅是训练代理。费用/借券率使用决策时可用的假设费率；未来成交状态不作输入。

最小首轮可固定成本项不反传，仅比较平滑毛选择目标与A，再在硬回放扣完整成本；若要声称“直接优化净收益”，必须实现上述时序持仓一致性。两者分开登记，不能混称。无需首轮加入Sharpe、CVaR、协方差头或新的仓位模型。

优势是目标更接近持有集合的经济用途，风险是单周收益噪声、软硬偏差、温度与费用代理误差。它不天然比A稳健，列为第二阶段候选。

## 6. 二阶段训练的因果边界

冻结权重不自动使元学习数据样本外。用最终B0对它训练过的2018年前样本出分，再训练精排器，虽未必泄漏独立测试，却会产生样本内/样本外候选分布偏差。更不能把2018–2020改为头的训练集后仍叫完整验证。

建议另行登记训练前缀内的时间顺序OOF：每个折基模型只读该折开始前已成熟的所有监督标签（含5周辅助任务），之后生成该折候选和分数；禁止随机K折。训练年份及成熟周数须由实际标签核验后冻结，不沿用旧legacy缓存冒充新版B0数据。验证仍完整2018–2020；2021-01-08起已读历史只作探索复检。不同折的模型步骤/选轮也必须只在折前决定；最终B0锁虽已使用验证选轮，这属于被复用的已开发系统，应披露选择偏差，不能包装成未接触验证的基线。

直接拼接不同fold独立训练的128维表示有坐标漂移风险。可执行的保守输入方案是：

1. OOF分数、截面秩/分差和语义固定的原始特征作为最小版输入，先不读取最终B0的训练期隐藏向量。
2. 需要128维表示时，另固定一个在最早OOF期之前训练完的编码器E_ref；全部OOF、验证、历史都用同一E_ref生成z。最终B0仍提供冻结基线分数，E_ref只为精排头提供固定坐标的特征。这不是最终B0隐藏向量的无成本复用。

两种输入不能不加对照地混在网络比较中；首轮选定一种后A/B/C共用。仅做机制探针时，可复用最终B0训练期表示，但必须标“样本内二阶段探针”，不作为主泛化证据。现有[OOF配比头](research_20261117_longshort_oof_bce_protocol.md)已经记录固定早期编码器应对坐标漂移的思路，其旧数据与模型产物并未在本提案中验收兼容。

## 7. 最小实验矩阵与停止条件

第一阶段仅比较：冻结B0、线性残差、A的MLP残差。若A有稳定增量，第二阶段再分别检验B/SELF或C，避免全架构×全损失搜索。初期seed42作机制筛查；验证支持后才登记42/43/44头种子复核。固定同一B0改变头种子衡量头优化随机性；要评价整个系统的种子稳定性，需要另做基线配对种子，不混为一谈。

训练步数、学习率、ρ、损失尺度、候选池具体互斥/补位规则、折日历和数据哈希待实施协议一次性冻结；本提案不自动下发训练。零修正必须重现原分数顺序及逐周硬回放；所有臂使用同一输入、候选、预处理和计算预算，参数容量差单列。精排头在完整2018–2020逐腿按净Sharpe选快照，平局取早；是否融合快照必须在训练前规定，不机械套用主干的三轮融合。早期内部训练诊断不替代完整验证。筛选候选和读取历史的顺序按原项目规则。

主要评价为L20、S10、LS50相对B0的逐周净差，主费用10bp/8.35%，压力30bp/12%；报告净CAGR、Sharpe、回撤、换手、成本、持仓替换数、逐年、行业暴露和8周块配对区间。以周为重抽样单位，不把成千上万股票对或3个seed视作独立市场样本。

机制指标：候选内pair准确率、实际入选与落选边界的未来收益差、替换股票贡献、TopK集合变化、全截面RankIC。候选内事后oracle最优集合只作毛收益机会空间诊断：它是不可交易、乐观的上界参考，不能用来挑池大小或声称可实现收益。

继续条件建议：验证净差方向为正、压力费率不反转，且不是单年或少数极端周支配，才补种子。区间跨零只能说证据不足；若仅训练配对损失降低而净收益未改善，则停止扩容，先检查候选覆盖、标签/费用错配与过拟合。历史不支持时保留负结果，不靠它再选ρ、温度、池大小或行业过滤。

## 8. 实施触点与待验收项

可复用：hierarchy.py的冻结表示与评分接口；model.py的ranknet_loss/cutoff_pairwise_loss作为实现参考（不能假定现有标签与权重定义一致）；hierarchy_engine.py的mask/成熟标签规则；既有逐腿融合锁与回放器。独立训练小头可置于单独模块，避免改主干训练语义；具体文件在实施前按调用方核定。

非平凡实现必须检验：零修正与baseline一致、主干无梯度/运行统计不变、标签成熟与OOF隔离、mask和空候选、两侧无冲突及现金、候选顺序置换等变、修正幅度界、soft选择和为K与梯度、按时间连续费用及hard回放对账。本文仅设计，未写这些实现或测试。

继承固定幸存股池、回溯行业、历史复权、代理成交与券源限制。新增排序网络不修复上述数据限制，也不能保证产生新的可交易信息。研究价值是以有限复杂度检验现有信息能否在决策边界上更有效地使用。

文档检查：新增两页的本地链接均存在。另以NumPy对5个固定分数、K=2、τ=0.4做一次公式自检：软选择总量为K，隐式Jacobian与中心有限差分最大绝对误差约1.24e-11，Jacobian列和为零。仅核对该示例的公式，不代表生产数值实现、边界情况或模型测试已完成。
