## 3. CPU 零训练实验（全部用 canonical s42 / 3seed 冻结分数）

### P1 免交易区阶梯（主对照：val 内部 2018–2019 校准 → 2020 应用；另报全 val 拼接）
- A0 无门槛（=canonical Top-20 全换）；A1 与 A2 同换手量的固定 band（band 网格
  仅 {0.125,0.25,0.375,0.5}×score_sd，取最接近 A0 换手者，禁止事后挑最优）；
- A2 固定成本单位门槛：换手当周双边成本 2×10bps < 校准 μ̂ 差才换；
- A3 逐票成本门槛：双边成本用 P11 口径 `clip(10·(med_amt/amt_i)^0.5,3,60)`。
- μ̂ 校准：早 val（2018-01..2019-12）分数五分位 → 下周简单收益均值，向零收缩 0.5；
  缺格回退全样本均值。**2020 段与 test 段不参与校准。**
- 判据：A2 不优于 A1 → 不升级 A3 主张（P-A 原文条款）；净差 CI 跨零 → 记
  "机制存在但经济意义未证实"；只有 A3 > A1 且逐年 ≥4/5 正才列候选。

### P2 固定持仓风险修整（同持仓、同 gross=1）
- B0 等权；B1 逆波动有限修整：w ∝ 1/σ26，σ26=信号周五前 26 个有效周已实现波动
  （不足 12 周向截面中位收缩），逐票硬约束 |w−1/20| ≤ 0.5/20 后归一；
- B2 安慰剂：随机修整（固定 seed=7，100 次平均），匹配 B1 的实际换手增量；
- 外部对照 Top-40（11-09 已有读数，直接引用）。
- 主比较：同 gross 下配对净差、周波动、下行波动、MDD、最差周。预期主张是**风险**
  而非收益：B1 若净损失 >5bps/周 → 记"风险取舍不划算"；波动不降 → KILL。
