# Two-stage stock encoder and projection learning-rate probes

For the allocation head, train all parameters for 10 steps, then lower only the stock projection learning rate from 0.001 to 0.0001. Continue to 100 steps and select by the complete 2018–2020 validation BCE. Compare against the prior joint and frozen-projection policies on identical weekly books. Retain the 70% and 40% long allocations.

For the stock model, initialize the baseline four-layer, 40-week attention encoder from the same seed for each pretraining arm. Train two short seed-42 self-supervised arms with 512 AdamW updates each. Sample up to 96 stocks from one training anchor per update. Both arms use training history only. One reconstructs eight contiguous randomly masked rows of the normalized price and volume features with Huber loss at observed positions. The other contrasts two masked views of the same stock and date against other stocks on that date, with the anchor row hidden in one view. The contrastive projection is specific to pretraining. Both use the same temporal encoder and freeze it before fitting an independent linear stock ranking head. The fixed budget is a feasibility screen.

Apply the same ridge probe to the random encoder, both pretrained encoders, and the existing jointly trained baseline embeddings. Fit on pre-2018 mature labels with a two-week gap and target weekly realized return ranks. Select the ridge penalty from 0.001, 0.01, 0.1, and 1 by validation Top-40 net Sharpe. Include the latest 30 raw features as a linear reference and the existing baseline score as context. Evaluate RankIC and Top-40 long-only net returns on the common validation and 2021–2026 historical test dates. Use the entry and 10 bps turnover accounting consistently for each arm. This is a seed-42 and short-budget screen on an examined historical test interval.
