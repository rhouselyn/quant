# MLP64 二值标签与温度配对

2026-11-17，Asia/Shanghai。批次 outputs/industry_mlp64_binary_v1，父研究为[MLP64](research_20261117_industry_mlp_width_protocol.md)。延续同一 B0 评分锁、固定第 3 轮编码器、入选股向量、训练时点、seed42、12 轮和股票权重约束。上一次结果已读，本批属探索。

三种预测头共享 128→64→1 GELU。连续收益臂沿用入选行业相对 Top20 的算术收益目标与 MSE。二值臂使用同一持有窗口，分别预测行业入选股绝对收益为正、及其相对 Top20 收益为正。标签为收益大于零 +1，其余 −1。使用日期等权 logistic 损失 softplus(−y×logit)，输出 p=sigmoid(logit)。为比较同一组温度，把方向预测映射为收益单位的信号 s=(2p−1)×c，其中 c 是仅用当前已成熟训练标签算出的日期等权绝对或相对收益均方根。它是预先指定的尺度映射，p 不声称已经校准，亦不声称 s 是条件均值。

三种头各用 T=0.02 和 0.05，先做已登记 EWMA 风险底仓，再使用 softmax 倾斜 25% 与相对 B0 行业偏移 5 个百分点限制。保留 B0 与风险对照；复用此前连续 T=.02 已发布分数与周账本，检查完全一致。验证每 13 周以不晚于当时的已成熟标签重训，历史从第一个决策周起冻结。153 周验证、297 周已读历史；10/30 bp，报告所有两两配对的净均值与各自最差 10% 周，按同周 8 周块 bootstrap 5000 次。Brier、logloss、各组胜率和覆盖分开报告。没有做多重比较校正，不把事后赢家当作确认。

入口 `python -u scripts/replay_mlp64_binary.py outputs/industry_mlp64_binary_v1/report`。CPU 四线程，记录源码、输入哈希、拟合损失、最终模型及预测、逐周与配对结果。
