Use the same frozen seed 42, 43, and 44 backbones, pre-2018 fitting period and label maturity gap. Select head checkpoints on complete labels from 2018–2019. Replay 2020 separately as a development confirmation slice. The underlying frozen checkpoints were originally selected using all 2018–2020, so this slice is only independent of the new head selection. Treat the previously examined 283 weeks from 2021 to 2026 as historical diagnostics. Fix all comparisons before reading those returns. No thresholds or position weights are fit on historical diagnostics.

Keep the Top-40 and eligible Bottom-10 candidates, costs and 70% or 40% long weights for the portfolio head. Refit the existing mean-pool BCE head as the matched control. Test one added diagonal bilinear term with 32 zero-initialized weights. Test one lower-quartile auxiliary head on the same BCE model using pinball loss with a fixed weight of 0.25. The target is next-week long-minus-short return after the assumed short fee, scaled by training standard deviation. Only the BCE logit drives allocation. Each arm selects the step with the lowest 2018–2019 validation BCE, with up to 100 Adam steps. A candidate earns further consideration only when both development slices improve net return and the 2020 Sharpe equals or exceeds control.

Test same-week stock context on the frozen stock score using a regularized residual rank head. Fit a matched ridge adding the elementwise interaction with leave-one-out industry and market mean embeddings for that week. Standardize features on training data, fix PCA width to 32 and ridge penalty to 1% of the training row count, and mix 25% residual score with 75% frozen score after weekly cross-sectional standardization. Compare frozen score, own-stock residual, and context residual by weekly RankIC and Top-40 long return under the same weekly fees. Industry groups use the existing retrospective universe mapping. This probes context at the final scoring head with frozen embeddings, where each embedding contains only history through the decision week. A temporal-token intervention inside the backbone is a separate experiment.
