**先冻结选股模型，在纯多组合层测试受约束的部分换仓。拿固定规则、一步决策和两到三周滚动优化做对照。只有跨周决策带来可重复的净增量，才训练外接小策略。模型内先试决策损失，保留排序监督。**

## 2. 外接策略先学习换仓节奏

上周买入的股票会漂移，无法成交会留下持仓或现金。本周少买卖同时影响本周成本、未来换仓和错失收益。这个跨周机制可以用相同排名检验。仓位择时则要先证明波动或尾部信息有独立的经济增量。

| 顺序 | 方案 | 本仓库的首版与控制 |
| --- | --- | --- |
| 1 | 固定部分换仓 | 冻结周五产生的 Top-20 目标，向目标走 50% 或 100%。比较固定 50%、基准 100%、K=100 缓冲、无缓冲 Top-40。部分换仓可能增加持股数，报告实际和有效持股数，区分分散化与节奏的贡献。 |
| 2 | 一步决策与滚动优化 | 用相同状态预测两档之间的一周增量净收益。特征从边际候选分差、历史分数持久性、持仓重叠、预估成本及集中度开始。成熟标签的基点校准可用时，比较两到三周滚动优化，用过去估计信号衰减和未来情景，每周执行第一步。 |
| 3 | 外接小策略 | 同状态、同两档、同执行层，先试小线性或浅层策略。若低冲击的两档转移都能可靠重放，直接多步优化或小型价值迭代足够。用相同信息的一步模型、滚动优化、移除持仓状态的策略对照，确认收益来自跨期决策。总仓位 80%/100% 另开实验，与事前校准的静态敞口、固定风险预算、Top-40 对比。 |
| 4 | 执行策略 | 有分钟盘口、委托、撤单、部分成交、实际费用后，固定订单意图，比较开盘、定时分批、参与率规则与小策略。计入冲击、延迟及未成交机会成本。现有日线支持限价与跳空诊断，队列和成交量约束仍待数据。 [执行现状](../outputs/research_20261111/acceptance.md) |

两档动作都能用成熟的市场路径复算时，先预测两档净收益之差，或直接用可微账本训练策略。持仓转移可模拟但执行规则离散时，可以比较有限动作动态规划或小型价值模型。历史只留下单一策略的订单轨迹、其他动作无法可靠估值时，离线 RL 仍缺动作覆盖，优先补成交记录及仿真校准。用同一条价格路径反复训练，只会增加优化轮次。

### 状态、动作、奖励

- **状态**用决策时已知的实际持仓、现金、未成交单、已知价格下的漂移权重、拟交易规模、滞后流动性和风险摘要。若目标包含回撤，加入当时净值和高水位比。周五用可得信息决定动作，周一才更新成交可行性。
- **动作**定义为 `w_intent = w_prev + a·(w_target − w_prev)`。执行层按现金、单票和行业上限、成交量占比、停牌限价、可卖数量、整手及借券可得性处理。分别记录意向、实际成交、未成交残余与期末现金。遇到限卖时保留旧仓并记录敞口偏离。
- **奖励**首臂用 `log(V_end / V_start)`，账本先扣交易、冲击和持有成本。若另有换手预算，用约束比较同预算前沿。风险臂可对每日回撤 `D = 1 − V/HWM` 的超预算部分加惩罚，或限制情景路径的 CDaR。周收益的 ES 衡量亏损尾部，另报日度最大回撤及持续期。跳空与无法卖出会使回撤超过预算。
- **先过可成交核验。** T0 新口径读取了 `tradable` 向量，实际交易仍按目标权重差计算。用两票样例把排名第一的 A 标成不可成交，新口径仍买入 A、计入其 10% 毛收益。架构回放能区分入场代理和成交权重，退出仍有收盘代理，也未维护跨周残单。复用分数融合、时点和统计函数，在共同账本上补出可买、可卖、停复牌、假期、残单、现金样例。无计划调仓周保留时间戳和已有仓估值，区分市场休市与持仓估值缺失。先对齐旧历史，再让所有臂在修正后的同一账本重放。 [T0 回放](../scripts/weekly_risk_timing.py#L443) · [架构回放](../scripts/eval_weekly_architecture.py#L139) · [整手入口](../src/quant_mvp/sizing.py#L134)

## 3. 在原模型中加入决策损失

**先冻结主干，训练候选边界的小头。** 只在已持股和拟换入股的边界候选上微调，训练目标可用真实收益差减换仓费用的边际偏好，或采用有单票上限的可微权重。候选集合、同规模排序头、训练数据、实际交易规则都保持对齐。纯粹的一步动作价值学习可把两档重放结果直接用作监督标签。

可用 `L_total = L_base + λ·L_decision`，首臂以短段连续回放的负净对数增长作为 `L_decision`。组合收益先把个股对数收益转换成简单收益，再按持仓权重汇总。权重来自上期已成交且漂移后的持仓，训练轨迹需要持仓预热。若加路径风险，同样预热现金与高水位，按实际标签成熟时点切分。验证用真实硬 Top-K、同账本和费用压力情景，逐周报告软权重与硬执行的换手和收益差。代理赢而硬回放输时，停在失配诊断。冻结头通过后才尝试解冻最后一层，保留原排序监督。

## 4. 验收与停止条件

1. 冻结分数、选轮、决策时点与成交模型。外接层训练用按时间推进的折外分数或当时可用的 vintage。逐周检查 `label_available_at`，未来价格或成交状态的修改只能改变其可用时点后的决策。580 只股票来自当前快照回溯，仍需时点池验证。组合仓位的样本单位是周，数百只股票和多种子无法增加独立市场轨迹。
2. 同一账户规模和日期下，报告毛差、费差、净差、实际换手、平均与峰值敞口、有效持股数、日/周回撤、最差 10% 周平均损失、最大贡献周及逐年结果。10 基点/边复现历史，20 基点/边作预设压力，取得账户真实费用时再单列。按同周配对、八周移动块为主，四和十三周作敏感性。
3. 收益和风险独立验收。可复用已有收益门（净增至少 5 基点/周、两半均正、回撤恶化不超过 2 个百分点）与风控门（最差 10% 周平均损失相对降低至少 10%、净均值损失不超过 5 基点/周）。新增效率门建议先预注册为换手相对降至少 20%、净均值损失不超过 2 基点/周、回撤无明显恶化，且压力费率下仍成立。配对区间覆盖有经济意义的亏损时，标为证据不足。
4. 2018–2019 做成熟标签校准，2020 做固定开发筛选，2021–2026 做已暴露历史复检。登记每次尝试，冻结胜者后用 26/52 个成熟周做前瞻影子账本。只有多步方案在相同输入和交易约束下反复优于固定规则与一步模型，才支持引入强化学习。 [既有统计与日期协议](research_20261111_execution_plan.md) · [风险实验手册](experiment_handoff_weekly_risk_and_timing.md)

本次阅读现有代码与产物，重算旧规则的费用归因和打平费率，并用两票样例复现 T0 成交标记缺口。新策略的训练、回测和券商成交验证待实验阶段。

## 5. 一手研究与适用范围

| 一手研究 | 可迁移的方法与证据边界 |
| --- | --- |
| Gârleanu 与 Pedersen，《Dynamic Trading with Predictable Returns and Transaction Costs》 | 在有成本、信号以不同速度衰减的模型中，向动态目标部分调整是最优结构。实证使用商品期货。本仓库可检验固定部分换仓及分数衰减，不能从论文直接取换仓比例。 [论文](https://www.nber.org/papers/w15205) |
| Boyd 等，《Multi-Period Trading via Convex Optimization》 | 把预测收益、风险、交易与持有成本及硬约束放在同一优化问题。多期只执行第一步，下一周用新信息重求。可检验组合状态和跨期成本的作用。预测的有效性仍由本地数据决定。 [原文和代码](https://stanford.edu/~boyd/papers/cvx_portfolio.html) |
| Wang 等，《Machine Learning Meets Markowitz》，2026 工作论文 | 与本项目更接近的 A 股证据。5,489 只股票、2010–2023、日频 VWAP、纯多约束。表 3 单边 20 基点，MSE 预测接同类优化器与决策端到端相比，年化净收益 24.0%→29.1%、夏普 1.16→1.42、报告的换手 30.3%→18.7%，最大回撤 22.79%→22.07%。30/40 基点情景下净收益和换手仍改善，最大回撤反而恶化。论文提供先检验决策损失的依据。日频 VWAP、股票池、换手统计和周一开盘的可交易性不同，数值无法直接迁移。 [工作论文](https://www.nber.org/papers/w34861) · [正文表 3](https://www.nber.org/system/files/working_papers/w34861/w34861.pdf) |
| Elmachtoub 与 Grigas，《Smart “Predict, then Optimize”》及 Agrawal 等，《Differentiable Convex Optimization Layers》 | 决策损失衡量预测造成的下游行动误差，SPO+ 给出特定优化问题下的凸代理。可微凸优化能让梯度回到预测头。整手、硬 Top-K、限价和拒单需由交易层另行评估，不能从光滑代理的目标直接推出收益。 [SPO 原文](https://pubsonline.informs.org/doi/abs/10.1287/mnsc.2020.3922) · [可微优化层](https://proceedings.neurips.cc/paper_files/paper/2019/hash/9ce3c52fc54362e22053399d3181c638-Abstract.html) |

| Sun 等，《PRUDEX-Compass》 | 可借用盈利、回撤、稳定性、解释性和跨市场评测。中国样本是 47 只上交所大盘股的小时线，完整样本筛选，使用少冲击仿真，且论文明确排除非 RL 对照。不能据此推断 PPO/SAC 优于本仓库 Top-40 或成本优化。 [原文 §5–6](https://arxiv.org/html/2302.00586) |
| Chow 等的风险约束 RL 与 Chekhlov 等的回撤优化 | 前者将累计损失的 CVaR 或超限概率作为约束，后者直接约束回撤路径尾部。可把回撤作为风险预算并保留净增长目标，分别报告周损失 ES 和日度回撤。算法约束基于给定模型和情景，无法保证遇到不可成交时的实际最大损失。 [风险约束 RL](https://jmlr.org/papers/v18/15-636.html) · [回撤约束](https://www.math.columbia.edu/~chekhlov/ChekhlovUryasevZabarankin--2003.pdf) |
