## 结论：先明确目标和解释，再考虑新网络

当前模型有明确的数学结构：**B0是共享时序Transformer上的条件横截面排序器，CS/CB/ADN是加入同周集合上下文的条件排序器。** 它不是当前启用了层次注意力的Mamba，不是条件期望收益估计器，也不是已经识别经济因子的资产定价模型。

暂时保留主干和四项训练目标。第一优先是给现有模型做可以重构预测的解释检查；未来只优先登记两个学习候选：**R1标签侧精确平均秩**、**S1完整40×30信息的线性ridge排序基线**。前者修正目标含义，后者检验复杂网络的增量。两者都没有被本轮证明收益更好，均不启动训练。更复杂的图网络、更大的注意力、Sharpe/换手/风险损失叠加目前没有足够新增证据。

“更科学”首先意味着输出对象清楚、假设可证伪、比较公平、解释忠实，而不是模型必须对应某个有名定理。

## 1. 现有模型的准确数学定位

令 t 为周五决策锚，i为股票，X_it∈R^(40×30)是当时历史窗口，h_it=Eθ(X_it)∈R^128。B0的Eθ为四层四头、RoPE与因果mask的时序注意力编码器。对有限数值输入，冻结为零的关系残差门使行业/市场注意力路径对有效股票恒等：

    z_it = normalize_L2(LayerNorm(h_it))
    s_it = wᵀ z_it + b

这是当前启用配置的简化，并不建议删除代码中的关系模块。C只抽查了B0首轮权重门为零，未逐轮认证。B0仍通过横截面标准化和训练损失读取共同结构；“网络逐股票编码”不等于“整个系统完全没有跨股信息”。

设c_it拼接同日其他有效同业和全市场股票的128维均值，均排除自身：

| 分支 | 条件化方法 | 数学含义 |
| --- | --- | --- |
| CS | h改为h+Wc，再LN/L2/线性头 | 上下文依赖的表示平移 |
| CB | s=wᵀz+b+Σ_k α_k(Uz)_k(Vc)_k | rank8低秩双线性交互 |
| ADN | z=normalize_L2(LN(h)⊙[1+A(Vc)]) | 上下文依赖的方向调制；本实现无shift |
| SELF | c改为[h;h] | 自身额外变换，对照显式跨股信息 |

它们与集合函数和条件因子思想有联系，但不存在“用了行业token，所以就是行业风险因子”的逻辑。CB潜坐标存在重标度、符号和排列不唯一性；同一个分数可以有不同潜参数表示。把潜维命名为价值、动量等需要额外观测定义和识别约束。公共市场加性标量m_t对每只股票相同，不改变当日排名；市场状态要影响选股，需要与股票特异暴露交互，或只作用于总仓位。

训练目标为：

    L = L_tail + 0.5 L_softIC + 0.1 L_InfoNCE + 1.0 L_industry_eta²

它是多目标经验风险。尾分类只在未来收益头尾各20%股票上优化logistic；即使单独优化，其理想概率对象也是“进入两尾条件下属于上尾的概率”。与其他项联合后，score连这个概率也不能直接认定已校准，更不能直接代入以收益率为单位的均值—方差优化。

## 2. 哪些问题已有证据，哪些仍是假设

| 判断 | 证据强度 | 对研究的影响 |
| --- | --- | --- |
| B0实际是Attention且关系门冻结 | 配置、源码、首轮门抽查 | 用实际计算重新描述模型，保留结构作为对照 |
| 平滑RankIC不是精确Spearman | 函数公式和CPU合成反例 | 允许单因素R1检验，不能直接断言现有目标有bug |
| 行业η²不保证Top20行业中性 | 解析与函数合成反例 | 分数正则和组合约束分别检验 |
| CB可按自身/行业/市场精确分解 | 双线性代数 | 可先做零训练解释验收，不必重构网络 |
| 非线性模型优于简单完整信息模型 | 当前缺公平对照 | 用S1测量必要的复杂度 |
| ADN的历史优势来自可交易α | 证据不足 | 不凭已读测试晋级，不把执行代理当实盘 |
| 特征加性网络更适合本项目 | 有文献结构启发，无本项目实验 | 作为备选，不进入当前优先训练集合 |

B的合成例子中，严格保持收益排序，只把收益乘0.1，当前softIC从0.845775变为0.821591，两者精确Spearman均为1。此性质说明目标包含收益间距信息；它可能有益，也可能在波动变化时带来不想要的权重，必须实验区分。

行业反例：A分数[-3,-2,2,3]、B分数[-0.3,-0.2,0.2,0.3]，两行业均值均为0，η²=0，但Top2全部属于A。这不是市场回测，只证明“分数均值中性⇒持仓行业中性”的推断不成立。

已存历史验收显示ADN的低费多空优势对高费敏感、相对SELF的组合配对区间跨零；本轮只把它用作不确定性边界，未据测试排名选择新结构。数值及哈希见[既有验收](research_20261113_checkpoint_review.md)。原四项损失中删除InfoNCE等已有旧批次负结果，B明确其cohort和选轮边界；无需凭概念怀疑重复大规模消融。

## 3. 可解释性应交付什么

先分清四层：原始输入如何影响模型分数、分数如何影响排名、排名如何形成实际持仓、持仓如何产生含成本收益。任何单层解释都不自动覆盖下一层。

现有CB令V=[V_I,V_M]，可导出：

    q_self = wᵀz+b
    q_ind = Σ_k α_k(Uz)_k(V_I c^I)_k
    q_mkt = Σ_k α_k(Uz)_k(V_M c^M)_k
    s = q_self + q_ind + q_mkt

这三项是同一个CB模型的内部贡献，q_self不是独立训练B0的预测。“市场贡献”是其他股票表示经条件支路影响分数的贡献，不是CAPM市场收益贡献。应先验证每行重构，再检查条件去除、缺失mask、股票置换及跨时期稳定性。

标准评分还包含每轮和融合后的横截面z变换。若s=Σq_k，则每项用(q_k−mean(q_k))/sd(s)分摊，使用同一总分数标准差；逐项独立标准化会破坏加和。均值、标准差必须使用实际有效集合与数值保护规则。最终贡献单位仍是分数，不能写成收益百分点。

ADN归一化使行业与市场贡献耦合，不能照抄CB线性拆分。固定同一个checkpoint与h做有/无条件差，可描述路径影响；若再分行业/市场，必须规定交互分摊。相关特征的遮挡可能制造分布外输入；热力图和注意力权重本身不是忠实性或因果性证明。

## 4. 优先顺序与不选的方向

**执行真实性是前置门。** E1固定既有意向并复用日账本，验收现金/库存/残单/权益和日期规则覆盖。它属于执行审计，不是第三个收益学习候选，不适用R1/S1正收益晋级门；更可信的成交处理即使降低回测收益也可能是正确修正。先核受影响证券、日期和订单，再另登记共同执行基准，不覆盖旧表。

1. **先做零训练解释审计**：复用已有CB权重和分数管道，核对三项分解及融合重构；按既定日期与mask做扰动。这项不改变预测函数，也不据扰动挑选checkpoint。本轮只设计，未运行整模型解释导出。
2. **R1损失候选**：仅将训练标签侧soft rank换成精确平均秩。保留收益clip及并列、预测侧温度、四项系数、输入和结构。它减少标签的单位尺度依赖，仍不是完全尺度不变的训练目标。
3. **S1简单参照**：vec(X)∈R^1200，以日期等权ridge拟合当周居中收益秩。1201个系数（含截距），按特征×滞后可精确相加解释。它检验整套学习系统的复杂度价值；因目标不同，不能把S1/B0差异归因于某一网络层。

R1与S1是两个独立问题，不组合。完整预算、固定正则、主指标与停止规则以[实验协议](research_20261113_math_protocol.md)为唯一登记。若结果不确定，保留B0，不自动扩大seed、预算或候选。

C提出按30个特征各自40周历史建40→8→1小网络的备选，约10,111参数，可精确重构特征贡献。这是解释性较强的可行方向，但会改变交互能力与InfoNCE接口；纯结构归因还要增加目标匹配对照。因此当前不优先实施。新的风险惩罚、换手损失、完整图网络或状态空间替换同样暂缓，直到有具体诊断支持。

## 5. 数据和评价边界

所选主研究为Q1固定580股、回溯行业分类；20/40/80共同mask下779个实际训练锚，153成熟验证周，297成熟历史复检周。监督与推理mask分开；训练前缀保留未来5周辅助标签成熟边界。旧配置F0字段不覆盖当前standard锁。旧P64 cohort与本轮Q1训练指纹不一致，不跨cohort拼排名。

原始历史已参与研究，不能通过重新切分或嵌套回放恢复“从未读过”的身份。验证选轮是整个算法的一部分；验证上的最佳净Sharpe也有选择偏差。新实验的置信区间是有限历史上的不确定性诊断，未来确认需要真正未暴露的数据。

A股可执行性依赖按日期的交易规则、持仓状态、真实券源及权益资料；网络损失无法代替这些证据。既有主回放仍是周级执行代理，原价日账本实现与完整成交验收是另一层。数据门未通过时，允许限定范围的Q1探索，不允许据此认证全市场或实盘能力。

E对锁定tape做了只读核查：1,271,061行的can_buy/can_sell均符合当前9.8%/19.8%/29.8%近似规则，SHA与standard锁一致。它没有逐日ST/IPO/正式限价字段。2026-07-06起上交所主板风险警示涨跌幅从5%改10%，说明规则必须带生效日期。[上交所官方说明](https://star.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20260424_10816474.shtml)

准确结论是“主板默认近似阈值缺历史风险状态”，不是“ST一直按旧5%”，也不能据此量化历史收益偏差。生效后46,384行覆盖只能证明待核日期存在，尚不能证明具体订单受到影响。完整数据旗标核对及来源访问限制见E报告。
