## 2. 从源码确认的执行与会计问题

### 2.1 纯多和纯空不是镜像策略

`long_only_backtest` 将对数收益变成简单收益，成本用买入+卖出的全额L1换手，净收益为 `(1-cost)*(1+gross)-1`；默认无期末清仓。`tradable` 过滤只在 `groups is None` 时执行，外部预分组调用必须自行保证过滤一致。该标志描述买入开盘可成交性，不足以证明旧仓卖出、空头卖出和空头回补均可成交。`hold_target_backtest` 保留幸存持仓的漂移权重，`skipfill_short_curve` 则每周显式把每个持仓恢复为 `1/target_n`。因此“缓冲、每周只补缺口、两腿等权”不能同时用一句话概括两腿的真实持仓更新。

代码证据：[纯多入口与记账](C:/Users/14815/Projects/quant/src/quant_mvp/long_only.py:35)、[缓冲多头](C:/Users/14815/Projects/quant/src/quant_mvp/long_only.py:104)、[空头重置权重](C:/Users/14815/Projects/quant/scripts/skipfill_short.py:92)。`hierarchy_engine.py:52` 导出预测和 `tradable`；`:550` 用纯多验证净Sharpe选轮。复用分数时应固定这份选择结果，本轮不以新组合指标重选轮次。

空头于11月8日修复过：收益必须 `expm1(log_return)`，名义空仓的物理漂移为 `w*(1+r)/(1+portfolio_return)`，不能以 `1-r` 代替。旧 `hold_short_target_backtest` 仍采用抽象的 `1-r` 记账以兼容历史，且多处调用仍在使用。不得把它的历史缓冲曲线与修复后的 `skipfill_short_curve` 当成同一实现。证据：`scripts/skipfill_short.py:10`；`src/quant_mvp/long_only.py:199`、`:243`；`scripts/hedge_backtest.py:61`；`docs/experiment_ledger.md:1796`。

### 2.3 “真实成本”目前仍是成本压力模型

P11 的 `clip(10*(median_amount/amount_i)^gamma,3,60)` 没有投资本金或交易数量，因此不能度量容量，也不是实测冲击。它在研究上有用，名称应是“按流动性分层的成本情景”。现有10bps、30bps与此情景都应保留，不应挑使候选获胜的一档。源码与产物证据：`docs/overnight_20261109_report.md:65`；`outputs/overnight_20261109/p11_liquidity_cost.json:1`。

部署账本最低需要区分：佣金/最低收费、按卖出方向的税、规费是否已含在佣金、买卖价差、市场冲击、借券费和召回成本、融资利息、期货展期与基差、未成交后实际留下的敞口。对交易额 `D_i=V*abs(delta_w_i)`，一个可检验的冲击压力项是 `I_i=Y*sigma_i*sqrt(D_i/ADV_i)`；组合冲击费用是 `sum(abs(delta_w_i)*I_i)`。`ADV`、波动估计和参数只用下单前信息；`Y`须成交记录校准，无成交记录时仅作区间情景，不能声称其是真实价格。

`sizing.py` 默认资本50万元、预留3%、券费8%/年；腿预算为 `capital*(1-reserve)/(1+mean_margin_ratio)`，幸存股票保留股数。它报告的 `borrow_fee_week` 不等于该费用已扣进历史组合收益，也没有在此函数里对旧持仓超保证金执行完整强平。8%只是当前代码假设，本文未获取用户券商报价。证据：`src/quant_mvp/sizing.py:35`、`:174`、`:224`、`:249`。

## 3. 四个针对性方案

四项都复用现有冻结预测。重点是给出“哪个机制若存在、应看到什么结果”；文献只支持机制，不证明本数据能获利。

### P-A：仅对边际换仓设置成本单位的免交易区

**改变什么。** 保持Top-20分数目标，取消全局固定分数SD带。对“卖旧票i、买新票j”的同额替换，只有历史校准的预期增益大于该笔实际双边成本才换：

`q*(mu_hat_j - mu_hat_i) > C_sell(i,q)+C_buy(j,q)+uncertainty_buffer`。

`mu_hat` 从严格已成熟、样本外预测的分数分箱映射为下一持有期收益；当前标签未到达时不得参与校准。首版只用少量固定分箱和收缩估计，不训练新深网。零成本时应接近无带策略；高成本时交易数应下降。大分数跳变保留及时换仓，不把全部仓位固定延迟数周。

**为什么、与旧实验差别。** 成本下的最优交易通常有部分调整，而慢衰减预测应受不同处理，这是动态交易论文给出的机制；其收益保证依赖模型假设，不直接迁移A股。[Gârleanu–Pedersen作者稿](https://nbgarleanu.github.io/DynTrad.pdf)。已有固定 `band*score_sd` 三seed仅1/3获胜，σ缩放也未成立；EMA/tranching和平滑还面对快速alpha衰减。此方案的新信息必须是**收益单位校准与逐笔成本异质性**，不是重扫band。现有诊断当期Top20超额45.25bps、旧一周书14.68bps，说明强制统一慢交易有明显机会成本。证据：`docs/experiment_ledger.md:58`；`scripts/band_sweep.py:97`；`outputs/overnight_20261109/p2b_p1b_diagnostics.json:52`。

**最小实现位置。** 将来仅在独立replay中复用 `prepare_groups` 与现有记账，替换 `scripts/band_sweep.py:72` 的swap接受条件；先不接 `hierarchy_engine`，不改线上状态。

**单因素验证。** A0无带；A1同换手量的固定带；A2固定10bps成本单位门槛；A3逐票成本门槛。顺序推进，A3与A2只改成本异质性。先s42确认单位、费用、换手分解，再固定参数到s43/s44与原3seed融合书；不把这些种子当独立市场样本。逐年报告毛收益损失、成本节省和净差，分低/高成本组验证机制。A2不优于同换手A1时，不升级A3。

**失效与停止。** 分箱收益排序不稳定、置信区间宽过候选换仓edge、节省费用小于损失毛alpha、结果仅2021或单seed为正，都应停止收益改进主张。成本模型未校准时只能做压力研究。旧band失败增加怀疑，不证明所有成本门槛永远无效。

### P-B：固定入选集合，在等权附近做有限风险修整

**改变什么。** 固定当前Top-20成员，不中性化分数、不剔除薄票、不改K；在等权邻域求一个小幅权重修整：

`min_w  ||w-w_eq||^2 + lambda*sum_g[(b_g' w - u_g)_+]^2`，

约束 `sum(w)=1, w>=0, |w_i-1/20|<=epsilon/20`。首版只选一个风险：如行业总权重过上限；`epsilon`与一个业务风险上限预先固定，避免把几十个上限当新搜索网格。上限不可达时应明确报告残差，不能悄悄更换成员或放松规则。无超限时严格返回等权。随后才考虑加入一项换手惩罚；不可首轮同时优化协方差、行业、beta、流动性和收益预测。

**为什么、与旧实验差别。** 权重约束可降低估计误差导致的极端组合，是风险正则化的依据，不是额外alpha。[Jagannathan–Ma，NBER原文](https://www.nber.org/papers/w8922)。现有 `book_constraint_replay` 是按行业/流动性跳过候选并补下一只，成员变了；分数中性化也改变排序。此方案固定成员，只问是否能在较小收益代价下削减特定风险。现有Top-40已经给出简单而强的风险对照，新方案必须同时比较它，不能只挑Top-20。证据：`scripts/book_constraint_replay.py:100`、`:132`；`docs/experiment_ledger.md:300`、`:307`；`outputs/overnight_20261109/p15_combo_migration.json:61`。

**最小实现位置。** 独立replay中仅替换 `book_constraint_replay.py:146` 的等权向量；继续复用同一成员和记账。需要行业历史有效日期；现有申万当前快照只能支撑固定快照敏感性分析。首轮小问题不需要引入新优化库或训练接口。

**单因素验证。** B0等权；B1固定epsilon的单风险修整；B2同等换手预算的随机修整安慰剂；Top40为已知外部对照。s42先验证不超单股边界、权重和、无风险触发时逐位一致；随后s43/s44及融合书重放。逐年看风险暴露、周波动、下行半方差、最差周、ES与净均值非劣性，目标是风险而非收益。

**失效与停止。** 风险下降仅来自降低整体仓位或增加现金，要与同仓位基线重比；净收益损失超过预先约定容忍值、行业估计过时、约束经常不可达，停止。不能把 `volatility~1/K` 当普遍恒等式；相关性与单股方差会决定实际分散收益。

### P-C：负尾部按借券后的净价值选择，允许少于10只

**改变什么。** 保留多头规则。空头候选先满足时点正确的法定标的、券商实际可借数量、期限和申报条件，再用负尾分数的单独校准值评价：

`short_edge_i = -mu_hat_i - borrow_fee_i*holding_days/day_count - roundtrip_cost_i - recall_risk_buffer_i`。

仅 `short_edge_i>0` 才占槽，且 `shares_i<=available_shares_i`。不足10只留现金；每只原来的1/10槽位不向剩余名字重新分摊，以免把“少成交”变成“更集中”。持有期按实际退出日计费，禁止把周费率固定乘满仓后解释成精确融资成本。

**为什么、与旧实验差别。** 原P9指出名单过滤大幅削弱负尾信号，P10用高相关可融券票替代不能复制个股负alpha；现规则仍倾向在允许池中凑满10只。新问题是“最差的可借股票是否仍值得空”，而非“不可借股票的跌幅能否用别的股票复制”。P9 test `L3_c10` 年化14.86%，加8%/年券费的 `L4_c10` 降为6.04%、MDD约−58.85%；这表明纯空腿正毛收益不足以支持独立投资。该P9重放不是上述baseline_stack完全相同曲线，不混合数字。证据：`outputs/overnight_20261109/p9_short_decomposition.json:36`、`:47`；`outputs/overnight_20261109/p10_short_proxy.json:24`。交易目标同时考虑持有费用的框架见[Boyd等作者主页](https://stanford.edu/~boyd/papers/cvx_portfolio.html)。

**尾部非对称的含义。** 多头损失有限、空头上行损失与召回风险不对称，两腿不必共用同一个分数→收益校准函数；只分别校准尾部的收益尺度与费用阈值，不更改模型分数或尾部训练权重。负尾相关性、负尾极值和可借负尾净收益必须分别列出。

**最小实现位置。** 未来在 `skipfill_short.py:81` 候选补位处加净edge和数量约束，导出未满槽原因；`sizing.py:134` 消费相同券源/费率记录。历史数据缺失时不假造券商库存。先做纸面数据记录和乐观/悲观容量边界，不投入训练。

**单因素验证。** C0同一时点正确名单+强填；C1只增加逐票券费，保持原持仓；C2增加净edge拒绝和保留现金；C3再增加真实可借数量。先s42，再s43/s44与融合；账户本金、费用与保证金假设固定。分别报告纯空、与固定多头合并，以及与等比例降仓的对照。逐年重点分2024-07监管变化前后，同时报借券成功率、被拒绝预测alpha、召回次数、负尾条件校准误差。

**失效与停止。** 没有可靠历史券源时，停止“可部署历史收益”结论；净edge多数≤0时，结果可以是不开纯空腿，不能继续向更差分数的票补满。若收益改善只靠降低净市场敞口，需把beta效应剥离后再论alpha。现金保留导致的多空不平衡必须显式记录。

### P-D：实际可交易合约、同时间窗与保证金账本下的静态部分对冲

**改变什么。** 使用已有低频分数构建纯多腿，固定部分beta对冲比例，替代不可实施的股票空头或与其并列作为不同产品目标。首轮不重新搜索动态beta、不追求加杠杆匹配年化；以实际逐合约价格、整数手数、预先固定展期日和账户现金约束重建。

**为什么、与旧实验差别。** 11月8日静态对冲改善风险的研究值得保留，但它不等于实际合约收益。`hedge_backtest.py:161` 用主连周五收盘变化，而多头是周一开盘至下周一开盘；`:176` 忽略融资拖累，`:14` 明说忽略roll spread，`:32` 固定每周手续费未按真实交易量计。新方案要检验可实施性，不是再次证明指数对冲降低方差。用 `N_t=round(h*V_t*beta_hat/(multiplier*F_t))` 时，还须检查整数误差和保证金；若整数手数为0或1手超风险预算，结论就是该资金规模不适用。50万元是代码默认值，不能默认能实现任意连续比例。

**最小实现位置。** 未来在独立replay替换 `hedge_backtest.py:155` 的主连和收益窗处理，保留股票分数；不接生产。IM每点200元与合约到期规则取自[中金所官方合约](https://www.cffex.com.cn/u/cms/www/202207/18190308vxpv.pdf)。逐合约持有收益已包含基差变化时，不再重复扣一遍估计“年化贴水”；只加真实展期成交价差和费用。

**单因素验证。** D0股票腿；D1同时间窗指数理论对冲；D2实际合约、不计费用；D3加入展期、手续费、资金占用与整数手数；D4保证金压力。每一步只替换一个执行假设，固定h不重选；先s42，多seed沿用相同h，逐年报告总收益、beta、波动、最差周/保证金占用及现金缺口。只能在合约实际上市后的公共日期与基线比较，不能把IM历史指数回填成不存在的期货合约。

**失效与停止。** 可交易对冲后的风险下降小于基差、费用与机会成本；危机周保证金不足；手数使过度对冲；或收益只来自隐藏杠杆，则不进入下一阶段。该方案目标是降低组合风险，不能以更平滑曲线直接声称更高alpha。

## 4. 四项共用的验证约束

1. **先固定两本对照。** 模型研究用 canonical pure-long；部署验证必须用实际双版融合缓冲规则。每个候选先单腿归因，再统一账户资本合并；不要只拿单腿增益推算整个账户。
2. **先核验会计，再测机制。** 在零新增约束、旧固定成本下复现对照；再逐项加入时点名单、成交和资本账本。未成交持仓必须留在账上，缺价沿用、停牌、跌停卖不掉、涨停回补失败均不能直接删行或当完成交易。所有策略保持共同交易日；收益标签的自然周/实际交易周映射要冻结。
3. **分数不等于预期收益。** 用s42做实现/方向初筛，用同参数s43/s44检查模型随机性，再看3seed融合。若收益校准用val拟合，评估必须是val内时序交叉拟合或其后的保留段；不能同一val拟合并评价。任何重叠标签必须purge到完全成熟，且持仓边界真实接续。
4. **2021—2026已被反复看过。** 这段能做历史稳健性和失败诊断，不能再叫全新未触碰test。参数冻结后需要新的前向数据，或尚未用于设计的独立样本确认。逐年必须包含失败年份、2026不满一年标记和缺券源覆盖率。
5. **推断匹配主张。** 收益主张用配对周净差的区间，保留自相关；风险主张看方差、下行风险和收益非劣性，不以Sharpe点估计一票决定。时间block bootstrap在同一个时间块联合抽取所有seed，避免把3个seed×283周当849个独立市场周。多重检验按本次实际搜索的候选家族校正；旧报告t=2.5或max|t|门限是特定协议，不能变成普遍统计定律。
6. **最小停止规则。** 先做一项、一种主机制、极小预注册参数集。若毛损益机制不成立、经济增益小于成本误差、跨seed方向反复或负面年份不可解释，停止扩参。证据不足可记“未解决”，不写成“数学上无效”；方差降低也不能自动升级成收益提高。

统一账户报告至少包括：`V`、多空名义敞口 `L/S`、gross exposure `(L+S)/V`、net exposure `(L-S)/V`、实际成交额、毛P&L、交易费、券费、融资利息、对冲/展期P&L、冻结卖空所得、保证金和自由现金。纯空以实际分配资本为分母；50/50序列平均只是研究组合。当保证金率为m、仅现金担保、预留r且两腿等额时，可行腿名义上界约为 `X=V*(1-r)/(1+m)`，真实券商担保折算和维持保证金另行进入账户账本，不从研究Sharpe倒推杠杆。

## 5. 执行顺序与当前结论

先整理冻结定义、时点券源、会计和成交证据；在现有分数上优先评估P-A的经济机制，P-B以风险目标小规模验证。P-C取决于真实券源与报价，数据不够就停在边界分析；P-D取决于合约数据、资金规模和交易权限。现有Top-40保留为已测风险基准，不包装成新发现。
