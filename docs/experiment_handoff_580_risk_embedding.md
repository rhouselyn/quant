### 0.2 时间、数据与评估契约

1. 全部 join 用 `(date, symbol)`，`symbol` 保留交易所后缀，`date` 表示周五锚点。交易日用实际交易日历。输出 `decision_at / entry_at / planned_exit_at / exit_at / label_available_at`，用北京时间。标注的收益只用于事后训练、校准和评估，周五候选池只依赖当时已知字段。执行代理可在开盘应用 `tradable`，必须两侧一致，且单列未成交与补位假设。
2. 开发主读数用 2020 年、风险校准从 2018–2019 年已成熟标签起步。可逐周扩展，未来标签在当周决策前成熟才可进入拟合。现成的基线权重或 epoch 曾用整段验证选过，2020 仍叫开发窗。严格独立检验须事前冻结规则并采集以后数据。2021–2026 已反复用于探索，合格方案只能按预注册读一次历史复检。各日期边界以实际配置和决策时间校验，保留原训练末 5 周预留，验证尾部按成熟时间裁掉。对 open-to-open 快照至少检查末两个验证锚点。
3. `realized_return` 是对数收益，组合 P&L 用 `expm1`。同一比较中的各臂用相同持有期、成交政策、缺失处理和成本。对账可复现旧版缺收益记平的假设并报告数量。新风险标签缺价格就标记不可构造，生产回放也要单列停牌、缺失和未平仓。每次输出完整日历及缺周原因，禁止静默 inner join 丢周。配对分析只用双方可比较的同周结果，列出交集之外的周及原因。
4. 纯多主账本用 Top-20 等权、单边 10 bps、同一个股票池的比较基准。Top-40 是固定风险对照。多空后续复用 v2 的 PIT 券源名单定义，固定成本和借券费做情景分析。旧融合分数有的丢了 `tradable`，先用 `arrays` 或按 `(date,symbol)` 从原分数补回，再让各臂按同一规则使用。若走 `prepare_groups` 后把结果传给回测，须提前应用执行过滤，否则回测会跳过它。
5. 每臂在看收益前写 `protocol.json`，含 experiment_id、父 run、git commit 和脏文件清单、配置差异、seed、日期清单或边界、epoch/融合规则、费用、输入文件 hash、计划主指标、候选数和晋级门。保存 `predictions.parquet`、`weekly.csv`、`metrics.json`，有拟合时加 `fit_audit.csv`。只拟合一次的对象也记录拟合截止时间。遇到既有输出，只有协议和输入 hash 一致且产物验收通过才允许复用。
6. 净收益差定义为每周 `candidate_net - control_net`，以 bps/周报告均值，另报毛收益、成本差、年化、Sharpe、周波动、最大回撤、最差周、换手、按年分解。用相同日期顺序的配对 8 周块 bootstrap，5,000 次，固定 seed 42，给 95% 区间。整段一起重抽各臂，保留连续周关系。多 seed 共用市场周，先同周合成再算区间，单 seed 方向另报。小样本/区间跨零记为不确定。多候选记录试验次数，进入正式候选前按仓库要求运行适用的 DSR/PBO 检查。

**默认筛选门，运行前锁定。** 收益型实验的默认晋级门是开发段配对净均值至少 +5 bps/周，两个半年方向同正，最大回撤恶化不超过 2 个百分点。风险型实验的默认门是同平均敞口对照下周波动至少相对降低 3%，净均值损失至多 5 bps/周，最大回撤恶化不超过 2 个百分点。阈值只用于决定是否投入下一步。样本外区间和交易约束单列，无法认证时写 `INCONCLUSIVE`。复现训练先 seed 42，达门后才加 43/44，要求至少 2/3 seed 同向且融合仍达到门槛。风险型 R2 还要过下文的预测准确性门。

## 1. 冻结模型给扩展池打分

### 1.1 数据源分支

优先建设一份同源扩展池。复用 akshare 580 现有 hfq 价格、原始量额的口径，先检查本地归档，缺失的股票若补数据，写新目录并保存每只股票的来源、复权类型、抓取日和 hash。按共同日期和同一特征版本准备缓存。当前历史 1,893 缓存能做低成本探针。使用它时先核实交集原始文件来源，再从**同一份宽池数据**切出原 580 的重叠子池，做旧源内部对照。将其标成 `legacy_source_probe`，结论最多用于判断是否值得补同源数据。

日历按日期映射切分。2004 起点的缓存索引与 ak2000 不同，直接沿用 939、1096 会把边界移到别的年份。构造 open-to-open 标签复用 `arrays` 的契约，周线缓存的 `target` 是 close-to-close 字段。整个阶段记录股票池为历史时点池或当前快照回溯池。后者的结论限定在回溯样本。

### 1.2 U0 对照和 U1 扩展

1. **U0 用 seed 42 的冻结 `best.pt` 只打重叠子池。** `HierarchicalRanker` 的 `industry_ids` 是持久 buffer，直接用宽池构造模型再 strict load 会遇到形状不符。用原 580 的行业 id 构造模型并 strict load。确认关系门为零、无 cross-stock block、无 market FiLM、无 daily branch。用原池逐个检验以下单股推理路径和 `predict` 输出的原始分相同，再对任意规模的池用它。

   ```python
   model.eval()
   with torch.inference_mode():
       temporal = model.encode(windows)  # [B, N, lookback, n_features] -> [B, N, D]
       score = model.score(torch.nn.functional.normalize(
           model.final_norm(temporal), dim=-1
       )).squeeze(-1)
       score = score.masked_fill(~available, float("nan"))
   ```

   如冻结关系的前提不成立，停止该旁路，记录模型差异。分日期、分股票块推理，显存不足就减推理批大小。调整批大小后用 D0 样本复核数值一致。

2. **U1 给全池打分，U0 与 U1 固定同一输入参照。** 仓库先用训练段的有效原始特征 fit 均值和标准差，缩放后 clip 到 ±8，再用每个锚点当期有效参照股做横截面标准化并 clip 到 ±6，最后对无观测槽位执行已有的向前携带规则。新脚本复用 `hierarchy_data.arrays` 的可评分掩码、特征顺序、40 周窗口和 32 周最小历史门，提取或小范围复用标准化代码。同源主实验用原 580 计算训练期统计与当周参照统计，允许参照股只用于归一化而不参与宽池选股。旧源探针用旧源重叠子池计算两套统计并记录变更。截面参照无观测时沿用原缺失路径并输出该周计数。
3. 给宽池各周的每只有效股写 `raw_score`、`score`、`available`、`is_baseline_member`、`tradable`、`realized_return`。单模型排序直接使用原分。只有进入多模型融合才需要模型间逐周对齐。对重叠股，U1 与 U0 的输入和原分应一致到 D0 容差；若不一致，先修输入参照。单独做可选诊断 U1-F，把参照换成全池并对重叠股报告秩相关和 Top-20 交集，作为池内标准化敏感性。
4. **主对照是同一周的两本账。** 基线从重叠子池选 Top-20，候选从宽池选 Top-20，执行政策和成本相同，比较净收益差。另报新增股独立的周 RankIC、新增股入选比例、候选新增股替掉的旧股，以及替换前后毛收益和换手贡献。用当周行业×成交额分位做匹配基准诊断，匹配不足写有效样本率。候选与对照用同一个外部基准，禁止用两个不同股票池各自等权后把超额差当作主证据。相同尾部比例只做诊断，较宽池取约 Top-65。
5. **产物和晋级。** 写 `u1/predictions.parquet`、`u1/weekly.csv`、`u1/coverage.csv`、`u1/replacements.csv`、`u1/metrics.json`。主净差、两个半年和回撤达第 0 步门槛，且新增股的替换贡献方向为正，才进入 U2。旧源探针即使达门，也要先在同源数据上确认再训练 U2。若需要证明训练覆盖是否补救外推失败，将其作为单独问题重新登记一组最小对照。

## 2. 学组合波动，再决定仓位

首轮做纯多，使用第 0 步重放一致的固定 Top-20 选股，Top-40 等权作对照。风险模型和分数模型分开。拟合只使用能按下述合同计算出的组合标签。该实验复用冻结分数，无需重新训练选股模型。

### 2.1 组合风险标签

1. 从周回放导出每周目标及实际成交的 `(date, symbol, weight, entry_at, exit_at)`。先记录不加仓位规则的基线持仓。确定性排序、选股、成交过滤与 D0 相同。选股在周五做，成交回报只进执行模拟。
2. 预先构造每段实际交易日的开盘到下一个实际开盘收益，价格用与周账本一致的复权口径。固定一个周入场和计划退出窗口。用持仓数量和当日估值计算组合的逐日简单收益，权重随价格漂移，中间没有调仓则不做日度再平衡。无成本、无延期的一周，`prod(1 + daily_gross) - 1` 要等于同持仓的周毛收益，容差 `1e-8`，用合成数据加一组真实完整周校验。
3. 目标为 `RV_week = sum(daily_gross ** 2)`，单位为周方差。缺开盘、停牌和延期退出有单独标记。第一版风险拟合只用持仓期和日路径能完整核对的周，目标缺失周保持在交易日历并输出原因，收益回放仍按共同执行规则处理。完整周不足开发窗的 95%，先查缺失是否集中在高风险期，记录 `BLOCKED_DATA`。有完整路径时再扩展到下行风险。多空的逐日风险用签名权重合并，协方差由真实两腿同日变动体现。
4. 输出 `risk_targets.parquet`，每周一行，至少含 `date, entry_at, exit_at, label_available_at, valid_rv, rv_week, n_intervals, missing_reason`。风险特征可以用周五已知的市场波动和计划持仓的历史波动。验收时把某个未来日价格改掉，预测输入必须逐值相同，允许未来标签改变。把一段延迟标签推迟成熟日，拟合审计应显示相应观测被排除。

### 2.2 三个实验臂和拟合

| 臂 | 定义 |
|---|---|
| R0 | Top-20 固定满仓，Top-40 固定满仓。另建与动态规则平均仓位接近的固定 Top-20 对照 |
| R1 | Top-20，使用已成熟的组合 `RV_week` 做 EWMA，半衰期预设 8 周，初值用最早 13 个成熟有效周的平均 |
| R2 | Top-20，在 R1 方差上加一个小型对数修正。仅用 2 个预设特征，市场 20 日已实现方差和计划 Top-20 的平均过去 20 日方差 |

R2 用 `eta = log(v_EWMA) + intercept + beta @ x`，`v_hat = exp(eta)`。将两个方差取 log 后按每次训练窗内统计标准化，方差下界 `1e-8`，标准化输入 clip 到 ±5。仅用在决策前已成熟的周拟合，至少 52 个样本。从 2018–2019 起步，每 13 周重新拟合一次，其他周复用最近系数。用已有 NumPy/Torch 做小型拟合，损失取 `mean(eta + rv_week * exp(-eta)) + 0.01 * sum(beta**2)`，截距不惩罚。以 R1 的同周方差为 offset，记录优化是否收敛。预测输出非有限或拟合失败时回退 R1，并在 `fit_audit.csv` 写明原因。

R1 和 R2 共用决策函数 `gross = clip(0.8 * target_vol / sqrt(v_hat), 0.6, 1.0)`。应用段的 `target_vol` 为 2018–2019 校准标签中、在首个应用日决策前已成熟的 `sqrt(RV_week)` 中位数，应用段内固定。R0 的同敞口对照，用 2019 校准段双方均有逐时可用预测的日期，按各自规则确定平均仓位，在应用段固定。计算 2019 决策时的 `target_vol` 也只能使用截至该时点已成熟的标签。报告应用段实际平均仓位差。差距大时再报用实际平均仓位构造的诊断性常数回放，标明它使用了事后信息。

每周目标股票权重乘 gross，剩余为现金。计算 `turnover = sum(abs(target_w - prev_drifted_w))`，包含加减仓引起的真实交易额。使用和长腿对账一致的乘法成本 `net = (1 - turnover * bps/10000) * (1 + gross_return) - 1`。用周末价格漂移更新下一周的 `prev_drifted_w`。复用 `long_only_backtest` 的转换和记账逻辑，若需要提取权重回放辅助函数，先写固定 gross=1 的逐周等价检查。动态仓位成本由实际权重路径计算。

**验收和晋级。** `gross=1` 复现 R0，`gross=0` 且从空仓起步产生现金收益 0，预先有仓再降到 0 产生卖出成本。R2 先与 R1 在同一批有效周比 QLIKE，取逐周差 `L(R2)-L(R1)`。开发窗均值为负、两个半年同向，且 R2 的实际控仓过第 0 步风险门，才有资格采用 R2。若 R1 同时做到更高净均值、更低周波动和不差的回撤，P1 以 R1 为起点。若只有 R1 达门，同样保留 R1。报告 Top-40 是否已在同样收益与风险条件下做到相同效果。输出 `r2/risk_predictions.parquet`、`r2/fit_audit.csv`、`r2/weekly.csv` 和 `r2/metrics.json`。

## 3. U2 用一个模型训练，每次轮换约 580 股

### 3.1 对照和采样

1. **U2-A 固定池。** 从同源宽池取 canonical 名单中存在的股票。**U2-B 轮换池。** 在同一批训练锚点，从宽池当周可评分股票里选择。两臂都在同一个宽池评估，使用 U1 的输入参照与执行账本。U2-B 每周每行业的有效名额等于 U2-A 当周该行业可评分数，合计上限 580。这样每步规模、行业梯度配比和早年可用宽度相近，改动集中在股票身份。首轮给两臂相同的 8 epochs、日期顺序、模型宽度、优化器、seed 和损失权重。训练与截面参照统计沿用 U1 的固定参照，各自逐周抽样前就已算好。
2. 每个训练 epoch、每个训练日期，在每个行业优先选此前累计抽中次数少的股票。同次数用独立、可复现的随机数打破平局，例如 `SeedSequence([seed, epoch, date_index, industry_id])`。日期按训练循环的实际顺序更新计数。源池成员资格只用该日期的 `available`，包括观测和历史长度，**不使用收益有效性、未来教师可用性、下一周开盘或收益大小抽票**。允许相同股票出现在不同周，禁止同一个日期截面重复股票。日志同时输出股票的入选次数和可入选机会数。固定池在某周该行业无可评分股时，两臂该行业名额都为零。
3. 实施时把每个日期抽中的索引放入矩形 `stock_indices[B, K]`，短行用 `slot_valid` 标记 padding。收集窗口、标签、行业、当周可用性，以及**同一索引**对应的未来教师窗口。把 `slot_valid` 与原掩码合并，padding 一律无效。模型用宽池行业 id 初始化，评分走第 1 步验证过的冻结关系旁路。保留原有极端尾标签、RankIC、5 周 InfoNCE 和行业暴露损失，各自在**采样后**截面上计算。首轮尾标签依原逻辑按所抽截面建。另改全池分位标签会改变监督，留给独立实验。对照也走相同的 gather 与旁路。
4. 实现位置是 `hierarchy_engine.train` 的 batch 构造和 InfoNCE 取窗处。新增功能用显式配置开关，默认维持原调用。把原 `batch_size` 理解为日期数。采样发生在 encoder 前，避免先算全池 embedding 再丢弃。为了固定比较预算，若显存要求减日期 batch size，两臂一同调整并记录。验证用确定的全宽池打分，绝不调用训练采样器。

### 3.2 校验与验收

- 人造两个日期、三个行业，验证逐行业数量、无重复、padding 不参与损失。改动未来标签、教师未来 mask 和后续日期数据，断言同一日期在相同采样器初态下索引不变。
- 在小截面中传入全部原股票、保持其顺序及所有 mask。用同模型、同 RNG，比较原路径和新路径的 logits、各分项损失及共享参数梯度。测出容差并在协议中锁定，同设备起始目标 `atol=1e-5, rtol=1e-4`。配置关闭时跑现有层级测试。
- 先跑 1 个 epoch 冒烟，检查采样分支实际触发、所有损失有限、可评分率和覆盖有变化。通过后 seed 42 跑完整 8 轮。开发读数用第 0 步固定窗口，不能看完曲线再改窗口。单 seed 达收益门才扩 seed。两臂都输出采样 coverage，检查新增股有效覆盖、各行业名额和模型实际处理的股票窗口数。
- 输出 `u2/{fixed,rotate}/` 的配置、训练日志、`sampling_summary.csv`、开发预测和 `u2/paired_weekly.csv`。U2-B 在同宽池账本中过第 0 步的复现门，才进入 U3。记录 U2-B 与 U1 冻结扩池的收益对照，避免把重训的额外价值误算成扩池收益。

## 4. E0/E1/E2 下一周 past60 表征

这里把 `past60` 定义为 **60 个实际交易日**。首轮用固定、可审计的 9 维价格路径编码作教师，以便先验证增量监督。当前 canonical 用 40 周输入，已有未来 5 个周 bar 的 EMA InfoNCE；它不自带一个经验证的 60 日教师。未来一周的真实数据仅用于构造训练目标。

### 4.1 构造标签和持久性对照

1. 从 canonical 日线构造截至 (t) 与截至下一周最后交易日的 60 日窗口。用交易日历对齐，并额外读取第一天之前的有效收盘用于计算第一条收益。每日 `cc=log(close/prev_close)`、`on=log(open/prev_close)`，价格口径与特征相同。任一所需开收盘缺失、非正或跨停牌导致收益间隔错误时，将该股该周的辅助标签标为无效。训练的收益分支仍用原掩码。
2. 定义固定编码器 `E60`。对最后 5、20、60 个交易日分别输出 `sum(cc)`、`log(1e-8 + sum(cc**2))`、`sum(on)`，拼成 9 维向量。输出当前向量 `z_now` 和下一周结束后实际向量 `z_real`。下一周实际包含 (k) 个交易日时，旧数据通常还共享 (60-k) 天。节假日按交易日历处理，完全无新增交易日则跳过该锚点。
3. 用**同一个下一周窗口日历**把新增 (k) 天的两个收益通道置零，其余真实已知历史保持原值，得到 `z_roll`。训练目标 `delta = z_real - z_roll`，这样窗口滚出最老几天引起的确定变化由 `z_roll` 表达。输出 `date,symbol,label_available_at,valid,z_now,z_roll,z_real,delta`。按训练有效标签 fit 每维均值和标准差，std 下界 `1e-6`，在验证和推理上只复用训练统计。
4. 两条零训练对照是 `z_hat=z_now` 和 `z_hat=z_roll`。将模型预测的 `delta` 反标准化后加到 `z_roll`，在相同有效样本上比较目标重建误差。用训练窗拟合的每维尺度统一误差单位。教师用确定性规则，无需先在宽池上训练一个模型。

### 4.2 模型和实验臂

| 臂 | 辅助任务 | 目的 |
|---|---|---|
| E0 | 保留原 5 周 EMA InfoNCE | 冻结对照 |
| E1 | `temporal_weight=0`，保留相同训练锚点 | 控制移除原辅助任务的影响 |
| E2 | 在 E1 加下一周变化预测 | 单独量化新监督 |

E2 在时间塔返回的 `temporal[B,N,D]` 上接一层 `Linear(D,9)`。损失 `loss = 原主损失 + 0.1 * masked_huber(delta_hat, delta_target)`，标准化空间 Huber `delta=1`，先按有效维度求均值，再按有效日期求均值。有效日期没有可用标签时辅助 loss 返回与模型图相连的 0。该头只在新配置下实例化，并在基础模型参数初始化之后创建，避免扰动对照的初始化。把新头加入同一 optimizer 与梯度裁剪，标量收益分数沿原 `score` 路径输出。三臂 `common_training_horizon=5`、训练日期、epoch 窗口和所有主损失保持一致。额外检查辅助标签成熟时间早于训练切分。E0 可复用冻结分数，但新 runner 的 E0 冒烟要证明与原路径对得上。

实现从 `hierarchy_engine.train` 的辅助 loss 位置接入。保存每轮训练/验证辅助有效率、各维预测和误差。验证时单独导出辅助头预测用于诊断。正常收益打分只需要原先的输入。用合成未来窗口检验无未来输入、缺失股只影响辅助掩码、去掉辅助权重时主 logits 和主 loss 与 E1 相同。把 `delta_hat=0` 反标准化后的期望值校验清楚，零变化基准要在原始目标单位上定义。

**完成和晋级。** E2 必须在同一批有效样本上，重建误差低于两条零训练对照，且开发账本同时胜过 E0 与 E1。对 E0 用第 0 步收益门，对 E1 要求净差方向为正。seed 42 达门再复跑 43/44。输出 `e2/embedding_eval.csv`、`e2/weekly.csv`、`e2/metrics.json`。通过复现后可登记 E3，把新任务与 5 周 InfoNCE 相加。若后来换成神经教师，先证明它只在本折训练窗拟合，再重跑持久性和滚动零收益对照。未来若采用对比损失，可用行业和波动档匹配负样本作诊断，记录有效负样本数和股票身份捷径。

## 5. 条件实验

### 5.1 U3 多组 580 的覆盖和融合

启动条件是 U2 完成复现，并有同源大池。先生成 `panel_membership.csv`，含 `panel_id,symbol,industry_id,is_anchor`。用训练截止前可得信息固定约 100 只共同锚点，覆盖行业和流动性档。每组其余约 480 个槽位用于轮换，优先按行业满足覆盖，再按股票当前累计入组次数由少到多填充，固定 seed 打破平局。训练前算出每只股票实际覆盖次数与各组 Jaccard。全池 1,893 股、100 锚点时，忽略行业约束至少 4 组才能覆盖一次，至少 8 组才能让非锚点股都覆盖两次。严格每行业每组 20 只时，最多 157 股的行业即使无重复也至少 8 组才能覆盖一次。先按实际名额算组数和 GPU 预算，再启动训练。

每组固定一个模型，使用 U2 的共用参照和固定比较口径。若各模型都能打全池，同周对同一有效宽池分别算均值、标准差并 z-score，再对同股取模型等权平均。若各模型只能给组内股票打分，在每周共同且有效的锚点上计算每模型的位置和尺度，变换组内股票后再融合。共同锚点少于 30 或某模型当周 std ≤ `1e-6`，该模型该周的融合无效，记录原因。输出 `n_models`、覆盖率、重复率、校准前后同股秩差、仅单模型高分的入选比例。无有效打分的股票保留缺失。最终全局 z-score 只用于分数展示。

至少比较 **等量独立 seed 的共享全池模型**和**子池模型集成**，报告训练窗口次数与耗时。若混入多个 epoch，先在各模型内按逐周 z-score 和算术等权聚合，再做模型间校准。只有子池组在同口径账本和覆盖检查中达到第 0 步收益门才继续。效果只来自改变入选池或单模型极端分数时，按此归因。

### 5.2 P1 基线策略上做仓位决策

R2 或 R1 的仓位规则先通过第 2 步，并有可对账的逐周持仓与费用数据，才值得加动作。第一版固定基线选股，把动作设为总敞口 `g ∈ {0.6, 0.8, 1.0}`。多空可成交数据具备后，再单独试净敞口 `n`。用正的腿名义定义 `w_L=(g+n)/2`、`w_S=(g-n)/2`，保证 `abs(n) <= g`，且记录实际 beta、未成交和有效敞口。每个空头名义同时受真实券源数量、费率、到期和召回约束。历史上只有 PIT 代理的周可做情景回放，部署可行性用有实际券源的记录核验。

1. 从同一个历史状态克隆几份，逐一回放有限动作，输出当周扣交易和持有成本后的回报。若会改变持仓和下一周状态，计算下一周时必须各自沿本策略状态滚动。检查动作结果为真实可回放范围，历史没有的成交和券源保留缺失。
2. 首轮学习用小型监督模型，按动作估计净收益与风险或直接估计同一固定风险效用。只用当时已知的风险预测、上一周持仓和当前回撤。比较固定动作、R1/R2 原规则和学习动作，复用第 0 步门。至少对账手算的开仓、减仓、调比例和缺券四种情况。
3. 若有限动作模型达门，并能从日志展示延迟成交、未平仓或路径回撤导致跨周依赖，再试离线 RL。保持动作同样离散且靠近 baseline。状态含净值、历史高点、持仓和券源，收益用 `log(1 + net_return) - lambda * max(0, drawdown_next - drawdown_now)`，其中回撤取非负损失率。成本只扣一次。以与监督策略相同的费用、相同平均敞口、相同时间切分做对照。首轮只定一套动作与奖励参数。若样本量或券源支持不足，在 `p1/metrics.json` 标 `BLOCKED_DATA`，保留规则控制结果。

### 5.3 P2 从 Top/Bottom 各 K 中重排

先检查候选尾部分数在开发窗之前成熟的数据上能否稳定映射成下一周收益。可用分位箱均值收缩到该腿均值，每次只用成熟标签。分别检查多头尾部和可借池空头尾部。用周内候选边界附近的同业、近流动性匹配作为诊断。若样本不足或分档关系跨两个校准段反转，停止可学习重排。仓库此前的分数收益校准与成本门槛曾跨窗反转，这一门必须先过。

1. 候选先固定为多头 Top-40、空头 Bottom-30。第一轮只在多头选 20 并等权，和原 Top-20 同口径比较。空头另做，从既定流动性池与可借名单选至多 10 个，每个保留原预算的 1/10。空头成本含借券费和进出场成本，合格票不足可留现金。两侧候选按 `symbol` 去重，权重符号独立约束。
2. 先做可解释的贪婪重排。每个候选用已校准的预期收益减实际预计交易成本，已有持仓与新入选票分别算边际成本。多头风险权重首轮固定等权。需要加入风险时再开一个固定成员定权臂，比较 `mean_return - risk_penalty - turnover_cost`，并把单票、行业、流动性和净/总敞口上限写在协议里。
3. 如果训练连续权重，评估时也按实际的截断、分配预算、手数、成本与成交重放。若有限于最小手数、停牌或借券导致不足，按执行逻辑保留现金和未成交量。主表写持仓前后变化、权重、实际成交与费用。零信号或零调整开关下必须逐周复现对照。

P2 只有在基础尾部收益校准和同口径重排通过收益门之后才扩至双腿或可学习权重。P1 与 P2 的结果各自和同一冻结基线比较，最后只对各自通过的变更登记一个组合复检。

> 按本手册执行本地研究。先完成第 0 步并写协议，然后实现 U0/U1 和 R0–R2。每个分支先用小样本验收，再输出完整开发窗。缺数据就写出缺哪一项、哪些日期或股票受影响，并继续可独立完成的分支。达门才启动后续训练。交付代码位置、运行命令、逐周数据、指标和最终状态表。
