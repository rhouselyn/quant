# P64 与 CS×P64 旧 checkpoint 复核

2026-11-13（北京时间），状态 **完成**。父实验为旧 `weekly_architecture_v1`。本轮按 [管道补齐与 P64 复核协议](research_20261113_pipeline_completion_protocol.md) 执行。旧权重、旧预处理及数据指纹的登记见 [批次冻结协议](../outputs/dataset_v2/p64_recheck_v1/protocol.md)。

本次复用旧批次 B0、CS、P64、JOIN（CS×P64）各 3 个种子的 8 轮权重，共 96 个 checkpoint。按 2018–2020 年的 153 个成熟验证周，对每个模型和种子的 L20、S10 分别以扣费 Sharpe 选择单轮，再取居中 3 轮融合，边界固定取最前或最后 3 轮。锁定后评估 2021-01-08 至 2026-10-23 的 297 个成熟测试周，最后退出日为 2026-11-02。三种子模型融合股票截面分数，再重建组合。测试区间此前已有历史暴露，本次结果用于历史复核。旧档未重训。

旧四臂使用同一训练输入和标签版本。旧特征的数值、观测掩码和可用时间摘要均与归档指纹一致。用原权重复现旧验证尾部全部 96 组分数，最大绝对差为 1.79×10⁻⁷，并补算 2020-12-25 验证周。结算使用统一的 V2 日期与标签、原始开盘价可成交近似、历史交易所资格名单，以及每边 10/30bp 的交易费和 8.35%/12% 的年化借券费。验证期间 39 周覆盖双交易所名单、101 周覆盖单交易所、13 周均缺，缺失份额留现金；测试 297 周均有两市名单。券源数量、真实成交与公司行为处理仍受代理口径约束。固定 580 股票池及静态行业标签亦限制外推。

## 改动和可比较范围

P64 保留周输入投影 `Linear(30,128)`，并在原 LayerNorm 前加上并行残差 `Linear(30,64) → GELU → Linear(64,128)`。末层权重和偏置零初始化，模型宽度仍是 128。残差新增 10,304 个参数。B0、P64、CS、JOIN 的可训练参数分别是 1,467,393、1,477,697、1,500,161、1,510,465。

P64−B0 和 JOIN−CS 分别估计未启用与启用 CS 时加入该残差投影的整体效果，包含新增参数和独立验证选轮的影响。JOIN−P64 同时增加 CS 与 32,768 个参数。旧批次没有 CS_SELF×P64 的参数匹配对照，无法从该差值单独识别跨股信息的贡献。

## 三种子融合

主档每边 10bp，借券年化 8.35%。表中为扣费 CAGR。

| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| B0 | 13.71% | 2.32% | 12.16% | 26.23% | 4.06% | 18.75% |
| CS | 17.51% | 17.36% | 21.84% | 15.93% | 9.58% | 16.86% |
| P64 | 15.24% | 2.81% | 13.17% | 27.24% | 1.89% | 18.07% |
| JOIN | 18.96% | 16.62% | 22.28% | 17.70% | 11.08% | 18.49% |

| 旧批次 | s42 多 / 空 | s43 多 / 空 | s44 多 / 空 |
| --- | --- | --- | --- |
| B0 | 1–3 / 1–3 | 1–3 / 5–7 | 2–4 / 6–8 |
| CS | 1–3 / 6–8 | 1–3 / 5–7 | 6–8 / 4–6 |
| P64 | 1–3 / 1–3 | 1–3 / 6–8 | 2–4 / 5–7 |
| JOIN | 1–3 / 6–8 | 1–3 / 5–7 | 6–8 / 5–7 |

- **JOIN−CS。** LS50 三种子融合的 CAGR 差为验证 +0.45 个百分点、测试 +1.63 个百分点。以同周净收益做 8 周块 bootstrap，验证每周均值差 +0.86bp，95% 区间 [−5.65, +7.71]bp。测试每周均值差 +2.67bp，区间 [−2.83, +7.96]bp。s42、s43、s44 的验证 CAGR 差为 −0.31、+0.33、+0.53 个百分点，测试均为正（+3.55、+2.38、+1.63）。30bp/12% 档的融合差为验证 +0.56、测试 +1.50 个百分点，区间仍跨零。
- **P64−B0。** LS50 融合差为验证 +1.01 个百分点、测试 −0.68 个百分点。配对每周差的区间均跨零，验证 [−5.29, +9.39]bp，测试 [−7.60, +5.94]bp。三个单种子的验证差为 +1.59、−2.02、−0.22 个百分点，测试差为 +0.52、+0.47、+1.15。截面分数融合会改变入选股票和成本，融合收益可与各单种子的方向不同。
- **JOIN−P64。** LS50 融合差为验证 +9.11 个百分点、测试 +0.42 个百分点，两个配对区间均跨零。三个单种子的验证差均为正（+3.48、+8.32、+4.29 个百分点），测试方向分化（+6.96、−1.59、−1.64）。30bp/12% 测试差降至 −3.32 个百分点。
- **费用与空腿贡献。** JOIN 的 LS50 相对同多腿加现金，测试主档高 +8.98 个百分点，配对每周区间 [−12.10, +35.31]bp。在 30bp/8.35% 与 30bp/12% 下分别为 −0.21、−2.03 个百分点。JOIN−CS 的 S10 验证差为 −0.74 个百分点，三个种子为 −3.24、−0.10、+6.30。测试融合差为 +1.50 个百分点，三个种子为 +4.35、+1.98、+4.31。两段 S10 每周配对区间均跨零。JOIN−B0 的 LS50 在验证主档为 +10.13 个百分点，配对每周区间 [+0.68, +32.96]bp。对已成交但结算收益缺失的头寸施加 20% 不利损失后，该区间跨零。测试主档为 −0.26 个百分点，30bp/12% 为 −3.81 个百分点。

三年验证对 JOIN 相比 CS 的 LS50 边际收益支持有限，单种子方向混合且同周区间较宽。现有结果不足以确认 P64 残差带来稳定增益，或 JOIN 的空腿扣费增益能在高成本档维持。
