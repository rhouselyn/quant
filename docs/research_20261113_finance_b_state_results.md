## 结论

**第一版应在“市场＋行业＋行业内残差”的收益 decoder 上增加现有六维市场状态的低秩条件项，而不是重做市场 FiLM。** 保留股票时序主干；状态输入只用已有 `M_t`，没有新外部数据、没有新市场时序 encoder、没有新增股票特征。616 个新增参数足以检验：同一相对股票表示在不同绝对市场环境下，是否需要不同收益映射。只称待验证假设，不预设“高波动一定压低收益”“成交活跃一定利好多头”等方向。

旧 M1 已经试过市场 FiLM，三 seed 旧实验相对 canonical 为 −9.2bp/周；M1+F1 为 −23.1bp/周，均未采纳。新假设与旧尝试的差异是收益单位的受约束 decoder、显式分离共同均值与股票异质响应，不能把旧模块改名后当新发现。行业绝对状态只列后续单独增量，不与第一版同时改变信息集。

与 A/C 分工对齐：`mu_log = market + industry + alpha`，score 使用 `mu_log`；本报告的状态项接入三个原始头后再做 A 的固定候选 mask 中心化。C 的风险尺度独立使用状态，不进入排序分数；简单收益均值只作分布 sidecar。这里的 `mu_log` 是个股下一持有期 log 收益条件均值，不是组合 log 效用、简单收益均值或因果 alpha。

## 1. 金融问题：相对位置不足以识别共同环境

对原始特征写成 `x_it = ell_t + d_it`。忽略截断且全局缩放为仿射时，当周截面标准化满足：

    zCS(x_it) = (d_it - mean_i d_it) / sd_i(d_it).

共同水平 `ell_t` 消失，正的共同尺度也消失。实际实现先训练期缩放、截断，再当周截面缩放，因此不能声称严格对任意共同变换不变；但不同绝对环境确实可能产生相同/相近相对输入。收益、波动和成交活跃度的整体水平，不能靠“每周股票之间谁更高”完整恢复。`h` 的市场均值可能包含分布形状信息，却不是未标准化市场水平的充分统计量。

金融假设是条件关系而非方向定律：

    E[y_i,t+1 | F_t] = f(relative_stock_history_it, observable_market_state_t).

例如，同样处于波动最高分位的股票，在全市场平静与市场剧烈波动时可能具有不同未来均值和误差尺度；行业相对强弱也可能在不同市场状态下具有不同延续性。方向、幅度和是否存在均由训练/验证判断。成交活动指标只代表活动度，未观测买卖价差、冲击和可借券约束前，不将它称为真实交易流动性。

共同加性 `b(M_t)` 对当期任意股票对有 `s_i+b - (s_j+b) = s_i-s_j`，不改变横截面排名；共同正乘数也不改变单模型当期排名，且会被后续截面 z 融合抵消。它仍可改善绝对均值预测和分布校准。要改善选股排名，需要股票/行业响应不同的交互，或改变交易决策规则；本轮只研究前者，不顺带引入择时仓位。

## 4. 第一版：616参数的 M6 条件金融 decoder

父对照是 A 的均值头无 M 版本收益 decoder。`z_it∈R^128` 仍由原时序表示得到，行业组和等权候选 mask 在决策时确定。设 `n_g` 是有效候选数，`p_g=n_g/N`；所有组均值只依赖输入可用性，不依赖未来标签成熟或未来收益。未知行业按 A 的明确兜底分组处理，不伪造所属行业。最终统一基础头：市场池化 `cM=mean_i z_i` 进128→16→1；行业头 `[cg;cM]` 进256→16→1、末层无bias；`a0=w_a^T z` 无bias。这三头不再拼M，避免与下面616参数重复加状态。

### 状态编码与共享机制

    c_t = W2 GELU(W1 M_t+b1)+b2 ∈ R^4
    W1: 6→8, W2: 8→4, q_it=U z_it ∈ R^4, U:128→4 (无bias)
    qbar_gt = mean_{i∈g,available} q_it

市场只有每日期一份 `c_t`，所有股票共享；行业只有每日期每组一份 `qbar_gt`，共享权重 U，不增加行业独立参数。**qbar是行业相对表示，不是绝对行业行情。** 第一版市场状态共享、行业响应共享的结构已可成立，不需要把行业隐藏表示冒充绝对状态。

选择当前 M 的小MLP而非新小时序 encoder：M本身含1/4/12/20周统计，足以检验最小状态假设，实际 batch 已提供 `[B,6]`。新序列会要求 `[B,Lm,6]`、前史 mask 和额外拟合，并同时改变历史记忆；暂无独立证据需要它。股票窗口保持40周。若最小模型有效且明确遗漏状态变化速度，再单独研究4/12周M序列或小因果encoder，不先安排网格。

### 三个零初始化残差

用 A 的原始头 `m0_t,d0_gt,a0_it`：

    m_t = m0_t + bM^T c_t
    d_gt = d0_gt + sum_k gammaG_k qbar_gtk c_tk
    delta_gt = d_gt - sum_h p_h d_ht
    a_it = a0_it + sum_k gammaA_k q_itk c_tk
    alpha_it = a_it - mean_{j∈g(i),available} a_jt
    mu_log_it = s_ref * (m_t + delta_g(i),t + alpha_it).

因此 `sum_g p_g delta_g=0`、`mean_{i∈g} alpha_i=0`，输出 `[B,N]`，组项 `[B,G]`，市场项 `[B]`。最终统一用训练期固定正尺度 `s_ref` 改善数值条件：三个原始头和状态残差先在无量纲坐标相加，最后统一乘回log收益单位；导出的市场/行业/alpha贡献也各乘同一个 `s_ref`。M残差必须在相同输出坐标加入，不能将任意排序分数与收益相加。

`bM,gammaG,gammaA` 全零初始化，U/MLP普通非零初始化；起始预测严格等于父 decoder，而不是宣称等于训练过的原B0。零增益意味着初次反传主要启动增益，U/MLP可能首步无梯度，这是预期；不能把所有因子矩阵也置零导致双线性分支永远打不开。不对经济方向施加符号约束。若担心极端状态，首先检查已有±6截断与验证外推，不随意再加一层状态开关。

参数为 `(6×8+8)+(8×4+4)+128×4+4+4+4 = 616`。只开行业内交互为608参数；完整616参数作为本文唯一详细规格，分支消融用屏蔽残差而非另加网络。额外时间复杂度 `O(B·(6·8+8·4)+BN·128·4+BN·4+BG·4)`，额外主激活 `O(BN·4+BG·4)`，没有 `N²`项；无新时间注意力。该数是解析计数，本文未实例化模型验证。

### 为什么中心化后仍可能改变排序，什么时候被约束消掉

令 D 是行业one-hot，W为事先固定候选权重，`P_D=D(D'WD)^-1D'W`，空行业排除。行业内残差为 `Q_D a=(I-P_D)a`。对市场共享 c，新增 alpha 具有：

    Delta alpha_it = sum_k gammaA_k (q_itk-qbar_g(i),tk)c_tk.

只要同业股票 q 不同，市场共同状态仍可改变行业内排序。若 q 对每个行业恒定，新增alpha完全为零；这种行业共同响应由delta头承担。单股行业的alpha必为零，不能以单股组“发现更强alpha”。再加因子中性约束时，任何落入所约束因子空间的交互也会被投影消掉；例如 q恰好只是待剔除beta，M×q无论多强都会归风险暴露项。需在解释前声明目标是可预测总收益、行业差异还是约束后的alpha，不能同时保留严格中性与被中性化掉的收益来源。

如果继续用 `eta²(total_score)` 强惩罚行业均值，会主动压制delta；不应把受惩罚后不产生行业收益归结为状态无用。可识别的中心化是输出定义，组合行业中性是执行约束，二者并不相同。该损失变动必须由 A 的父decoder与 M增量臂共同采用，才可隔离M信息增益。

## 5. mu 与风险的不同职责

本研究不把市场波动高硬编码成预测收益低。均值头学习 `mu_log`，风险头学习条件误差尺度；它们可能同向、反向或无显著关系。与 C 的最终统一规格是同中心两尺度 Gaussian mixture：中心 `mu_log`、固定混合权重0.9/0.1、尺度比例1/3，风险尺度由独立 `u_sigma` 产生。

统一尺度头为 `u_sigma_it = wSigma^T z_it + vSigma^T M_t + bSigma`，128+6+1=135参数，通过 C 的 `s_ref*(epsilon+softplus(u_sigma))` 保证正尺度。不复用均值MLP和γ，避免一条状态通道同时承担收益符号与波动大小；**所有概率控制臂都同样开放这6个风险状态系数**，因此“均值无M”父对照仍有风险M，A与A+M616仅比较均值状态增量，不把风险新增信息混入收益归因。风险系数的初始化与尺度下界由C统一，本文不另设第二个风险臂。

最终完整decoder计数：市场头2081、行业头4128、alpha线性头128、均值状态残差616、尺度头135，共7,088；不含原时序主干。关闭均值状态残差后的概率父对照为6,472参数。两者均为纯NLL，旧tail/rank/InfoNCE/eta²损失关闭，因而相对旧B0的差异是完整学习系统，相对概率父对照才是M均值信息的增量。

同中心混合模型的简单收益均值为 `exp(mu_log) * sum_k pi_k exp(0.5*a_k²*s²) - 1`，所以等 `mu_log` 而风险较高会有更高模型隐含简单均值。综合方案已确定 score=`mu_log`，不将此Jensen项偷渡为选股优势。单股边际尺度也不等于组合风险：共同市场状态不构成跨股残差协方差估计，组合VaR/杠杆仍需另外的联合风险模型。

## 6. 后续行业绝对状态与新数据：明确分开

只有M增量通过预登记验证才考虑新增 `I_gt∈R^3`，第一组只用现有周行情：行业等权1周收益、该行业合成收益20周波动（至少16项）、行业上涨广度。来源是同一周panel和决策时已知行业ID，shape `[T,G,3]`，接入时 gather为 `[B,N,3]`，不产生独立行业网络。为避免动态组历史随今日分类回填，每个历史周用当周已知行业ID计算；目前静态回溯分类只能标为回溯行业实验。

每个字段用训练期全部有效“周×行业”行拟合一套共同尺度，验证/测试固定，**不逐期跨行业z，也不每行业单独z**，这样保留跨行业及跨期绝对差异。同时保存输入有效mask、收益成分数和统计窗口观测数；若行业股票不足，按预登记最小数无效化、用mask门控新增残差为零，而非修改既有候选名单。状态是同行共享统计，不能把各股票LOO值声称同一行业共同状态。自股参与合成收益是过去信息，不是未来泄漏；小行业的机械自相关应通过行业规模/去自身诊断识别。

该三字段需要新派生产物与preprocessing身份，但不需要外部下载。它与旧F1的“股票特征减行业均值再截面z”不同。具体下一阶段模型可将状态输入 `[M_t;I_gt]` 送共享9→8→4 MLP，但不在第一版就替换全模型；此时有行业不同的c，市场m头仍只读取M，防止随机行业次序进入市场预测。

以后需要外部数据的版本：真实历史PIT行业变更/股票池、市值和可交易自由流通股以区分成交活跃与换手、官方指数与成分、日内价差/冲击、融资和借券供给、利率/估值/宏观状态。它们的发布延迟、可得时点和修订历史须先登记。现有M6没有估值或资金价格信息，不能拿文献中的宏观状态交互成功替代缺失字段。第一版不依赖这些资料。

验证仍是2018–2020完整三年；2021+是已读历史复检。按日期块做配对不确定区间，seed不是独立经济样本。解释指标包括市场状态各训练分位的交互变化、alpha中心化后保留比例、行业项占比及状态分桶误差；不能通过看历史测试的分桶效果反向挑状态阈值。这里未创建任何运行任务，也未判断其他会话后台任务当前状态。

## 8. 原始论文与本项目推断的边界

Gu、Kelly、Xiu 的研究把股票特征与宏观变量做交互，并以条件期望为预测目标；说明“股票特征×共同状态”是可用建模结构。其美国股票、月频、宏观字段和实证结论不能外推为本项目周频M6必然有用。本文的小MLP与低秩残差是项目候选，不是论文原模型复现。[论文作者版本，§2.1式21–22及§3.3.1](https://dachxiu.chicagobooth.edu/download/ML_BKP.pdf)；[正式发表页](https://doi.org/10.1093/rfs/hhaa009)。

Kelly、Pruitt、Su 的 IPCA 通过特征联系动态因子载荷，强调可预测收益可能来自风险暴露，而非必然是异常alpha。这支持先定义共同项/暴露/残差的职责，不支持把任意潜向量命名为经济因子，也不证明行业中心化后的alpha必须有预测力。[原论文正式发表页](https://www.sciencedirect.com/science/article/pii/S0304405X19301151)。

Hamilton 的状态转换模型将参数变化建模为不可观测离散状态并递归推断；这与本报告直接观测M的小MLP不同。第一版不需要HMM，更不能用全样本平滑的历史状态标记当实时可得状态。若未来研究隐状态，只能用截至t过滤概率并冻结训练期估计，另行检验标签交换与状态稳定性。[Hamilton原始研究发表页（1988）](https://www.sciencedirect.com/science/article/pii/0165188988900474)；[作者列出的1989论文及实现](https://econweb.ucsd.edu/~jhamilto/pub_metrics)。
