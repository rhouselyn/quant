## 外部研究

### 候选重排与 GRPO

- **候选重排有金融先例。** Poh 等在 31 个货币对上做日频多空，分别将原榜前 10 和后 10 重排，最终各取 3 个。第二阶段用同截面 pairwise logistic 或 ListNet。表 2 中 LambdaMART 的夏普从 0.822 到 1.008。这个结果支持验证两阶段结构，收益幅度取决于市场、初始排序、持有期和执行条件。580 股版本可用同一冻结候选比较原分数、逐股小头和候选自注意力，隔离横截面上下文本身的作用。监督基线可用候选内 pairwise logistic，另按需要试可微 Spearman 或头部指标。全截面 RankIC 和候选内排序各回答一个问题。 [外汇重排原文 §§3–5、表 2](https://arxiv.org/html/2105.10019) · [可微排序与 Spearman](https://proceedings.mlr.press/v119/blondel20a.html) · [NeuralNDCG](https://arxiv.org/abs/2102.07831)
- **PoLi-RL 是条件语义相似度任务。** 同一个文本样本采样多条生成，先学逐条评分，再按生成编号分片，给每个生成加成对和列表奖励。附录 A.4 的回归对照用 Pearson 损失代理 Spearman。论文提供先学粗分、再加强候选排序的类比。对于可直接反传的股票分数，先检验同候选、同信息和同模型容量的监督损失。 [PoLi-RL §§2.2–2.3、A.4](https://arxiv.org/html/2510.04080)
- **组内收益标准化与策略夏普的分母不同。** 原 GRPO 对同一问题从旧策略抽取多条输出，标准化组内奖励，优化带截断的概率比及参考策略 KL。移植到选股时，硬 Top-K 需要定义实际采样的组合或序列动作及其 log-prob。即便策略抽样条件独立，同周组合回报仍共享市场路径与持仓重叠。组内标准差衡量同周动作回报的离散程度，策略夏普需要按时间排列的组合净超额收益波动。增加同周采样改善的是对该周动作的估计。估计样本外增量仍依赖不同周的市场路径，扣费、成交和持仓状态也需要一致。 [DeepSeekMath §4.1](https://arxiv.org/html/2402.03300#S4.SS1) · [Sharpe 原文](https://stanford.edu/~wfsharpe/art/sr/sr.htm) · [Lo 的时序统计](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=377260)
- **ParetoSlider 的证据来自图像与视频生成。** 它对每个奖励通道分别计算组内标准化优势，再按条件偏好加权损失。可以借鉴显式收益与换手偏好，但组内标准化会改变各周的相对权重，也会丢掉原本可用的基点单位。用冻结分数先比较固定成本惩罚或换手预算的净收益前沿，成本、成交和限制按同一账本计。 [ParetoSlider §§4–5](https://arxiv.org/html/2604.20816#S4) · [多期组合优化](https://stanford.edu/~boyd/papers/cvx_portfolio.html)

### 多期限与对比学习

- **直接多期限预测有成熟做法。** TFT 的多个预测期限共享表示，用各期限的分位损失联合训练。DeepSeek-V3 的 MTP 则逐深度接入后续真实 token 的嵌入，保持自回归链。当前任务适合共享主干、独立收益预测头，在周五同时出分。先保留一周主头，仅加一个期限验证辅助监督。区分从同一入场时点起算的累计收益和独立远期区间收益，前者含有主标签的部分回报。每个训练标签按其最迟退出时间判定成熟，切分点清除跨界标签。更长的持有期重叠，增加的是标签而非独立周度路径。验收依旧看原一周硬选股净表现。 [TFT 原文](https://doi.org/10.1016/j.ijforecast.2021.03.012) · [DeepSeek-V3 §2.2](https://arxiv.org/html/2412.19437#S2.SS2)
- **逐 token 对比是监督位置的选择，正负样本定义决定学到什么。** TS2Vec 对同一时点的两个增强视图做分层对比，兼有时间与实例负例。当前模型的终点查询与未来五周同股 EMA 表示配对，以同周其他股票为负例。对比损失可仅靠股票的长期风格、行业或流动性指纹下降，同业负例只能缩小行业捷径，还可能把经济暴露相近的股票推开。逐 token 臂应保证每个查询只看其锚点及以前，未来键只在训练中使用，掩码排除无效观测。按每周等权归一并记录有效监督量，先对比无辅助、末 token 与等预算多 token，配一个打乱同股未来窗口的诊断。仍能识别同股而一周收益无增量时，身份信息是更合理的解释。 [TS2Vec §§2.3–2.4](https://arxiv.org/html/2106.10466#S2) · [随机负例与假负例](https://arxiv.org/abs/2007.00224) · [当前查询与教师](../src/quant_mvp/hierarchy_engine.py#L561) · [周内负例](../src/quant_mvp/hierarchy.py#L528)

### 日频分块、时间塔与权重平均

- **H-Net 的最后压缩 token 取自最后一个块的起点。** 原路由用相邻投影状态的余弦距离，压缩直接收集边界位置，随后解块、接逐位置残差、再解码。在因果编码下，若只取主网络最后压缩向量做周五分数，最后边界之后的交易日没有输入路径。可用解码后的最后有效日，或把闭合块的末状态或掩码池化送入时间塔，或在当前决策窗口末尾追加一个能读全窗的汇总位置。块末信息只在块结束后可用。固定与动态分块须共用读出，检查末段、停牌和短交易周的有效性。 [H-Net §2](https://arxiv.org/html/2507.07955v2#S2) · [边界与收集代码](https://github.com/goombalab/hnet/blob/main/hnet/modules/dc.py#L78-L178) · [解块与残差代码](https://github.com/goombalab/hnet/blob/main/hnet/models/hnet.py#L223-L275)
- **KDA、Mamba-3、Frac 对应不同的时序假设。** KDA 用逐通道衰减的 Delta Rule 状态做关联记忆，Kimi Linear 整模还混合 MLA。Mamba-3 引入指数梯形离散、复值状态与可选 MIMO，论文主要验证语言建模、检索和生成效率。Frac 用有限组对数间隔指数状态逼近指定范围内的幂律记忆，状态和计算随模式数增加。对 40 周时间塔应按本地同参数量、同输入和同机时间验证。若主张 Frac 的慢衰减有价值，先用低成本的多半衰期 EWMA 或有限滞后聚合对照。 [Kimi Linear §§3–4](https://arxiv.org/html/2510.26692#S3) · [Mamba-3 §§3–4](https://arxiv.org/html/2603.15569#S3) · [Frac §3、附录 H](https://arxiv.org/html/2609.36314#S3)
- **输出门和 DSA 的加速条件不同。** Qwen 论文中的头专属 sigmoid 作用在 SDPA 输出上，仍要算密集注意力。DSA 把主注意力降至 `O(Lk)`，轻量索引器仍对全序列打分，为 `O(L²)`，另有 top-k 与稀疏访存开销。40 个时间位置对长上下文速度结论的适用性有限。580 个截面位置上，若需建模候选上下文，先在固定候选的稠密小头上测收益和耗时。 [Gated Attention 原文](https://arxiv.org/abs/2505.06708) · [DeepSeek-V3.2 §§2.1、2.3](https://arxiv.org/html/2512.02556#S2)
- **Weight soup 优先验证同一训练轨迹或共同母模型。** Model Soups 的主实验是在共同预训练权重上做多次微调后平均，成立与否依赖低损失区连通。独立初始化的相同网络存在隐藏单元的置换对称，参数按下标平均可能破坏函数。同一架构的同轨迹 checkpoint 可先看插值路径和平均点在开发窗的损失及净指标，再与现有分数融合比较。独立种子的默认对照仍用预测融合。 [Model Soups](https://proceedings.mlr.press/v162/wortsman22a.html) · [Git Re-Basin](https://arxiv.org/abs/2209.04836)

## 2. 从 Top-K 和 Bottom-K 重排后等权持有

**可以直接做。两阶段设计对当前问题比重训整个骨干更容易归因。** 把 `K` 定义为冻结模型在决策时产生的候选数，把 `N<K` 定义为最终持股数。若目标是 50 只，首臂锁定 **Top-100→50**，主对照是在同样的 100 只中用原分数取前 50。若目标是改善现有 40 只研究书，可另登记 **Top-80→40**。固定本轮一种组合，避免读历史后挑最佳 K 和 N。多头与空头分开训练和评估。空头先按实际券源、流动性及多空冲突过滤，再构建 Bottom-K；风险预算、费后空头价值和可借量约束允许留空槽。

1. **冻结候选的生成器。** 保存时点外分数、同股 embedding、候选成员和已持仓。每折基模型只训练到该折以前。用当时决策可见条件入池，未来收益、开盘成交和借券结果只进入标签与账本。时点外指该周未用于训练或挑选生成其分数的主干，旧全验证选轮权重不能倒过来生成严格样本外训练特征。
2. **从小残差头开始。** 输入原分数、冻结表示，可选加入少数明确的边际成本特征。用 `新分数 = 标准化原分数 + 小头修正`，末层零初始化。比较原排序、线性残差、单层小 MLP。随机种子的 embedding 坐标可能不同，各 seed 训练自己的头，最终融合分数。硬 Top-K 选池索引当作固定，首轮不开主干梯度。通过后再与同预算的「冻结小头」和「同样解冻只训原目标」比较末层微调。
3. **训练候选内的名次，验收实际换人。** 先用同周、同腿的 pairwise logistic，只给跨真实标签边界的股票对较高权重。真实未来标签只决定监督对及偏好；候选仍是固定的预测 Top-K。每周归一，跳过无有效配对的周。对极端差值使用有界权重或排序标签，小到难区分的差值可低权处理。若要直接扣成本，先用可校准的边际基点预测，比较「保留 A」与「卖 A 买 B」。在 50 只等权、单边 10 基点的简化账本，单槽换一次成本约占整个组合 0.4 基点，需要 B 对 A 约 20 基点的毛收益差覆盖；真实费用与漂移仓位逐笔核算。评估报硬入选净差、实际替换数、毛差、费用差、行业/流动性偏移、换手和回撤。给一个限制每周最多换少数席位的对照，判断增益是否来自过度改动。

历史负证据的范围清楚。P2 只是检验原分数到未来收益基点的分箱校准，多头 Top-40 未过门。旧 score MLP 只在固定候选内作 `80% 等权 + 20% softmax`，纯多绝对/相对标签分别 −1.21/−0.66 基点/周。H32 是全池上联合训练的分数残差，开发窗 −1.57 基点/周。尾部分层旧臂把四项改动捆在一起。它们都没有做冻结、时点外候选 Top-100→50 的硬成员重排。 [P2 校准门](../outputs/exp580/p2/gate.json) · [旧 MLP](score_mlp_results.md) · [H32 首筛](../outputs/weekly_architecture_v1/screening_s42.csv) · [四合一臂](experiment_ledger.md)

### RL 的可识别增量

固定 N 等权且收益、交易费可按个股加总时，期望净价值足以决定大部分选择。先做局部换仓价值、硬等权、规则或有约束的优化。若行动影响未来持仓、费用与可买卖性，才比较外接小策略。让它从固定候选中选「0、2 或 4 个边际换仓」或「固定目标的半量/全量调整」，使用真实持仓、现金、残单和候选分差作状态。同输入的固定换仓、一步监督价值与两三周滚动优化是必要控制。小规模、低冲击且转移可可靠重放时，可以用确定性滚动规划或直接优化净增长。要采样硬组合时定义不放回动作与对应概率，组合奖励用该账本的净对数增长或同周基准增量，并在完整验证路径上测 Sharpe。资产级信用先用已实现持仓收益与单槽换仓净差，路径风险及交易延续进入跨周价值。 [既有 RL 报告与成交缺口](research_20261112_rl_portfolio.md)

## 4. 对比学习放在什么位置

**当前已经在最后时间表示上做了类似操作。** 40 周输入经时序注意力后取末端状态，再经单独投影头与同股未来 5 周 EMA 编码匹配，同周其他股票作负例，权重 0.1，发生在关系层之前。它训练的是「哪段未来更像我」。EMA 键里的滚动特征仍含较长历史。旧同业负例没有改善 IC/组合。去掉当前 InfoNCE 的固定窗口首种子 −4.5 基点/周（t≈−0.59），无法证明它有明确净收益贡献，但支持把它保留为现有控制。另一个预训练实验里，同股掩码对比 loss 从 1.309 到 0.133，冻结后相对随机编码器加同一线性头净差 −6.78 基点/周。 [实现](../src/quant_mvp/hierarchy_engine.py#L561) · [同业负例 §2](experiment_ledger.md) · [移除 InfoNCE](research_exec_20261110_report.md) · [两阶段预训练](two_stage_embedding_results.md)

在 attention 前把同一个投影 token 当正例容易变成原样匹配。把所有别的周或别的股推开也可能强化行业、个股持久风格、缺失模式，或推远真正相似的事件。每个原始周进入许多重叠窗口，逐 token loss 还会反复计数。优先级依次是现有末端目标、末端目标的替代、少量有任务语义的 token 级目标。真要试，用两个掩码视图或未来变化做正例，仅在 attention 后的因果状态或末端表征上加小投影头，固定监督预算并按唯一周等权。保持主损失，替换旧辅助臂的一部分，而不是同时堆几种损失。用同股未来窗口时间打乱的诊断检查身份捷径，另查短周、复牌和极端风险信息是否被增强擦掉。读数看头部净收益和稳定性，同时观察是否仍能在时点外解码截面风险与方向。

## 5. H-Net 如何取最后一个 token

**可以取最后一个有效的块表示，条件是它是块末摘要，且最后一个块截止到决策时点。** 原版 H-Net 主网络压缩时取块开始处的向量。假设最后一次边界在周三，因果主网络里的最后压缩向量最多看到周三，周四周五只有通过解块后的逐位置残差与解码器等路径才可进入最终读出。

首选让每个块汇聚从开始到末尾的因果日编码，周末闭合最后一块，送入现有时间塔，再按有效掩码读取最后块。也可加一个周末 query，让最后有效交易日的状态读取整段压缩历史。在完全保留原 H-Net 时直接读解块解码后的最后有效日。块时间位置用真实块结束日期和时间间隔，短周或停牌不产生伪 token。取读出时必须避开 padding。固定分块与动态分块共用末端读出，避免把周末信息遗漏误当成路由收益。测试固定边界后修改尾段两天，确认存在影响分数的路径；另修改决策后的数据，分数须保持不变。 [现有末周读取](../src/quant_mvp/model.py#L433) · [此前日线分块方案](research_20261112_daily_tokenization.md) · [原版 H-Net 分块](https://arxiv.org/html/2507.07955v2#S2)
