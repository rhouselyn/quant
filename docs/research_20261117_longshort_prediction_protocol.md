# 多空比例预测与行业叠加

2026-11-17，Asia/Shanghai。批次 outputs/longshort_prediction_v1。复用[行业 MLP](research_20261117_industry_mlp_protocol.md)、[二值及温度](research_20261117_mlp64_binary_protocol.md)和标准三年回放。比较 B0 锁定多头1–3、空头6–8轮的 LS50；固定 Top20/Bottom10 与当时融券资格，空头不足预算留现金，按各臂实际状态独立计费用与借券。缺失持仓标签不参与拟合，成交阻断遵照周度代理。

每周用冻结 B0 第3轮时序编码器，分别对多头与候选空头向量均值汇总，拼接两个128维向量与入选空头数量比例。无空头时用零向量与零数量。输入不含未来成交或标签。每周记录原计划等权实际成交的单位名义多头毛收益 L、空头盈利方向毛收益 S（空头每只权重按10只的分母，未填预算留现金），训练目标 D=L−S。二值标签 D>0 为 +1，否则 −1；同一标签成熟时点。特征标准化仅使用已成熟训练周。至少40周，每13个锚扩窗拟合，2021+首周用全部成熟验证周拟合后冻结。

比较 256+1→16→1 与 256+1→64→1 的 GELU MLP，各用收益 MSE 或方向 softplus(−y×logit)，AdamW lr=.001、权重衰减 .01、batch64、12轮、seed42。回归预测恢复收益单位；二值预测概率映射为 (2p−1)×已成熟 D 的 RMS，作为可比较的收益尺度，非概率校准的条件收益。双项 softmax 为 pL=sigmoid(Dhat/T)，设多头预算 0.5+0.25×(pL−0.5)，空头为余数。温度 .01/.02/.05/.10，热身回退50/50。组内行业叠加使用已发布行业 MLP64 连续收益 T=.02 的逐行业预测，同时运行同条件的仅行业和仅多空臂；对多头套用同一个风险底仓、25% softmax 倾斜及按原行业预算缩放的5个百分点上限。空头不做行业倾斜。多空叠加改变信号解释，需以仅多空和仅行业的同周账本比较。
