# 降噪组内排序与 FOX 常数衰减登记

2026-11-14，Asia/Shanghai。父实验的诊断和原始口径见[零训练诊断](research_20261114_p6_fox_diagnostics_results.md)及[组内排序与FoX协议](research_20261114_group_fox_protocol.md)。

- **P6GAP 对 P6**。每交易锚沿用同组非同收益配对，每股票最多4对。配对权重为 `abs(y_i-y_j)/(abs(y_i-y_j)+s_ref)`，按当日入选对的权重和归一，再日期等权。沿用训练期冻结的 s_ref、0.1 系数和 faithful 均值与尺度梯度隔离。近似平局相对降权，覆盖、NLL、RMSE、RankIC 和多空净收益共同检查。
- **FOXCONST 对动态 FOX 和 B0**。每层每头一个可学习常数 b，logit 偏差为 `(t-s)*logsigmoid(b)`。初始 sigmoid(b)=0.99，4层4头共16个门参数。沿用 B0 目标和 teacher。两实验分别训练。

使用 BQ_F0_r2，训练标签截至2018-01-01并保留共同5周预留，实际779锚（2002-07-19 至2017-11-24）。seed42，各8轮，batch16。2018–2020三年完整验证153成熟周，分别按多空净Sharpe选单轮，再取边界修正的连续3轮窗口。两臂锁定之后才运行历史评分。2021-01-08起297成熟周为已读历史复检。保留原候选集、概率或z分数融合、持仓和交易代理。主成本每边10bp、空头年券费8.35%，另有30bp/12%及缺失20%压力档，分别报告L20、S10、LS50、LONG_CASH、配对周净差及8周块区间。历史方向仅提供探索证据。

成本门槛换股审计截至登记日。P6 原训练锚覆盖2002-07-19至2017-11-24。P6 实际可见评分包括内部验证2018-01-05至2019-12-27、标准原始验证评分2018-01-05至2021-01-01、原始历史评分2021-01-08至2026-10-30。成熟周依据原执行日历另外锁定。旧 walkforward、R50 与 one-step-turnover 产物来自其他模型、标签或分数口径，现有产物未提供同一 P6 收益单位且模型训练、预处理、换股收益标签均符合时序的校准对。换股门槛零训练回放暂缓。重新评估需要训练期严格时间外的 P6 预测、持仓漂移和买卖双方成熟标签，用以核验算术收益差与双边成本同单位。
