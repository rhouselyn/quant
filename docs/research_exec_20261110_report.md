## 1. 一句话结论

九个预注册方向全部执行完毕。**没有任何候选值得替换 baseline 或扩 seed**；本轮价值在于

5. **P17 幅度迁移教训第三次复现**：P1 成本门槛在 val 报 +9.9bps/周（含校准味），

## 4. E0 计时、M1 梯度探针、M4 层诊断

**E0（以真实臂运行为准，探针绝对值受系统失真仅取份额参考）**：
- 教师塔/InfoNCE 成本 ≈ **0**：M1（无教师）877s vs canonical 837s，差值在噪声内为负；
- 4 层时间塔占 **~81–86%** 运行时间：L0（0 层）155s vs 837s；L2（2 层）553s →
  **~200s/层，近线性**；
- 数据准备占比 ~0.1%（探针），损失计算可忽略；
- 冻结零门关系层旁路的可省上限 ≤155/837≈18%（未细测，按 E0 原则"占比不明朗不实施"）。
- 结论：**优化空间不在 InfoNCE（零收益），而在深度本身**；下一步若要提速应做
  checkpoint/BF16 的逐项数值验证，不是砍辅助任务。

**M1 梯度探针**（canonical best.pt，引擎同序前 8 个 batch）：
`cos(g_main, g_infonce)` 均值 **−0.016**（逐 batch −0.048~+0.004）；归一化范数
0.233 / 0.304 同阶。→ InfoNCE 与收益目标**近正交**：无一阶冲突、也无顺梯度，
是弱耦合正则。与账本（删除 −4.5bps、IC ↓）互证：保留。

**M4 前置诊断**（4 层 encoder，6 个 batch）：
层输入/输出 RMS 1.00→1.13→1.35→1.63→1.93（每层 ~+18%，平滑）；cos(in,out)
0.92→0.94→0.96→0.97。**无幅度爆炸、无表示塌缩**；结合 0<2<4 层的收益单调性
（无深度稀释症状），**Attention Residuals 的前置条件不成立 → M4 关闭**
（计划原文条款）。
