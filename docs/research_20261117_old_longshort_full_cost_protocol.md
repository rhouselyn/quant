# 原冻结 BCE 的全多全空计费优化

2026-11-17，Asia/Shanghai。固定[旧 BCE 和 Top40/Bottom10](research_20261117_old_longshort_bce_rules_results.md)，沿用 133 周验证、283 周已读历史。原 z>0 全多、否则全空，与宽档 40%/70% 对照。计费优化使用原费用实验的训练期正负条件差值换算、原有估值时点和 0.05 偏离 50% 平方惩罚。分别跑二值端点 p∈{0,1} 与连续 p∈[0,1]，并各跑同目标规划费为零，两者实际回放都扣费。端点之间的平方惩罚相同。单边 10/30 bp 配 8%/12% 年券费。以原账本验证边界、总净和两腿贡献。

另外比较弱信号时保持两腿的办法。预定绝对 logit 阈值 0、.0025、.005、.01、.02、.04、.08。绝对值小于阈值时回退旧宽档，同方向强信号周保持原全多或全空。仅验证期筛两档净均值均不低于原全多全空且两档最大回撤均不高于原全多全空的规则，在其中选两档回撤平均最小的阈值，同分取较低阈值。若无正阈值通过则保留 0。把锁定档带到已读历史。作为探索，报告周均、最差 10% 周、年化夏普、最大回撤、多空净贡献、换手及逐周配对。
