# 入选股行业向量 MLP 结果

2026-11-17，Asia/Shanghai。已完成。[协议](research_20261117_industry_mlp_protocol.md) · [日志](../outputs/industry_mlp_v1/run.log) · [配对结果](../outputs/industry_mlp_v1/report/paired.csv)。

固定 B0 Top20。以第 3 轮 B0 冻结时间编码器抽取 128 维个股向量后按行业平均。Ridge 与 128→16→1 GELU MLP 使用同一向量、收益标签和训练周。验证有 104/153 周产生预测，98 周有完整标签。历史复检前最后用 139 个成熟周训练 12 轮后冻结，两头在 297 周都有预测，286 周有完整标签。最终 MLP 的训练 MSE 从第 1 轮 0.001685 降至第 12 轮 0.001588。周等权算术收益 RMSE（Ridge / MLP）验证 4.348% / 4.347%，历史复检 4.551% / 4.532%。
