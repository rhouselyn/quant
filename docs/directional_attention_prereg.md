# Direction classifier and discrete allocation experiment

Fixed-vintage seed 42 epoch 3 encoder and data as in score_mlp_prereg.md. After its training boundary, select highest 50 scores for long and lowest 50 eligible scores for short, excluding the long candidates from short. The prior-quarter public eligibility list is a short-availability proxy. No realized returns or entry flags enter candidate selection.

Use one joint MLP, input frozen 128-dimensional stock embedding plus side indicator, 129→32 GELU→1, binary cross entropy on positive directional simple return. Fit annually on preceding matured candidate observations with a two-anchor-week gap. For each week select the 50 highest sigmoid probabilities across both sides. Normalize softmax of these probabilities globally. Keep the side for trade direction. Missing label observations do not train the classifier. Compare the resulting score weighting and 50/50 normalized legs to equal weights over the same selected stocks and to the original old-score 40-long/10-short equal-weight proxy.

The allocation network receives the 50 selected stock embeddings and side indicator, projects them to 32 dimensions, and uses one learnable token as query in four-head cross-attention with candidates as keys and values. Residual plus layer normalization and a 32→64→32 GELU FFN with residual and layer normalization lead to three logits. The three classes use 60/40, 50/50, 40/60 long/short budgets and preserve the MLP-derived normalized weights within each leg. Train with cross-entropy using ex-post one-week returns less 8% annual short fee, with the same out-of-sample generated MLP candidate weights. Label 60/40 or 40/60 when their return difference exceeds 10 bps in that direction; otherwise label 50/50. The 10 bps gap gives 50/50 a 5 bps tolerance to the better extreme. When a leg is absent its allocation stays cash. Select the highest logit at inference. Compare three fixed budgets and a shared-projection mean-pool classifier. Fit annually using prior matured examples, 40 full-batch Adam steps, lr .001, weight decay .01, seed 42. The first MLP fitting year is 2023, using data since 2021; allocation fitting begins with 2023 examples and evaluates 2024–2026.

Compute shared-account drift-aware weekly net return and full L1 turnover, 10bps traded notional and 8% annualized short borrow. Report zero-filled missing return counts. This is a historical proxy using a retrospective universe and incomplete execution and borrow information, not a prospective test.
