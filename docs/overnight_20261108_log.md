## 00:55 零训练实验 Z2 / Z3（结论：Z2 杀，Z3 只算线索）

**Z2 理由**：融合先逐日 z 再平均，但决策只用序；z 被每个模型分数分布的
尾部形状污染。高斯 copula 下最优聚合是逆正态秩（van der Waerden）平均，
简单秩平均是分布无关的稳健版。**重建的 z 版与冻结参考逐周完全重合**
（corr 1.0，最大差 1.3e-16，score corr 1.0）→ 仪器可信。

| 臂 | val diff bps (t / NW) | test diff bps (t / NW) | 判决 |
| --- | ---: | ---: | --- |
| Z2 normal-score 聚合 | +3.90 (1.04 / 1.20) | **−2.25** (−0.86 / −0.87) | 跨窗反号 → KILL |
| Z2 简单秩聚合 | +7.31 (2.11 / 2.60) | **−1.37** (−0.61 / −0.62) | 跨窗反号 → KILL |

val 上看起来很显著（秩聚合 t=2.11、NW 2.60）但在 test 完全反转——
这是"验证窗挑出来的测量改进"的教科书案例，正好说明为什么主门要 val/test 同号。
**教训**：改集成的 score→rank 变换只动了分数的单调非线性，
它改变的是**中段的相对密度**，Top-20 尾部几乎不变；val 的 +7bps 是尾部换票的运气。

**Z3 理由**：9 个分数面给每周每票的均值与标准差（模型分歧），
现有融合只用了均值。均值-方差/模糊厌恶效用下应按 `mean − λ·std` 选票，
避开"只有一个模型看好"的噪声票；λ 先验固定（1.0 主、0.5 稳健），
与台账 §10/§11 的 Kelly（用横截面分数幅度）完全不同。

| 臂 | val diff vs base | test diff vs base | test Sharpe / 年化 |
| --- | ---: | ---: | ---: |
| flat-9 z 均值（Z3 自身对照） | +0.82 (t=1.41) | +0.22 (t=0.50) | 1.015 / 27.45% |
| λ=1.0 | +4.39 (1.31) | +2.25 (0.86) | **1.066 / 28.92%** |
| λ=0.5 | +2.33 (0.92) | +2.18 (0.98) | 1.060 / 28.83% |

两窗同号、剂量响应平坦（λ=0.5 与 1 几乎一样）——**但 t 全部 <1.2，
远低于预注册主门 2.5**。判为**线索，不是胜者**，不扩 seed、不采纳。
附带发现：两阶段 z 融合（冻结口径）比 flat-9 直接平均略差（test −0.22bps），
说明"先 seed 内 ens3 再跨 seed z"这一历史惯例并非最优，但差异在噪声内。

## 01:05 零训练 Z4：期货对冲"更高收益也更稳"的证伪（关键审计）

**理由**：台账 §21.1/§21.2 说给纯多书加 IM/IC 对冲能把
27.3%/1.011 提到 **30.9%/1.56 且 MDD −21%**——收益、Sharpe、回撤三项全赢。
但对冲只移除市场暴露，按定义不可能凭空造 alpha；三项全赢意味着
**样本里的市场方向在替空头腿付钱**。用仓库自己的等权 580 基准做严格分解。

- β（纯多书 vs 等权 580）：**val 1.129 / test 1.127**，两窗几乎完全一致
  （这是本晚最稳的一个统计量，支持任何 beta 对冲构造）。
- 等权 580 市场**平均收益为正**：val +18.37bps/周、test +18.67bps/周。
  → 做空它不是"避跌"，而是**要付出 ~21bps/周 的负 carry**。
- 用 **val 拟合的 β=1.129 静态对冲**、test 单次外推：

| | 年化 | Sharpe | MDD | 年化波动 |
| --- | ---: | ---: | ---: | ---: |
| 不对冲 | 27.31% | 1.011 | −28.97% | 27.7% |
| 静态 β 对冲 | **17.80%** | **1.492** | **−12.29%** | 11.4% |
| trailing-26w β 动态对冲 | 15.97% | 1.232 | −13.19% | 12.7% |

**判决**：hedge 确实把 Sharpe 从 1.01 提到 1.49、MDD 减半，
但**年化收益下降 9.5pp**；动态 β 择时贡献 −2.7bps/周（负）。
所以 §21.1 的"30.9%"不是 beta 对冲的功劳：
`futures_hedge_report.json` 早期版本里期货与多头书相关只有 0.02~0.06
（明显是 Monday-open 对齐 bug），修好后的 `_aligned` 版 IM0 才给出
corr 0.77/0.88 与 30.94%；那个数字来自 IM0 连续合约自身的收益路径，
而不是"去掉 beta"。**结论：把 IM 对冲当成'更高收益'的证据是口径混淆；
它真实提供的是风险调整后稳定性，代价是收益与负 carry。**

## 01:15 零训练 Z5：持仓权重更新（用户点名），今晚最像"候选"的结果

**理由**：既然 β 稳定、alpha 为正、残余波动只有原来 41%，
那么数学上正确的做法不是"要不要对冲"，而是**两资产组合的权重**：
`r(h) = L − h·β·B`（B=等权 580 空头），再按**波动匹配**加杠杆
`k = σ_val(L)/σ_val(r(h*))`。刻意**不估计期望收益**（Markowitz 的误差放大器），
只用波动；h 由 val 的 Sharpe 网格 {0,.25,.5,.75,1} 选，k 由 val 波动定，
**两者都在读 test 之前冻结**；对冲腿按 0.23bps×2/周计费。

- val 网格 Sharpe：0→0.855、0.25→0.955、0.5→1.095、**0.75→1.248**、1.0→1.199
  → h\*=0.75，k=2.245（总敞口 4.14×）。
- test（单次外推）：

| | 年化 | Sharpe | MDD | 波动 |
| --- | ---: | ---: | ---: | ---: |
| baseline | 27.31% | 1.011 | −28.97% | 27.7% |
| 对冲 h=0.75（不加杠杆） | 20.58% | **1.502** | **−13.42%** | 13.0% |
| **对冲 + 2.245× 杠杆** | **48.59%** | **1.502** | −28.31% | 29.3% |

paired 差 **+30.69bps/周，plain t=2.06 / NW5 t=2.28**，
**逐年 6/6 全正**（15.8/51.0/14.0/42.2/25.4/39.0 bps），val 与 test 同号。
- **但融资成本敏感性**（借入 k−1 倍名义）：
  2% → 45.0%/1.417/diff 25.9bps(t=1.92)；
  3% → 43.2%/1.375/diff 23.5bps(t=1.75)；
  4% → 41.4%/1.332/diff 21.1bps(t=1.57)。
- **判决：候选（不是认证胜者）。** NW5 t=2.28 未过预注册主门 2.5，
  加融资后降到 1.6~1.9；且需要 4.14× 总敞口、一个可交易的
  等权 580 空头工具（现实中只能用 IM/IC，基差风险未建模）。
  **不加杠杆版本是"更稳但不更高收益"**（Sharpe 1.50、MDD 减半、年化 −6.7pp）。
  这是"更稳 + 更高收益"必须靠杠杆/融资换，而不是免费午餐——
  这一条本身就是今晚最重要的结论之一。

## 01:20 第三批预注册（此时 7 个训练臂**一个 val 读数都没出来**）

**T8：市场 beta 中性化训练标签**（本晚唯一改训练目标的臂，从原理出发）

完整理由：标签 `y[t,i]=log(open[t+2]/open[t+1])` 含 `β_i·m_t`。
单一常数平移对 rank-based 损失无效，**但 β_i 横截面变化，β_i·m_t 不是常数**：
在强涨/强跌周，它会改写头尾标签的成员。Z4 实测 β≈1.13 稳定、
市场漂移为正，说明模型有一部分容量花在"识别高 beta 票"（一个静态、
无补偿的风险倾斜）而不是"识别跑赢 beta 的票"。把这一项从**训练目标**
中减掉，是对标签的方差削减/去噪，不加特征、不加容量、不改推理。
`m_t` 用同一周标签的横截面均值（它本身就是目标，合法）；
`β_i,t` 只用 `s∈[t-54, t-3]` 已完全实现的旧标签滚动估计（严格因果，
W=52 先验固定）；`evaluate()/predict()` 仍读原始 `y`，
所以**账务与其他臂逐值可比**。代码不进 `src/`：由
`tmp_ov_make_beta_engine.py` 生成 `outputs/overnight_20261108/ov_engine_beta.py`，
只改两处（构造 `y_train` + `raw_targets` 指向它），已静态 diff 核对。

预期：书的 β 与 MDD 下降（更稳）；若 beta 倾斜本身是账面超额来源，
年化会降（那就如实记录 trade-off）。**无剂量调参**，只有 1 seed=42。

**T9 / T10（预留）**：只有当某个臂 val 同时超过 s42 参考
（val Sharpe 0.931 / IC 0.0778 / 超额 32.9bps）且在**验证窗逐周 paired**
不劣时，才按预注册规则扩 seed 43/44；扩种子不是新实验，是复现门。
若 7 臂全败，则把 GPU 余量用于 **T8 的 seed 43/44** 做一次
"标签去噪机制"的独立复检，而不是临时发明新臂去碰运气。

## 01:45 零训练 Z6 / Z6b：35bps 超额到底是不是"选股"？（对 Z5 杠杆的关键前提检验）

**理由**：Z5 要把总敞口放大到 4.14×。如果底层超额只是**流动性/行业/

  raw 超额 45.57bps/周（gross 口径，与官方 net 35.2bps 的差是成本），

## 01:10 Z9 预注册：部署分数的因果时间平滑（新增，读任何训练臂 test 之前）

**为什么现在加**：这不是从前面结果里挑出来的补救，而是一个独立的、
从**信号估计理论**出发的空白。核查 `scripts/` 全部脚本与台账后确认：
"score smoothing" 在这个仓库里指的**全是训练标签的平滑**
（`run_score_smoothing_ablation.py`、`continuous_tail_score_smoothed`），
`two_week_rule_*` / `long_buffer_sweep` 改的是**持仓规则**；
**从没有人把"已部署分数"本身沿时间做去噪**。

**原理**：设第 t 周观测分数 `s_t = a_t + ε_t`，`a_t` 是慢变的潜变量
（动量/质量/流动性类信号按周衰减），`ε_t` 是模型与标签噪声，
近似周间独立。则因果等权滑动平均
`ŝ_t = (1/k) Σ_{j=0}^{k-1} s_{t-j}`
是最小均方误差的线性滤波，SNR 提升 ~√k，代价是 (k−1)/2 周的滞后。
它还是**严格因果**的（只用 t 及更早的分数），不碰标签、不重训、
不改执行口径；换手应下降 → 成本下降 → 更稳。
若 `a_t` 其实周间不相关，平滑会把信号一起抹掉，读数会随 k 单调恶化——
这正好给出可证伪的剂量响应。

**冻结设置**：
- 每个窗口内先逐日横截面 z（与部署一致）；平滑用同一窗口内
  t 及之前 k−1 周的 z 分数等权平均（头几周用可用历史，收缩窗），
  **绝不跨 val/test 边界**。
- 主臂 k=2；稳健性 k=3、k=4；k=1 为对照。**不调权重、不调 k 以外的东西**。
- 先报 val 与 test 的 score 自相关（lag1..4）作为机制前提；
  再报 paired 差、Sharpe/MDD/换手、逐年、剂量响应。
- 判据沿用预注册主门（NW5 t≥2.5、val/test 同号、≥4/6 年）。
- 明确声明：这是在看到 Z2/Z3/Z5 结果**之后**新增的机制，
  因此即使过门也只能记为"线索"，不能算认证胜者（多重比较惩罚）。
