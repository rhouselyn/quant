# P6 残差排序头与尾部分类实验协议

日期：2026-11-16，Asia/Shanghai。状态：registered，用户授权实现、测试后训练。父研究：[损失迁移](research_20261115_loss_transfer_session_results.md)、[P6实验](research_20261114_group_fox_protocol.md)。本协议在新臂查看验证或历史结果前登记。

新增单臂P6TAIL，以P6为父对照，B0为原模型共同参考。P6训练目标、编码器、收益分解、Gaussian尺度及0.1组内pair loss不变；增加128→1无偏置线性残差头h，零初始化，不消耗主随机数。`q=stopgrad(mu/c)+h(z)`，训练增加 `0.1 * mean_date(mean_valid_tail(softplus(-a*q)))`，尾标签a为当日有效log收益截断至±0.25后前/后20%的±1，中间排除；其标签规则借用B0，日期等权而非B0样本等权。c是训练期固定s_ref。q含无量纲残差，评分为`c*q`；逐epoch以该分数选股及收益单位线性融合，概率混合分别使用mu、scale。分类梯度通过h进入共享编码器，但stopgrad阻止它直接穿过mu，scale头不接收该梯度；P6组内配对仍会更新均值路径。128个新增参数，非等参比较。候选lambda=0.1、温度1，不以历史结果调参。零权重模型同样包含零头、不得更新，需证明与P6初始、训练步骤和评分兼容；旧配置及检查点行为保持。

数据继承BQ_F0_r2、训练截止2018-01-01及共同5周预留，779训练锚、seed42、8轮、batch16。2018–2020三年验证153成熟周；每个模型及多空腿各按验证净Sharpe选最佳单轮并取相邻三轮，边界平移；选轮锁定后才生成2021-01-08起297成熟周的历史评分。历史和验证已反复暴露，本批探索性。继承Q1固定幸存股池、回溯行业、代理成交及券源限制。主费用每边10bp、年借券8.35%，并报告既有压力档。主要比较P6TAIL−P6及P6TAIL−B0，分别给出L20、S10、LS50、LONG_CASH收益、Sharpe、回撤、换手、成本、逐年和8周块配对区间；金融臂报告NLL、RMSE、覆盖、PIT与RankIC。B0无概率头，不虚构概率对照。单种子不自动扩展实验。

训练前需通过零权重、初始化随机状态、梯度隔离/共享路径、空标签、缺失mask、旧checkpoint、分解与分数融合、概率密度融合、合成训练恢复及真实16×580×40 CUDA前后向检查。按共享GPU锁串行。源码、数据、配置、父对照、锁、脚本与检查产物需冻结哈希；失败阻断后续，不降低规格或无声换口径。证据仅本机，未异地备份。
